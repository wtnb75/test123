# モバイル対応

`docs/spec.md` の一部。モバイル（画面幅 768px 以下）のレイアウト・タッチターゲット・操作・表示の最適化を、独立して書いたもの。`docs/spec.md` と合わせて 1 つの spec である。

## 概要

モバイルでは PC レイアウトの縮小表示を避け、タッチ操作前提の専用レイアウトにする。主要操作は画面下部に集約し、解析や import は下部シートまたはタブで切り替える。

## 操作仕様

下の「画面・Scene 構成」の「モバイル操作仕様」に書く。

## 画面・Scene 構成

### モバイル対応方針

- モバイルでは PC レイアウトの縮小表示を避け、タッチ操作前提の専用レイアウトに切り替える
- 切り替えの目安は画面幅 768px 以下とする
- 主要操作は画面下部に集約し、片手操作で到達しやすくする
- 盤面の視認性と操作性を優先し、解析や import は下部シートまたはタブで表示する

#### レスポンシブ切り替え

- `width > 768px`: 既存の 2 カラム寄りレイアウト
- `width <= 768px`: モバイル 1 カラムレイアウト
- モバイル時は以下を適用する
  - 右パネルは常時表示しない
  - 盤面を最上段に配置
  - ツールバーを下部固定
  - 補助機能はタブで切り替え

#### タッチターゲット基準

- タップ可能 UI の最小サイズは 44px x 44px とする
- セルサイズが 44px 未満になる場合はズームを前提にし、見た目サイズと判定サイズを分離してもよい
- セル間に最低 1px の視認境界を維持する

#### モバイル画面構成

- 上部: タイトル、モード、盤面サイズ、簡易ステータス
- 中央: 盤面 + 行列ヒント
- 下部: タブ切替 `編集` / `情報` / `入出力`
- タブ上のパネル: タブごとに操作群または情報を表示

#### モバイル画面イメージ

```text
+------------------------------------------------+
| NonoEdit | Edit | 10x10 | Unique: Yes         |
+------------------------------------------------+
|                 列ヒント                       |
|   行ヒント   +-----------------------+         |
|             |        盤面           |         |
|             |  (1本指タップ/ドラッグ) |       |
|             +-----------------------+         |
+------------------------------------------------+
| [編集] [情報] [入出力]                        |  ← 下部タブ
+------------------------------------------------+
| (選択中タブの内容: Resize/Test など)          |  ← タブパネル
+------------------------------------------------+
```

#### モバイル操作仕様

- 1 本指タップ:
  - 編集モード: 単セルトグル
  - プレイモード: `Fill` / `Mark` の現在モードで適用
- 1 本指ドラッグ: 直線編集
  - 水平または垂直のみ
  - 軸はドラッグ初期方向でロックする
  - 編集モード: 範囲内に `empty` があれば `empty` のみ `filled` にし、全て `filled` の場合は全て `empty` にする
  - プレイモード: 範囲内に `unknown` があれば `unknown` のみ現在モードで更新し、`unknown` がない場合は現在モード対象のみの範囲を `unknown` に戻す

#### モバイル時の表示最適化

- 行列ヒントが長い場合は省略表示を許容する
  - 例: 先頭/末尾のみ表示し、タップで全表示
- 解析情報は下部タブ内で表示し、常時表示しない
- import/export はタブから開くダイアログを基本とする
  - 複数行 `textarea` を表示
  - `Load PBM` / `Cancel` を配置する
