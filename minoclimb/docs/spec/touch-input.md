# 入力とタッチ操作の詳細

`docs/spec.md` の一部。入力の合成と、タッチ操作（スティックの指・ジャンプの指・タップ）の規則を、独立して書いたもの。`docs/spec.md` と合わせて 1 つの spec である。操作の一覧（キーボード・タッチの対応表）と、数値（STICK_*・TAP_* など）は `docs/spec.md` のとおり。

## 概要

キーボードとタッチのすべての入力を合成してキャラに渡す規則と、タッチ（画面全体が 1 枚のパッド）の指の役・浮動スティック・タップの判定を、1 か所にまとめる。挙動は `docs/spec.md` の操作仕様と同じで、書く場所だけを分けている。

## 操作仕様

- すべての入力（キーボードとタッチ）は合成して扱う。左と右が同時に入力されたら打ち消し合って止まる。
- ジャンプは押しっぱなしにすると、着地するたびに再ジャンプする。空中では（通常のジャンプは）跳べない。ただし、壁に接している空中でジャンプを新しく押すと、壁を蹴って跳べる（「ルール」の「プレイヤー」の壁蹴り）。壁蹴り専用の操作は無く、ジャンプ入力（キー・タップ・スティックの上への弾き・2 本目の指）をそのまま使う。
- **新しく押した**: 合成後のジャンプ入力が、前フレームは入っておらず、そのフレームで入っていること（キーの押し始め、2 本目以降の指が 1 本も無い状態から 1 本触れた瞬間、タップのジャンプが始まった瞬間、スティックが「入っていない」から「入っている」になった瞬間）。すでに別のジャンプのキー・指などで入っているときに、別のものを足しても新しく押したことにならない。`playing` の最初のフレームでは、前フレームは入っていないものとする（ただし、離すまで無効の入力は、そもそもジャンプ入力に入らない）。
- タッチは、画面全体が 1 枚のパッドで、左右の区分は無い（画面のどこに触れても同じに効く）。指の役は、触れた時点で決まる（途中で変わらない）。同時に複数の指を扱う（最大 3 点）。
  - **スティックの指**: 何も触れていない（スティックの指が無い）ところに触れた指。同時に 1 本だけ。画面のどこで触れてもよい。
  - **ジャンプの指**: スティックの指がいる間に触れた、2 本目以降の指。触れている間、ジャンプ入力が入る（位置・動きは見ない。スティックの指が先に離れても、その指が離れるまで入ったまま。1 フレームより短く触れて離れた 2 本目の指は、その読み取りの 1 フレームだけジャンプ入力が入る）。
  - **無視される指**: 下記「ゲーム入力として有効になる入力」で無効の指。
- スティックの指は、浮動スティックとして扱う（横の移動と、上へ弾くジャンプ）。スティックの起点 (ax, ay) は最初に触れた位置で始まり、指の現在位置 (px, py) に対して、毎フレーム次の順で決める（y は下向きに増える）。
  1. **起点の追従**: px − ax > STICK_RING_RADIUS なら ax = px − STICK_RING_RADIUS、px − ax < −STICK_RING_RADIUS なら ax = px + STICK_RING_RADIUS（横は両方向に追従し、|px − ax| は STICK_RING_RADIUS を超えない）。py − ay > STICK_RING_RADIUS なら ay = py − STICK_RING_RADIUS（縦は下方向にだけ追従する。上方向には追従しないので、上へ弾く距離は変わらない）。追従は起点を動かすだけで、指の役は変わらない。
  2. **差**: dx = px − ax、dy = py − ay（上へ動かすと dy は負）。
  3. **移動**: dx < −STICK_DEADZONE なら左、dx > STICK_DEADZONE なら右、|dx| ≤ STICK_DEADZONE なら入力なし。
  4. **ジャンプ（弾き）**: スティックごとに「ジャンプ状態」（入っている／入っていない）を持つ。触れた時点は「入っていない」。「入っていない」で dy < −STICK_JUMP_FLICK になったら「入っている」にする。「入っている」で dy ≥ −STICK_JUMP_RELEASE になったら「入っていない」に戻す（その間はそのまま。ヒステリシス）。「入っている」間は、ジャンプ入力が入っている（キーを押しっぱなしにするのと同じ。着地するたびに再ジャンプし、壁蹴りは弾き直し＝「入っていない」に戻してからまた弾いたときだけ）。指を離すとジャンプ状態は消える。
  - 同じフレームの 1.〜4. は、先に起点を動かしてから dx・dy を出す（追従で |dx| が STICK_RING_RADIUS に収まった値で、移動とジャンプを判定する）。
- **タップ**: スティックの指が、次のすべてを満たして離れたとき、離れた瞬間から TAP_JUMP_HOLD 秒の間、ジャンプ入力が入る（離れたことを読み取ったフレームを 0 とし、経過が TAP_JUMP_HOLD に達したフレームで切れる）。壁蹴りにも使える（入った瞬間が「新しく押した」）。ジャンプ入力が入っている途中（接地・空中を問わず、着地をまたぐ場合も含む）は、押しっぱなしと同じ扱い。パルスの途中で次のタップが離れたら、残りは破棄して TAP_JUMP_HOLD 秒に取り直す（延長ではなく取り直し。このとき「新しく押した」にはならない）。
  - **時間の基準**: 純粋なロジックは時刻を持たず、呼び出し側が渡す経過時間 dt（ラウンドの時計と同じ数え方、MAX_DT で頭打ちにしたフレームの経過時間）を足して測る。触れたことを読み取ったフレームを 0 とし、それ以降の各フレームの dt を足す（離れたことを読み取ったフレームの dt も含む）。比較には 1e-9 の許容を入れる（経過 ≤ TAP_MAX_TIME + 1e-9 が「以内」、経過 + 1e-9 < TAP_JUMP_HOLD の間がパルス。壁蹴りの規則と同じ許容）。1 フレームより短いタップの経過は 0 として扱う。
  - 触れてから離れるまでが TAP_MAX_TIME 秒以内（ちょうど TAP_MAX_TIME は含む）。
  - 触れた位置から一度も TAP_SLOP を超えて離れなかった（現在位置と触れた位置の直線距離。ちょうど TAP_SLOP は含む。追従した起点ではなく、触れた位置で測る。一度超えたら、戻しても対象外。測るのは読み取った位置だけで、読み取りの合間の動きは見ない）。
  - その指が触れている間に、ジャンプの指が 1 本も新しく触れなかった（2 本目の指で跳んでいる場合は、タップで重ねて跳ばない）。この指が触れる前からいたジャンプの指は数えない（その指は、スティックの指の役にはならなかった別の指）。
  - 離れるまでに、弾き（4.）でジャンプ状態が「入っている」になったことが無い（弾いた場合は TAP_SLOP を超えているので、これを自然に満たす）。
  - 1 フレームより短いタップ（押して離すまでの間に入力の読み取りが 1 回も無い）も、タップとして数える（実装は押下と解放を取りこぼさずに持つ）。
  - TAP_MAX_TIME を超える長押しや、動かさずに触れたままの指は、何も入力しない。
- ジャンプ入力は「キー」「ジャンプの指」「タップの入力」「スティックのジャンプ状態」の OR で合成する。
- **ゲーム入力として有効になる入力**: `playing` の間に押し始めたキー／触れ始めた指だけ。`playing` が始まった時点で既に押されているキー・触れている指（開始やリトライに使ったもの、結果画面の間に押したものを含む）は、いったん離すまで移動・ジャンプ・スティックの起点にならない（そのような指は、スティックの指がいるかどうかの判定にも、ジャンプの指にも入らない）。
- 開始・リトライの受け付けは「押した瞬間」だけ（キーはキーダウン、タッチは新しく触れた指）。押しっぱなしのキー・指では始まらない。結果画面が出てから RETRY_LOCKOUT 秒は受け付けない。
- 結果画面の「タイトルへ」（ボタン・`T` キー）の受け付けも、リトライと同じく「押した瞬間」だけ（キーはキーダウン、タッチ・クリックは新しく触れた指）で、RETRY_LOCKOUT 秒は受け付けない。新しく触れた指の位置が「タイトルへ」ボタンの矩形（`docs/spec.md` の「Result Scene」）の中なら、その指は「タイトルへ」のもので、リトライにならない（受け付ける時間の前に触れても、リトライにもならず、「タイトルへ」にもならない）。矩形の外で触れた指は、あとから矩形の中へ動いても、リトライのままである。ボタンの上で触れた指・押した `T` キーは、`Title` が始まったあとも、離すまで `Title` の開始（START）にならない（開始は新しく押した指・キーだけ）。
- マウスの主ボタンは 1 本の指として扱う（PC では、クリックがタップ、押したままのドラッグが移動）。ブラウザのキャンセル（ジェスチャーによる中断、ウィンドウの外での解放、タブの非表示）で指が消えたときは、その指が離れたものとして扱い、タップにはしない（ジャンプの指が離れないままジャンプが入りっぱなしにならない）。同じフレームに複数の指が触れたときの先後は、Phaser が渡す指の並び順（入力イベントの到着順）とする。
- 無視される指は、あとからスティックの指・ジャンプの指にならない。スティックの指が離れたらスティックは解除され（ジャンプの指は、離れるまでジャンプの指のまま）、次のスティックの指は、その後に新しく触れて、そのときスティックの指がいなければ、その指になる。同時に扱う指の上限（3 点）は、無視される指も数える。
