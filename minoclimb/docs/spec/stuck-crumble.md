# 閉じ込めの崩れ（stuck-crumble）

## 概要

ミノが穴にふたをして、プレイヤーが上下左右すべて固体で閉じた空間に入ってしまったとき、一定時間のあとに、外へ通じる最短の壁を 1 セルずつ崩して出口を作る。閉じ込められると、潰されも動けもせず、負けるまで見ているだけになるのを防ぐ。壁蹴りで出られる穴は閉じ込めではないので対象外。操作・ルール・着地 AI・数値は変えない。

## 操作仕様

なし（操作は足さない・変えない）。

## 画面・Scene 構成

- 新しい Scene は無い。盤面の描画（`Game`・`Demo` が共有する盤面の描画）に、崩れの予告（対象セルの点滅）が加わる。`Demo`（Title の小窓）にも同じに出る。
- 文字・HUD・音・画面の揺れは足さない。
- **描画順**: 固定されたセル → **崩れの予告** → 固定・行消しの光 → 着地位置の枠 → 予告中／落下中のミノ → プレイヤー（その上は `docs/spec.md` の描画順どおり）。点滅は対象セルの矩形だけを覆う白い塗りで、セルの色の上に重ねる。プレイヤーとミノは点滅より上に描かれる。
- **崩れの予告の見え方**: 対象セル 1 つが点滅する。点滅は、予告の経過時間 t（秒）に対し、不透明度の係数 `blink(t) = (1 + cos(2π × (CRUMBLE_BLINK_HZ_START × t + (CRUMBLE_BLINK_HZ_END − CRUMBLE_BLINK_HZ_START) × t² / (2 × CRUMBLE_TIME)))) / 2`（0〜1）で決まる。点滅の速さが、START_HZ から END_HZ まで直線的に上がる（消える直前ほど速い）。塗りの不透明度は、この係数に最大の濃さ（実装裁量）を掛けたもの。
- **結果の間**: ラウンドが終わると（`Result` が出る）、予告は止まった瞬間の経過時間のまま描く（点滅も止まる）。リトライで `Game` を作り直したとき、予告は残らない。

### 状態遷移（`Round` の閉じ込めの状態）

| 局面 | 内容 | 次へ |
|---|---|---|
| 開いている | 閉じ込められていない。`sealedFor` = 0。予告なし | 閉じ込められたフレームから「数えている」 |
| 数えている | 閉じ込められている間、`sealedFor` が増える。予告なし | `sealedFor` が STUCK_TIME に達したフレームで「予告中」 / 開いたら「開いている」 |
| 予告中 | 対象セルが点滅する。経過時間 `t` が増える | `t` が CRUMBLE_TIME に達したフレームで対象セルが消え、`sealedFor` = 0 で「数えている」（まだ閉じ込められていれば）または「開いている」 / 開いたら「開いている」（予告は取り消す） |

## ルール

### 閉じ込めの判定

- **プレイヤーのセル**: 列 = floor(x + PLAYER_W / 2)（盤面の内側に収める）、行 = floor(y + PLAYER_H / 2)（体の中心のセル）。体の中心の行が 0 より上（行 < 0）なら、閉じ込められていない。
- **空間**: プレイヤーのセルから、空きセル（固体でないセル。盤面の左右の外・最下段の下は固体）を上・下・左・右にたどって届くセルの集まり。斜めには進まない。幅 1 セルの隙間にもプレイヤー（PLAYER_W = 0.7、PLAYER_H = 0.9）は入るので、セル単位の判定でよい。
- **閉じ込められた**: 空間が行 0 の空きセルを 1 つも含まない（盤面の上に開いていない）。行 0 の空きセルは、その上が何も無い空間（天井が無い）につながっているので「開いている」。プレイヤーのセルが固体のとき（起こらないはずの状態）は閉じ込められていない扱い。
- 判定は、1 フレームの最後（プレイヤーの更新・ミノの進行・行消しのあと）の盤面とプレイヤーの位置で行う。

### 時間

- 閉じ込められたフレームごとに `sealedFor` に dt（MAX_DT で頭打ちにしたもの）を足す。閉じ込められていないフレームでは `sealedFor` = 0（予告も取り消す）。ミノの固定・行消しでは `sealedFor` をリセットしない（閉じ込めが続く限り数える）。
- `sealedFor` + 1e-9 ≥ STUCK_TIME になったフレームで予告を始める。そのフレームを t = 0 とする（そのフレームで対象セルを決める）。以降、閉じ込めが続く各フレームで t に dt を足す。
- t + 1e-9 ≥ CRUMBLE_TIME になったフレームで、対象セルを消す（盤面のそのセルを空にする）。`sealedFor` = 0 にして、予告を終える。消えたフレーム自身では `sealedFor` に dt を足さない（0 のまま）。次のフレームでまだ閉じ込められていれば、そのフレームから `sealedFor` を数え直す（STUCK_TIME → 予告 → 消える、を繰り返す。1 サイクルは 60fps で 180 フレーム）。
- 60fps（dt = 1/60）で、閉じ込められたまま続くと、閉じ込められた最初のフレームを 1 として、60 フレーム目に予告が始まり（t = 0）、180 フレーム目に対象セルが消える。
- 崩れは乱数を使わない。`Round` の乱数の消費は崩れの有無で変わらない（着地 AI の選択・ミノの種類の並びは同じ）。

### 対象セル

- **費用**: 盤面のセル（左右の外・最下段の下は含めない）から「外」まで、上・下・左・右にたどる経路で、通る固体セルの数（そのセル自身を含む）。「外」とは、空間に含まれないすべての空きセル（行 0 に届かない、別に閉じた空きも含む）と、盤面の上（行 0 より上）。空きセルを通るのは費用 0。経路は空間のセルを通らない。行 0 の固体セルは、その上が何も無いので、それ自身の費用 1 で外に出られる。別に閉じた空きにつながっただけでは出口にならないことがあり（例 B）、その場合は次の予告で続きを崩す。
- **候補**: 空間のセルに上下左右で接している固体セル。そのうち、費用が最小のものを選ぶ。
- **同点の決め方**（上ほど優先）:
  1. プレイヤーの足元を支えるセルでないもの。足元を支えるセルとは、`onGround` のとき、足の下端の直下の行（floor(y + PLAYER_H + GOAL_TOL)）にある、体の横の範囲（floor(x) 〜 floor(x + PLAYER_W − 1e-6) の列）の固体セル。空中では無し。
  2. 行番号が小さい（高い）セル。
  3. 列番号が小さいセル。
- 消えたあとにまだ閉じ込められているときは、次の予告で、そのときの盤面から対象を選び直す（1 セルずつ繰り返す）。外につながったら終わる。
- **ミノの固定・行消しでの追従**: 予告中に行が消えたら、対象セルの行を、その対象セルより下の消えた行の数だけ下げて、同じセルを追う。対象セルの行そのものが消えたら、予告を取り消して、そのフレームの盤面で対象を選び直し、t = 0 から予告をやり直す（`sealedFor` は STUCK_TIME 以上のまま）。
- **予告中に開いたら**: 閉じ込められなくなったフレームで、予告を取り消し、`sealedFor` = 0 に戻す。

### 同じフレームの処理順

プレイヤーの更新 → ミノの進行（潰れ・固定・積み上がりすぎ・行消し。行消しがあれば対象セルを追従させる）→ クリア判定 → **崩れの進行**（上の閉じ込めの判定・時間・対象セル）。ラウンドが終わったフレーム（潰れ・積み上がりすぎ・クリア）では、崩れを進めない（予告は直前の状態のまま止まる）。

### 手計算の例（ROWS = 20、行 19 が最下段。左右の外と最下段の下は固体）

例の盤面は、判定と対象選びの純粋関数に格子を直接渡す入力である（満杯の行があるが、行消しは適用しない。`Round` を通して作る盤面ではない）。

- **例 A（天井が最短）**: 行 14 以上はすべて空き。行 15〜19 は、列 4・5 の行 16〜19 だけが空きで、あとはすべて固体（列 4・5 の行 15 がミノのふた）。プレイヤーは列 4 の行 19 に立つ。空間は列 4・5 の行 16〜19 で、行 0 の空きに届かないので、閉じ込められている。候補の費用: (4,15) = 1（上の (4,14) は空き）、(5,15) = 1、(3,16) = 2（(3,15) を通ってから (3,14) の空き）。最小は費用 1 の (4,15) と (5,15)。足元を支えるセルは無く（最下段に立っている）、行も同じなので、列の小さい (4,15) が消える。消えると、(4,14) の空きにつながり、閉じ込めでなくなる。
- **例 B（足元を避ける）**: 行 14 以上はすべて空き。行 15・16 はすべて固体。行 17 は列 4・5 だけが空きで、あとは固体。行 18 はすべて固体。行 19 は列 4・5 だけが空きで、あとは固体（この空きは別に閉じた空間）。プレイヤーは x = 4.15（体は列 4 だけ）で、(4,18) の上に立つ（y = 17.1）。空間は (4,17)・(5,17) で、閉じ込められている。費用: (4,18) = 1（下の (4,19) が空き）、(5,18) = 1（下の (5,19) が空き）、(4,16) = 2（(4,16)・(4,15) を通って (4,14) の空き）、(5,16) = 2、(3,17) = 3。最小は (4,18) と (5,18)。(4,18) は足元を支えるので避けて、(5,18) が消える（足元を避けないと、行も同じなので列の小さい (4,18) が選ばれる）。消えたあとは (5,19)・(4,19) の空きとつながるが、その空間は別に閉じているので、まだ閉じ込められている。`sealedFor` を 0 から数え直して、次の予告に進む。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| STUCK_TIME | 1 | 閉じ込められてから予告を始めるまで（秒）。ミノが落ちた直後などの一瞬の閉じ込めで画面がちらつかないための間。小さいほど出口が早くできる |
| CRUMBLE_TIME | 2 | 予告（対象セルの点滅）の長さ（秒）。この間に消えるセルが分かる。合計 STUCK_TIME + CRUMBLE_TIME = 3 秒で 1 セル消える |
| CRUMBLE_BLINK_HZ_START | 2 | 予告の始めの点滅の速さ（回/秒） |
| CRUMBLE_BLINK_HZ_END | 8 | 予告の終わりの点滅の速さ（回/秒）。(START + END) / 2 × CRUMBLE_TIME = 10 回で、消える瞬間に最も明るい |

統計の数え方（目安とテスト観点の「統計（模擬）」で共通）: 「閉じ込めの時間の割合」は、1 走りごとに「閉じ込められていたフレームの数 ÷ 走りのフレーム数」を出し、60 走りの平均を取る。「閉じ込めの回数」は、閉じ込めの判定が偽 → 真に変わった回数の 60 走りの合計。「崩れの合計」は、消えたセルの数の 60 走りの合計。クリアは `Round` の状態が `cleared` で終わった走りの数。

実測（ボットの模擬。60 シード、デモのボット、1/60 秒刻み、上限 300 秒。閉じ込めはフレームの最後の盤面で判定。実装で測った）: 崩れなしで閉じ込められた走りが 7 / 60（回数も 7。7 走りとも最後まで開かない）、閉じ込めの時間の割合の平均 4.73%、クリア 11。崩れありで割合の平均 2.65%、閉じ込めの回数 20（開いたあとに再び閉じ込められたものを含む）、崩れの合計 41 セル、クリア 11 のまま（このボットは開いたあとの深い穴から自力で出られないため）。閉じ込めの起きなかった 53 走りは、崩れの有無で終わるフレーム・状態・到達高さがすべて一致した。

## テスト観点

純粋ロジックの単体テスト（境界値を含む）:

- **閉じ込めの判定**: 行 0 の空きに届く空間は閉じ込めでない。ふた（ミノ）で行 0 に届かない空間は閉じ込め。幅 1 セルの隙間も判定できる。斜めにしか届かない空きは届かない扱い（上下左右だけ）。体の中心の行が 0 より上のときは閉じ込めでない。
- **時間（60fps、dt = 1/60）**: 閉じ込められた 59 フレーム目までは予告なし、60 フレーム目に予告が始まる（t = 0）、179 フレーム目まで対象セルは残り、180 フレーム目に消える。消えた次のフレームでまだ閉じ込められていれば `sealedFor` が 1/60 から数え直される。dt が MAX_DT で頭打ちになる大きいフレームがあっても、dt の合計で数える。途中のフレームで閉じ込めでなくなったら、`sealedFor` が 0 に戻り、予告が取り消される（次に閉じ込められたら 0 から）。
- **対象セルの選び方**: 例 A は (4,15) が消える。例 B は (5,18) が消える（足元を避ける）。足元を避けないと (4,18) になることを、足元の判定を外した比較で確かめる。費用が同じで行が違うときは行の小さいほう。行も同じなら列の小さいほう。対象セルが固体でないこと（空きセルを選ばない）、盤面の外（左右・最下段の下）を選ばないこと。経路が別の閉じた空間を通る場合の費用。
- **追従**: 予告中に、対象セルより下の行が消えると、対象セルの行がその数だけ下がり、同じセルが消える。対象セルの行が消えたら、予告をやり直す（t = 0、対象を選び直す）。ミノの固定では `sealedFor` が変わらない。
- **点滅の係数**（CRUMBLE_TIME = 2、START = 2、END = 8）: t = 0 で 1、t = 0.5 で約 0.146、t = 1 で 0、t = 2 でちょうど 1。t が増えるほど点滅が速い（隣り合う山の間隔が短くなる）。
- **乱数と回帰**: 崩れの有無で `Round` の乱数の消費が同じ（シード固定の走りで、閉じ込めの起きない走りは、終わるフレーム・状態・到達高さが一致する）。
- **終わったラウンド**: 潰れ・積み上がりすぎ・クリアのフレームで、崩れが進まない（予告も消えない）。
- **統計（模擬）**: `Round` に対して、デモのボット（`demoBot`）の入力だけで、シード 1〜60 の 60 回、1/60 秒刻み、上限 300 秒。閉じ込めの判定は、上の閉じ込めの判定そのもの。崩れなし（テスト専用に崩れを無効にする）と崩れありを比べ、次を満たす: 崩れありの「閉じ込めの時間の割合」の平均が、崩れなしより小さい（実測 4.73% → 2.65%）、崩れの合計が 1 以上（実測 41）、崩れなしで閉じ込められた走りが 1 走り以上（実測 7、空振りの検査）、クリアの数が崩れなし以下にならない（実測 11 → 11）、閉じ込めの起きなかった走り（実測 53）の結果が崩れの有無で一致する。クリアが崩れなしを下回ったときは、原因を確かめてから閾値を決める（そのまま値を緩めない）。
- **デモ**: 「デモのボットは蹴らない」（`docs/spec.md` の壁蹴りの統計）の、壁蹴りが無い物理との比較は、崩れがあっても（両方に崩れが入っているので）一致する。デモの品質のしきい値（`docs/spec/title-demo.md`）は保たれる。
- **壁蹴りの統計**（`docs/spec.md` の「壁蹴りの統計（模擬）」）は、崩れが入っても、囲まれている時間の割合の平均 10% 以下、クリア 20 回以上、空振りの検査を満たす。

Scene / 統合（必要最小限）:

- 予告中の対象セルが盤面の描画で点滅し、消えたあとは描かれない。`Demo` でも同じに出る。ラウンドが終わったとき、予告は止まった状態で、リトライで残らない。

- 閉じ込められると、STUCK_TIME のあとに CRUMBLE_TIME だけ対象セルが点滅し、消える。外につながるまで、1 セルずつ繰り返す。例 A・例 B のとおりのセルが選ばれる。
- 崩れの統計（テスト観点の「統計（模擬）」の閾値）と、閉じ込めの起きない走りの一致（乱数の消費を含む）を満たす。

## 実装裁量

- 点滅の塗りの色と最大の濃さ（白に近い色で、セルの上で見分けられること）。
- 閉じ込めの判定・費用の計算の実装方法（塗りつぶしと 0-1 幅優先探索、など。結果が上の規則と同じなら何でもよい）と、ファイル名・関数名・状態の持ち方（`Round` が持つか、別のオブジェクトか。描画側が読める形にする）。
- テスト専用に崩れを無効にするオプションの形（比較の基準を作るためだけに使う）。
- QA で閉じ込めの盤面を作る dev 専用の手段（既存の `window.__qa` に足すか、別の dev 専用のフックにするか。いずれも本番の bundle に残さない）。
