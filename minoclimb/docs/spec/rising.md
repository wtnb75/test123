# せり上がり（rising）

`docs/spec.md` の一部。ステージ 2 以降で、盤面の下から行がせり上がる規則を、独立して書いたもの。パラメータ名と節名は `docs/spec.md` のものを指す。`docs/spec.md` と合わせて 1 つの spec である。

## 概要

ステージ 2 以降（`stage` ≥ RISE_FROM_STAGE）では、一定の間隔ごとに、盤面の下から穴が 1 列だけ空いた行が 1 行ぶんせり上がり、積み重ねとプレイヤーを押し上げる。待てば足場ができる、という今までの遊び方が通用しなくなり、登り続ける判断が要る（コアループを深める）。ステージ 1 と `Demo`（Title の小窓）は今までのまま。操作は足さない・変えない。

## 操作仕様

なし（操作は足さない・変えない）。

## 画面・Scene 構成

- 新しい Scene は無い。`Game` の盤面の描画に、せり上がりの合図（盤面の下端の三角の点滅）と、せり上がった行の光が加わる。`Demo` は `Round` をせり上がり無しで動かすので、どちらも出ない。
- 文字・HUD の変更・音・画面の揺れは足さない。HUD の「高さ」の定義は変えない（下の「HUD」）。
- **描画順**（`docs/spec.md` の「論理サイズとレイアウト」の順の中で）: 固定されたセル → 崩れの予告 → **せり上がりの合図** → 固定・行消しの光と**せり上がりの光**（同じ層。2 つの光どうしの上下は実装裁量） → 着地位置の枠 → 予告中／落下中のミノ → プレイヤー → HUD ほか。合図と光はプレイヤーより下に描かれる。
- **セルの色**: せり上がった行のセル（値 RISE_CELL）は、7 種のミノのどの色とも見分けられる 1 色（実装裁量。灰色など）で描く。以後は普通のセルと同じに扱う（行消しで消え、下がり、崩れの対象になる）。

### せり上がりの合図（見え方）

- 表示する条件: せり上がりのタイマー `riseElapsed`（下の「ルール」の「タイマー」）が `RISE_INTERVAL − RISE_WARN_TIME` 以上（1e-9 の余裕を持たせる）の間。期限（`RISE_INTERVAL`）を過ぎて、ミノの固定を待っている間も出し続ける。せり上がったフレームで消える（`riseElapsed` = 0 に戻る）。
- 形: 盤面の下端（最下段の下端）に沿って、全 COLS 列の各列の中央に、上向きの二等辺三角形を 1 つずつ（底辺 RISE_MARK_W セル・高さ RISE_MARK_H セル。底辺は盤面の下端に接する）。実寸（FIT 後）の高さは、375 × 550 と 390 × 844 で 10 px 以上（約 13.8 px と 18 px 弱）。667 × 310 では約 7.7 px になるが、盤面全体が同じ縮小率で縮み（論理サイズは固定）、この合図は補助の手がかり（期限は盤面の下端の動きでも分かる）なので、許容する。
- 点滅: t = max(0, `riseElapsed` − (`RISE_INTERVAL` − `RISE_WARN_TIME`) + 1e-9)（合図が出始めたフレームで t = 0。浮動小数点の誤差で t が負にならないための下限と余裕）とし、floor(t × 2 × RISE_BLINK_HZ) が偶数の間は「点」、奇数の間は「消」（t = 0 から 1 / (2 × RISE_BLINK_HZ) 秒は点。RISE_BLINK_HZ = 4 なら、0〜0.125 秒が点、0.125〜0.25 秒が消）。期限を過ぎて待つ間も t は数え続ける（リセットしない）。三角は全列が同時に点滅する。
- 色は、盤面の背景と、7 種のミノ・せり上がりのセルの上で見分けられる色（実装裁量）。入力は妨げない。
- **結果の間**: ラウンドが終わると（`Result` が出る）、合図は止まった瞬間の t のままで描く（点滅も止まる）。リトライ・次のステージへで `Game` を作り直したとき、合図は残らない。

### せり上がりの光

- きっかけ: せり上がったフレーム（`Round` が返す「出来事」に、せり上がった、が入る）。そのフレームを t = 0 とし、最下段（行 ROWS − 1）の空きでない各セル（穴のセル以外）に、白に近い色の光を重ねる。光の不透明度は、固定・行消しの光と同じ時間規則: t = 0 で最大、t = RISE_FLASH_TIME でちょうど 0（それ以降は描かない）、間は単調に減る（曲線は実装裁量）。
- せり上がりのフレームに、固定の光・行消しの光も出ているときは、重ねて出す（それぞれ別に数える）。そのフレームの固定の光のセル・行消しの光の帯は、せり上がったあとの盤面の座標（行 − 1）に出す（光が盤面と 1 行ずれない）。光の最中にもう一度せり上がることは無い（RISE_INTERVAL > RISE_FLASH_TIME）。
- 光が終わるとき: 光が透明になったら。クリアまたはゲームオーバーで切る（固定の光・行消しの光と同じ。[演出・UI](effects.md)）。リトライ・次のステージへで `Game` を作り直したとき、光は残らない。せり上がりでゲームオーバー（積み上がりすぎ）になったフレームでは、せり上がった出来事は返さず、光は出ない。

## ルール

### ステージと有効化

- せり上がりは、`stage` ≥ RISE_FROM_STAGE のとき有効（ステージ 2 以降はすべて同じ規則。ステージごとの違いは足さない）。`stage` = 1 と `Demo` では、せり上がりは起きず、`Round` の走りは今までと同じ（盤面・ミノの並び・着地 AI の選択・乱数の消費・終わるフレームと状態・到達高さ）。
- 受け渡し: `Game` は `stage` から「せり上がりが有効か」を決めて `Round` に渡す（`RoundOptions.rising`。`Demo` は渡さない = 無効）。`Round` は `stage` の番号そのものは知らない。
- 乱数: 穴の列を決める乱数源 `riseRng` は、盤面の乱数（`Round` の `rng`）とも `swayRng` とも別（`RoundOptions.riseRng`。ゲームは `Math.random`、テストと計測は固定の列）。せり上がりが有効でも、`rng` の消費は変わらない（着地 AI の選択・ミノの種類の並びは、せり上がりの有無で同じ）。

### タイマー

- `riseElapsed`（秒）を持つ。ラウンドの開始（`playing` の開始）で 0。`Round` の更新ごとに dt（MAX_DT で頭打ちにしたもの）を足す（予告・落下・SPAWN_DELAY のどの間も数える）。せり上がったフレームで 0 に戻す（そのフレーム自身には dt を足し直さない。余りは持ち越さない）。ラウンドが終わったら進めない。
- **期限**: `riseElapsed` + 1e-9 ≥ RISE_INTERVAL になったフレームから、せり上がりの「期限が来た」状態。期限が来ても、すぐには上がらず、次の「ミノの固定」まで待つ（下）。

### せり上がる時機

- 期限が来ているとき、**ミノが固定され、そのフレームの行消しが済んだ直後**（同じフレームの中、「1 個のミノの流れ」の 4 のあと）に、1 回せり上がる。予告中・落下中には上がらない（着地行・予告の枠は、せり上がりで無効にならない）。
- そのフレームでゲームオーバーになる（潰れ、または固定による積み上がりすぎ）ときは、せり上がらない（ゲームオーバーが先）。
- 期限が来たフレーム自身にミノが固定されるなら、そのフレームでせり上がる（期限の判定が先）。期限が来ていないとき（`riseElapsed` が RISE_INTERVAL 未満）の固定では、せり上がらない。
- せり上がっても、SPAWN_DELAY の数え方・次の予告の始まり・着地 AI は変わらない（固定のフレームから SPAWN_DELAY 後に次の予告。そのときの盤面（せり上がったあと）で着地 AI が決める）。

### せり上がりの手順（1 回ぶん）

同じフレームの中で、次の順に行う。

1. **盤面を 1 行ぶん上げる**: すべての行を 1 行上へ動かす（行 r の内容が行 r − 1 へ。行 0 の内容は盤面の外へ出て失われる）。最下段（行 ROWS − 1）は、`riseRng` で決めた穴の列 h（h = floor(riseRng() × COLS)。riseRng は 0 以上 1 未満を返す。1 回のせり上がりで 1 回だけ引く）だけが空きで、ほかの列は値 RISE_CELL のセルで埋める。行消しはこの時点では行わない（せり上がった行は、次のミノの固定のときの行消しで、普通の行として揃えば消える）。
2. **積み上がりすぎの判定**: 上げたあとの盤面で、行 `TOP_OUT_ROW` より上（行 0〜`TOP_OUT_ROW − 1`）に空きでないセルがあれば、「積み上がりすぎ」でゲームオーバー（`docs/spec.md` の既存のゲームオーバーの条件と同じ種類として扱い、結果画面の敗因の文言も同じ）。このとき、手順 3 以降は行わない（プレイヤーは押し上げない。上がった積み重ねに体が重なった絵が結果画面に残ってよい。`riseElapsed` もそのまま止まり、合図は止まった状態で描く）。ゲームオーバーのとき盤面に残る描画は、上げたあとの盤面（行 0 より上に出たセルは描かない）。このフレームの固定・行消しの出来事は、せり上がりの有無によらず通常どおり返す（光の扱いは `docs/spec/effects.md` の既存の規則のまま。ゲームオーバーのフレームでは光を出さない）。
3. **プレイヤーを押し上げる**: 上げたあとの盤面に対して、プレイヤーの長方形が固体セルと重なっていれば、重ならなくなる最小の量だけ上へ動かす。
   - 重なりの判定は、行消しとプレイヤーの規則（`docs/spec.md` の「1 個のミノの流れ」の 4）と同じ: 厳密な不等号（辺が接するだけなら重ならない）。許容値 GOAL_TOL は使わず、浮動小数点の誤差を吸収する 1e-6 程度の内部の微小値だけ使ってよい。
   - 動かす量 d（セル）は、重なっているすべての固体セルについて、「プレイヤーの足の下端 − そのセルの上端」の最大値（重なっていなければ 0）。上げる前にプレイヤーが重なっていなかったので、d は 0 以上 1 以下になる（積み重ねとプレイヤーが一緒に 1 行上がっても、体と積み重ねの位置関係は保たれる）。
   - 動かすのは位置の縦だけ。水平位置・速度（vx・vy）・`onGround`・壁蹴りの記憶（直前に蹴った壁の側・戻れない側・蹴りの経過時間）は変えない。上へ動かして行 0 より上へ出ても、そのままでよい（天井は無い）。
4. **閉じ込めの崩れの追従**: 予告中の崩れの対象セルは、1 行上へ動かして同じセルを追う（`sealedFor`・経過時間 t は変えない。[閉じ込めの崩れ](stuck-crumble.md)）。
5. **出来事**（手順 2 でゲームオーバーにならなかったときだけ）: そのフレームの `Round` の結果に、せり上がった、を入れる（光のきっかけ。穴の列 h も返す）。`riseElapsed` を 0 に戻す。

### 同じフレームの処理順

プレイヤーの更新（ゴール到達を覚える）→ ミノの進行（潰れ・固定・積み上がりすぎ・行消し）→ **せり上がり（期限が来ていて、このフレームでミノが固定され、ゲームオーバーでないとき）** → クリア判定（プレイヤーの更新で覚えた到達だけで決まる）→ 崩れの進行（ラウンドが続いているときだけ）。

- せり上がりでプレイヤーが上へ動いてゴールの高さに届いても、そのフレームではクリアにならない。次のフレームのプレイヤーの更新で、足の位置が `y + PLAYER_H ≤ GOAL_ROW + GOAL_TOL` なら到達を覚え、そのフレームのクリア判定でクリアになる（押し上げられて届いたときも、クリア）。
- せり上がりの積み上がりすぎは、ゲームオーバー。同じフレームで覚えたクリアの到達（プレイヤーの更新で覚えたもの）があっても、ゲームオーバーを優先する（既存の「ミノの進行でゲームオーバーの条件が成立したら、クリア条件が同時に成立していてもゲームオーバー」と同じ）。

### 着地 AI

- 評価の式・数値・乱数の使い方・空け列は変えない（`docs/spec.md` の「着地 AI」のとおり）。せり上がった行（RISE_CELL）は、普通の積み重ねのセルとして、穴・凸凹・行が揃うかの評価に入る。AI はせり上がりの時機を考慮しない。

### HUD

- 「高さ」の定義は変えない（`docs/spec.md` の「HUD」: 足の下端の位置から決まる絶対の高さ。ゴール判定と同じ基準）。せり上がりで押し上げられて足が上がれば、高さの表示も上がる。「到達した最大の高さ」は、`playing` 中の全フレームの n の最大値のまま（押し上げられた高さも入る）。

## テスト観点

純粋ロジックの単体テスト（境界値を含む。乱数は注入する）:

- **盤面を上げる**: 空の盤面で、最下段が「穴の列 h だけ空き、ほかは RISE_CELL」になる。盤面の途中のセルは 1 行上へ動く（行 r → r − 1）。穴の列 h は `riseRng` の値から floor(値 × COLS) で決まる（0 → 列 0、0.999… → 列 COLS − 1、0.5 → 列 5）。`riseRng` は 1 回のせり上がりで 1 回だけ引かれる。
- **積み上がりすぎ**: 上げる前に行 `TOP_OUT_ROW`（= 2）にセルがあれば、上げたあと行 1 になって「積み上がりすぎ」。行 3 のセルは行 2 になるので、積み上がりすぎにならない（境界）。行 0 のセルは盤面の外へ出るが、その前に積み上がりすぎになっている。積み上がりすぎのとき、プレイヤーの押し上げ・出来事は行わず、結果は積み上がりすぎのゲームオーバー。
- **押し上げの量**（PLAYER_W = 0.7、PLAYER_H = 0.9、x = 4.65 で体は列 4・5 の範囲。上げたあとの盤面で）: ①床に立っている（足の下端 20.0、y = 19.1）。最下段の列 4・5 が RISE_CELL（穴は列 0）で重なるので、d = 20 − 19 = 1、y = 18.1。②穴が列 4（体は列 4・5）でも、列 5 のセルと重なるので d = 1。③穴が列 4 でプレイヤーが x = 4.05（体は列 4 だけ。4.05 〜 4.75）のとき、列 4 は空きなので、重ならず d = 0（穴に立っているままで、押し上げない）。④空中で足の下端が 17.5（y = 16.6）、上げる前に行 18 の列 4 にセル（上端 18.0。接していないので、上げる前は重ならない）。上げたあと、そのセルは行 17（上端 17.0）になり、足の下端 17.5 と 0.5 重なるので、d = 0.5、y = 16.1（足の下端 17.0）。⑤同じで足の下端が 17.0 ちょうど（y = 16.1）なら、重ならず（辺が接するだけ）d = 0。足の下端が 16.9 でも d = 0。⑥プレイヤーが積み重ねの上に立っていて足の下端がセルの上端に接している（上げる前の足の下端 = 18.0）なら、上げたあとそのセルの上端が 17.0 で、足の下端 18.0 − 17.0 = 1 重なるので d = 1（足の下端 17.0 で、積み重ねの上に立ったまま）。⑦押し上げても、vy・`onGround`・x・壁蹴りの記憶・戻れない側は変わらない。行 0 より上（y < 0）へ出ても落ちない（クランプしない）。
- **時機（60fps、dt = 1/60、ステージ 2 相当の `Round`、プレイヤーの位置と入力は何も影響しない）**: ①`riseElapsed` は 720 フレーム（12.0 秒）で期限が来る（RISE_INTERVAL = 12。浮動小数点の誤差は 1e-9 の余裕で吸収し、719 フレームでは来ない）。②期限が来たフレームより前にミノが固定されても、せり上がらない。③期限が来ているあいだに（フレーム 720 以降）最初にミノが固定されたフレーム（行消しがあればそのあと）で、1 回だけせり上がる。期限が来たフレーム自身の固定でも上がる。④予告中・落下中のフレーム（固定でないフレーム）では、期限を過ぎていても上がらない。⑤せり上がったフレームで `riseElapsed` = 0。次のフレームで 1/60。その 720 フレーム後（せり上がったフレームの 720 フレーム後）に次の期限が来る。⑥期限が来ている状態で固定したフレームが、潰れまたは固定による積み上がりすぎなら、せり上がらず（`riseElapsed` と期限は変わらない。ラウンドは終わっている）。⑦固定のフレームに行消しがあれば、行消しが先で、そのあとにせり上がる（消えた行の分下がった盤面が、さらに上がる）。⑧せり上がったフレームからも、SPAWN_DELAY 後に次の予告が始まる（固定のフレームから数える）。
- **有効化**: `rising` が無効の `Round`（ステージ 1・`Demo`）は、何秒たってもせり上がらない。有効な `Round` で `riseRng` を空の列（呼ばれたら失敗する関数）にしても、期限前は呼ばれない。
- **乱数の独立**: 1 個のミノあたりの `rng` の呼ばれ方（種類 1 回、続けて着地 AI の u1・u2。`docs/spec.md` の「着地 AI」）は、せり上がりの有無・`riseRng` の値によらず同じ順序（せり上がると盤面が変わるので着地 AI の選ぶ位置は変わりうる。同じ盤面なら、`riseRng` の値を変えても、選ぶ位置と `rng` の呼ばれ方は同じ）。せり上がりの処理そのものは `rng` を引かない。
- **ゴール**: プレイヤーが床に立ち、せり上がりで押し上げられて足の下端が `GOAL_ROW + GOAL_TOL` 以下になったとき、せり上がったフレームではクリアにならず、次のフレームでクリアになる。同じフレームに積み上がりすぎが成立したら、ゲームオーバー。
- **閉じ込めの崩れ**: 予告中の対象セルが、せり上がりで 1 行上へ動いて同じセルを追う（`sealedFor`・t は変わらない）。
- **着地 AI**: せり上がりのある盤面でも、`rankPlacements` の式・数値が変わらない（RISE_CELL のセルを含む盤面を、通常のセル（1〜7）に置き換えた盤面と、同じ評価点になる）。
- **HUD の高さ**: 押し上げで足が 1 セル上がれば、高さの表示が 1 上がる（`docs/spec.md` の HUD の式のまま）。
- **合図の表示規則**（純粋な関数: `riseElapsed` から「出すか・点か消か」を返す）: `riseElapsed` = 9.999 は出さない、10.0 ちょうど（RISE_INTERVAL − RISE_WARN_TIME = 10。1e-9 の余裕を含む）で出す（t = 0 は「点」）。60fps で `riseElapsed` を 600 回（1/60 秒）足した値（浮動小数点で 10 よりわずかに小さくなりうる）でも、600 フレーム目に出て、t = 0 の「点」になる。t = 0.124 は点、0.125 ちょうどは消、0.249 は消、0.25 は点（RISE_BLINK_HZ = 4）。期限を過ぎた（12.0 以上）ときも、t が続く（t = 2.0 は点: floor(2.0 × 8) = 16 は偶数）。せり上がったフレームで `riseElapsed` = 0 になり、出さない。
- **光の時間規則**: t = 0 で最大、RISE_FLASH_TIME でちょうど 0、間は単調に減る。きっかけは、せり上がったフレームだけ。
- **回帰の対応**: 結果画面の文言・位置は `docs/spec/result-screen.md`、HUD・見出しの文言は `docs/spec/stages.md`、操作・入力は `docs/spec/touch-input.md` の既存のテスト観点が、変更なしで通る。スコア無しの方針は、テストでなく完了条件の確認事項。
- **回帰（変えないもの）**: ステージ 1 と `Demo` で、同じシード・同じ入力の走り（盤面・ミノの並び・着地 AI の選択・乱数の消費・終わるフレームと状態・到達高さ）が、今までと一致する（せり上がり無効の `Round` を、せり上がりを足す前の実装と比べた結果と同じ。実装で足したオプションが無効なときの回帰テスト）。デモのボットの品質のしきい値（`docs/spec/title-demo.md`）、壁蹴りの統計・崩れの統計・着地 AI の統計（それぞれの spec）は、せり上がり無効の走りで変わらず満たす。既存の単体テストは、変更なしで通る（`docs/spec/stages.md` の「`stage` からせり上がりの有効化への変換」の追加分を除く）。
