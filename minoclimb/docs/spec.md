# minoclimb（仮称。画面表示名は MINOCLIMB）

## コンセプト

普通のテトリスの盤面（10×20）にミノが 1 個ずつ降ってくる。プレイヤーは小さなキャラを操作し、落ちてくるミノを避けながら、積もったミノを登って上端近くのゴールラインに足を届かせるアクション。一列揃うとその行は消え、足場も一緒に下がる。ミノは足場であり脅威でもある。

## ターゲットプレイヤー

数十秒〜数分で 1 回遊べるカジュアルなアクションが好きな人。テトリスのミノの形を知っている人。PC（キーボード）とスマホ（タッチ）の両方で遊ぶ。

## コアループ

1. 上に現れたミノが回転しながら着地位置（枠）を予告する。予告を見て、落ちてくる列から逃げる。
2. 予告が終わるとミノが一気に落ちて積もる。積もった段差にジャンプで乗り、高さを稼ぐ。
3. 行が揃って消えると足場が下がる。足場を保ちつつ登り、ゴールラインに足を届かせる。

## 操作仕様

プレイヤーが操作するのはキャラだけ。ミノは操作できない。

| 操作 | キーボード | タッチ |
|---|---|---|
| 左へ移動 | ← / A | 画面の左半分に触れ、触れた位置から左へ STICK_DEADZONE を超えてドラッグ |
| 右へ移動 | → / D | 画面の左半分に触れ、触れた位置から右へ STICK_DEADZONE を超えてドラッグ |
| ジャンプ | ↑ / W / スペース | 画面の右半分のどこかを押す |
| 開始（ready 中） | スペース / Enter | 画面をタップ |
| リトライ（結果画面） | R / スペース | 画面をタップ |

- すべての入力（キーボードとタッチ）は合成して扱う。左と右が同時に入力されたら打ち消し合って止まる。
- ジャンプは押しっぱなしにすると、着地するたびに再ジャンプする。空中では跳べない。
- タッチの左半分・右半分は、画面の論理幅（`COLS × CELL` px）の中央で分ける（x < 論理幅 / 2 が左、それ以外が右）。区分は、指を最初に置いた位置で決まる（左半分で触れた指は、右半分へ動いても左のスティックのまま）。同時に複数の指を扱う（最大 3 点）。
- 左半分のタッチは、最初に触れた位置を起点にした横方向だけのスティックとして扱う。起点からの横方向の差 dx が −STICK_DEADZONE 未満なら左、STICK_DEADZONE を超えれば右、|dx| ≤ STICK_DEADZONE なら入力なし。指を離すまで起点は動かない。縦方向は見ない。左半分に複数の指があるときは、最初に触れた指だけをスティックとし、他は無視する。右半分は 1 本以上の指があればジャンプ。
- **ゲーム入力として有効になる入力**: `playing` の間に押し始めたキー／触れ始めた指だけ。`playing` が始まった時点で既に押されているキー・触れている指（開始やリトライに使ったもの、結果画面の間に押したものを含む）は、いったん離すまで移動・ジャンプ・スティックの起点にならない。
- 開始・リトライの受け付けは「押した瞬間」だけ（キーはキーダウン、タッチは新しく触れた指）。押しっぱなしのキー・指では始まらない。結果画面が出てから RETRY_LOCKOUT 秒は受け付けない。
- 無視される指（上記の押しっぱなしの指、左半分で 2 本目以降の指）は、あとからスティックにならない。スティックの指が離れたらスティックは解除され、次のスティックは、その後に新しく触れた左半分の指になる。同時に扱う指の上限（3 点）は、無視される指も数える。
- 一時停止は無い。ブラウザのタブが非表示の間は進行しない（Phaser の既定）。

## 画面・Scene 構成

| Scene | 役割 |
|---|---|
| `Game` | 盤面・プレイヤー・ミノ・HUD を描画し、ゲームを進行する。ready → playing の局面を持つ |
| `Result` | クリア／ゲームオーバーの表示とリトライ。`Game` の上に重ねて起動する。`Game` はそのまま動かし続けるが、ラウンドの進行は止まり（盤面・プレイヤー・ミノは結果の瞬間のまま）、画面の揺れなどの演出だけが動く。最後の盤面が背後に残る |

起動後は `Game` が直接始まる（アセットの読み込みは無い）。Title 画面は MVP に含めない。

### 論理サイズとレイアウト

- 論理サイズは `COLS × CELL` = 360 px 幅、`ROWS × CELL` = 720 px 高さ。Phaser の Scale `FIT`＋中央寄せで、ウィンドウに収まるよう拡大縮小する。背景色は暗色（実装裁量）。
- 盤面が画面全体を占める。座標は盤面のセル単位（列 x、行 y。左上が (0, 0)、y は下向きに増える）で扱い、描画時に `CELL` 倍する。
- 盤面の上端 `TOP_OUT_ROW` 行分（行 0〜1）は「積み上がりすぎ」の危険域として、他と違う色の帯で示す。
- ゴールラインは行 `GOAL_ROW` の上端に、盤面幅いっぱいの太さ 4px の黄色い線で描く。
- HUD（高さ）は盤面の左上に重ねて表示する。黒い縁取り（太さ 3px）を付けて、ミノと重なっても読めるようにする。
- ゴールラインの右端に「GOAL」、危険域の帯の下端付近に中央揃えで「ここまで積むと負け」を、小さく薄い文字で常に表示する（見え方は「演出・UI」を参照）。
- 描画順（下から）: 背景・危険域の帯・ゴールライン → 固定されたセル → 固定・行消しの光 → 着地位置の枠 → 予告中／落下中のミノ → プレイヤー → HUD・GOAL・「ここまで積むと負け」の文字 → 操作ヒント → スティックの輪・つまみ → ready / Result の重ね表示。プレイヤーが行 0 より上にいるときは、画面の外にはみ出して描かれず見えなくなってよい（クリア済みの高さなので問題にならない）。
- 左半分のスティックは、触れている間だけ、起点に輪（半径 STICK_RING_RADIUS px）、横方向に（起点から ±STICK_RING_RADIUS に収めた）つまみ（半径 STICK_KNOB_RADIUS px）を描く。右半分は、タッチ操作の目安として薄い色でうっすらと区別する。

### Game Scene の局面と遷移

| 局面 | 内容 | 次の局面へ |
|---|---|---|
| `ready` | 盤面とプレイヤーを表示し、「MINOCLIMB」「←→ 移動 / ジャンプ」「左ドラッグ = 移動 / 右タップ = ジャンプ」「タップまたはスペースで開始」を重ねる。時間・ミノ・プレイヤーは動かない | 開始操作（スペース / Enter / タップ）で `playing` へ |
| `playing` | 下記「ルール」のとおり進行する | クリアまたはゲームオーバーで、`Result` を起動する。`Game` は止めず、ラウンドの進行だけを止める（Scene 表のとおり。結果の局面の描画と演出だけが動く） |

- `ready` 中に受け付ける入力は開始操作だけ（移動・ジャンプは無効）。開始に使ったキー／指の扱いは「操作仕様」のとおり（離すまでゲーム入力にしない）。
- リトライでは `Game` を作り直して `ready` を挟まず `playing` から始める（盤面・タイマー・空ける列を初期化する）。

### 演出・UI

見た目と分かりやすさのための表示で、ルールや数値には影響しない。いずれも入力の受け付けを遅らせない。

| 名前 | きっかけ | 見え方 | 消えるとき |
|---|---|---|---|
| GOAL ラベル | 常時（Game Scene のどの局面でも） | ゴールラインの右端に「GOAL」。ライン（黄色）と同じ色、線のすぐ上、右端から 6px 内側 | 消えない |
| 危険域ラベル | 常時 | 危険域の帯の下端のすぐ上に中央揃えで「ここまで積むと負け」。白の薄い文字（透過度 0.35 程度）、小さい文字 | 消えない |
| 操作ヒント | `playing` の開始（リトライの `playing` も含む） | 画面の下端近くに、左半分の中央へ「ドラッグ: 移動」、右半分の中央へ「タップ: ジャンプ」を薄く表示する。キーボードで遊んでいる場合も同じ | `playing` の経過時間が HINT_TIME に達するまで出し、最後の HINT_FADE 秒で直線的に透明にして消す。クリアまたはゲームオーバーで、残りに関わらず消える |
| 固定の光 | ミノが固定されたとき | 固定されたミノの 4 セルを白い光で覆い、LOCK_FLASH_TIME 秒かけて透明にする。同じフレームに行消しがあったときは、行消し後の位置に出す（消える行にあったセルは出さない） | 光が透明になったら。クリアまたはゲームオーバーで切る |
| 行消しの光 | 行が消えたとき | 消えた行（消える瞬間の行の位置）を白い帯で覆い、CLEAR_FLASH_TIME 秒かけて透明にする。2 行以上のときは行ごとに 1 つの帯 | 光が透明になったら。クリアまたはゲームオーバーで切る |
| 結果の揺れ | ゲームオーバー（潰された／積み上がりすぎ）で `Result` が出るとき。クリアでは揺らさない | 盤面（`Game` の画面）を RESULT_SHAKE_TIME 秒、RESULT_SHAKE_INTENSITY の強さで揺らす（Phaser のカメラの揺れ）。`Result` の暗幕と文字は揺らさない | RESULT_SHAKE_TIME 経過で止まる。リトライで `Game` を作り直したとき切れる |

- **時間の数え方**: 光と操作ヒントは、きっかけのフレームを 0 とし、ちょうど決められた時間で消える。時間はラウンドの時計と同じ数え方（1 フレームの経過時間は MAX_DT で頭打ちにして足す）で、長いフレームがあってもラウンドと食い違わない。同じ種類のきっかけがもう一度来たときは、前の光はそのまま続け、新しい光を別に出す（1 つにまとめない）。
- **同じフレームの扱い**: 固定と行消しが同じフレームに起きたときは「固定の光」（行消し後の位置）と「行消しの光」を両方出す。潰れ・積み上がりすぎ・クリアのフレームでは光を出さない（そのフレームから光は描かない）。
- **局面**: ready の間は GOAL・危険域のラベルだけが見える（操作ヒント・光は出ない）。リトライ後は光・ヒント・揺れをすべて作り直す（前の run のものは残らない）。
- **結果の間の見え方**: 結果の局面（`Result` の間）は、ラウンドの進行が止まった瞬間のまま。着地位置の枠は点滅もその瞬間の濃さで止め、スティックの輪・つまみは描かない（`Result` の間に指が触れていても出さない）。
- **重なり**: 光はプレイヤー・ミノより下に描かれる。揺れは `Game` の画面全体（盤面・HUD・ラベル・結果の瞬間に残っているもの）を動かす。揺れの間は盤面の端が動いて背景色が見えてよい。
- **画面の端**: GOAL の右端は盤面の右端から 6px 内側に収める。操作ヒントは、最下段（行 ROWS − 1）より 1 行上の高さの中央（盤面の下端から 1.5 セル上）に、各半分の中央で中央揃えにし、各半分の幅（COLS × CELL / 2）に収まる大きさの文字にする。HUD の「高さ」と「ここまで積むと負け」は重ならない大きさにする。

## ルール

### 盤面と座標

- 盤面は `COLS × ROWS` のセル格子。行 0 が最上段、行 `ROWS − 1` が最下段。
- 盤面の左右の外側と最下段の下は壁／床（固体）。行 0 より上は何も無い（天井は無く、空間として自由）。
- セルは「空」か「ミノの種類（1〜7）」。空でないセルは固体として扱う。

### プレイヤー

- 大きさは PLAYER_W × PLAYER_H（セル単位）の長方形。座標 (x, y) は左上で、初期位置は盤面の中央・床の上（x = COLS / 2 − PLAYER_W / 2、足が最下段の下端に接する）。
- 1 フレームの経過時間 dt は MAX_DT 秒で頭打ちにする。
- 毎フレーム、先に水平、次に垂直の順に動き、固体セルにめり込んだら手前に押し戻す。
  - 水平: 入力方向 × WALK_SPEED × dt だけ動く。壁・固体セルに当たったらその面に接する位置で止まる。
  - 垂直: 重力 GRAVITY で vy を更新し、vy × dt だけ動く。この移動は SUBSTEP_MAX セル以下の小刻みに分けて判定する（落下が速くても 1 セル厚の固体をすり抜けない）。下向きに当たったら着地（足が固体の上に接する、vy = 0、`onGround`）。上向きに当たったら天井にぶつかったとみなし vy = 0。
  - ジャンプ: ジャンプ入力があり、かつ前フレームの垂直移動の結果が `onGround` なら、そのフレームの重力を足す前に vy = −JUMP_V にする。
- ジャンプで届く高さは約 2.3 セル（JUMP_V² / (2 × GRAVITY)）。段差 2 までは自力で登れるが、3 以上は登れない。
- プレイヤーはミノを押せず、すり抜けもできない。固定されたミノは壁のように扱う。落下中のミノは固体でなく危険物（下記）。
- 穴に落ちて出られなくなっても救済は無い（そのままミノが来て潰されるか、積み上がりすぎで終わる）。

### ミノ

- 7 種類（I・O・T・S・Z・J・L）。各形は 4 セル。回転は 90 度刻みの 4 状態で、回転後は外接矩形の左上を原点に詰めた形として扱う。回転 0 の形:

  | 種類 | 回転 0 のセル（列, 行） |
  |---|---|
  | I | (0,0) (1,0) (2,0) (3,0) |
  | O | (0,0) (1,0) (0,1) (1,1) |
  | T | (0,0) (1,0) (2,0) (1,1) |
  | S | (1,0) (2,0) (0,1) (1,1) |
  | Z | (0,0) (1,0) (1,1) (2,1) |
  | J | (0,0) (0,1) (1,1) (2,1) |
  | L | (2,0) (0,1) (1,1) (2,1) |

  回転 k は (列, 行) → (−行, 列) を k 回適用してから、最小の列・行を 0 に揃えたもの。
- ミノは常に 1 個だけ。固定されてから SPAWN_DELAY 秒後に次の予告が始まる。`playing` の開始からも SPAWN_DELAY 秒後に最初の予告が始まる。
- 種類は 7 種から一様ランダム。着地位置（向きと列）は「着地 AI」が決める。

### 着地 AI

予告の開始時に、盤面と種類から (向き 0〜3, 左端の列) の全候補を評価し、評価点の高い順に並べる。通常は上位 AI_TOP_K 件から一様ランダムに 1 件を選ぶ。確率 AI_MISTAKE_RATE で「ミス」をして、上位 AI_MISTAKE_K 件から選ぶ（完璧な AI だと壁が平らに上がるだけで、足場に段差や隙間ができずクリアしにくいため、意図的に下手に積む）。

- 候補: 向き 0〜3 のすべて（同じ形になる向き、例えば O の 4 向きも別の候補として数える）× 左端の列 0〜「COLS − ミノの幅」。
- 着地行: ミノを盤面の上（外接矩形の上端が行 −4）から真下に動かし、固体にぶつかる直前の行。これでミノの外接矩形の上端行が決まる。行 0 より上のセルは盤面に書き込まない（その候補は、上端が `TOP_OUT_ROW` より上になるので積み上がりすぎの扱い）。
- 着地行の外接矩形の上端が `TOP_OUT_ROW` より上になる候補（積み上がりすぎ）は、評価点を −1,000,000 にする。
- それ以外は、そのミノを置いた盤面（行は消さない）について次で評価する。
  - 評価点 = AI_LINES_W × 揃う行の数 − AI_HOLES_W × 穴の数 − AI_BUMP_W × 凸凹 − AI_WELL_W × 空け列に置くセル数
  - 穴: 各列で、その上にセルがある空セルの数
  - 凸凹: 隣り合う列の高さ（最も上のセルから底までのセル数）の差の絶対値の和。空け列を含む組は数えない
  - 空け列: ゲーム開始時に左端（列 0）か右端（列 COLS − 1）のどちらかを 50% ずつで決め、そのゲームの間は変えない
- 評価点の降順に並べる。同点の候補は、生成順（向き 0→3、各向きで列の昇順）を保つ（安定ソート）。「積み上がりすぎ」でない候補（評価点 > −1,000,000）がある場合、1 個目の乱数 u1（0 以上 1 未満）が AI_MISTAKE_RATE 未満ならミス、そうでなければ通常とする。選ぶ件数 k は、通常なら min(AI_TOP_K, 積み上がりすぎでない候補数)、ミスなら min(AI_MISTAKE_K, 積み上がりすぎでない候補数)（積み上がりすぎでない候補が 1 つも無いときは、全候補を対象に通常の k）。2 個目の乱数 u2 で、並べた候補のうち floor(u2 × k) 番目（0 始まり）を選ぶ。積み上がりすぎでない候補が 1 つも無いときは、ミス判定をせず、通常の選び方で選ぶ（その候補は固定されると積み上がりすぎになる）。
- 着地 AI はプレイヤーの位置を考慮しない。

### 1 個のミノの流れ（進行）

1. **予告**（TELEGRAPH_TIME 秒）: 盤面の最上部（外接矩形の上端が行 0）に、選ばれた種類のミノが現れる。経過時間 t に対し、残りの回転数 = max(0, 3 − floor(t / ROTATE_STEP + 1e-9))（浮動小数点の誤差で境界の回転が 1 つ遅れないようにする）。表示する向きは「選ばれた向き − 残りの回転数」（4 を法とする）。つまり ROTATE_STEP × 3 秒後に最終の向きになり、予告が終わるまでその形で止まる。表示する列は、その向きの幅で盤面からはみ出すときは、はみ出さない最も右の列に寄せる。着地位置（最終の向き・選ばれた列・着地行）に、同じ形の点滅する枠を表示する。この枠は予告の開始から、ミノが固定される（または潰れで終わる）まで出し続け、SPAWN_DELAY の間は出さない。予告中のミノは何にも当たらない（プレイヤーは潰れない）。
2. **落下**: 予告が終わると、最終の向き・選ばれた列で外接矩形の上端が行 0 から、DROP_SPEED セル/秒で落ちる。1 フレームの移動は SUBSTEP_MAX セル以下の小刻みに分けて判定する（すり抜けない）。落下中のミノの各セルとプレイヤーの長方形が（辺が接するだけでなく）重なったら、その時点で「潰された」。
3. **固定**: 下に固体があって進めなくなったら、最後の小刻みな移動を着地行（整数の行）に揃え、その位置でも潰れの判定をしてから（重なれば「潰された」）、その位置で固定してセルを盤面に書き込む。固定された外接矩形の上端が `TOP_OUT_ROW` より上なら「積み上がりすぎ」。同じ固定で潰れと積み上がりすぎが両方成立したら「潰された」を優先する。
4. **行消し**: 固定後に、横一列が埋まった行をすべて消し、その上の行を（消えた行数ぶん）下げる。プレイヤーの足の下端が消えた行の上端より上（足の下端 ≤ 消えた行の上端 + GOAL_TOL）にあるとき、消えた行 1 つにつき、プレイヤーも 1 セル下へ動く（足場と一緒に下がる）。それ以外のプレイヤーは動かない。
5. SPAWN_DELAY 秒後に次の予告へ。

同じフレームでの処理順: プレイヤーの更新（このあとゴール到達を判定して覚えておく）→ ミノの進行（潰れ・固定・積み上がりすぎ・行消し）→ クリア判定（覚えておいた到達、または行消しで下がったあとの位置での到達のどちらかが成立していればクリア）。ミノの進行でゲームオーバーの条件が成立したら、クリア条件が同時に成立していてもゲームオーバー。

### クリア・ゲームオーバー・スコア

- **クリア**: プレイヤーの足の下端（y + PLAYER_H）が、ゴール行の上端（`GOAL_ROW`）以上の高さに達する（y + PLAYER_H ≤ GOAL_ROW + GOAL_TOL）。ジャンプの頂点でもよい（足場の高さ 13 段にジャンプが加われば届く）。
- **ゲームオーバー**: ①落下中のミノに潰される、②ミノの固定位置が「積み上がりすぎ」になる。
- **スコア**: 無し。クリアしたか、しなかったか（しなかったときは敗因と到達した最大の高さを表示するだけ）。時間・ベストタイム・記録の保存はしない（着地 AI の積み方に左右されるので、腕前の指標にならない）。

### HUD

- 左上に「高さ 7 / 15」（n / (ROWS − GOAL_ROW)）を表示する。時間は表示しない。
- 高さ n は、floor((ROWS − プレイヤーの足の下端) + GOAL_TOL) を 0 以上にしたもの。床に立っていれば 0。ゴール行に足が届いた（クリアした）ときだけ ROWS − GOAL_ROW になる。空中（ジャンプの頂点など）も、その瞬間の足の位置で計算する。ゲームオーバーで表示する「到達した最大の高さ」は、`playing` 中の全フレームの n の最大値。

  - 乱数は関数として注入できるようにして、テストで再現できるようにする（ゲーム内では `Math.random`）。

## テスト観点

純粋ロジックの単体テスト（境界値を含む）:

- ミノの形: 7 種 × 回転 0〜3 のセルが外接矩形の左上 (0,0) に詰まり、4 セルで、回転 4 回で元に戻る。O は全回転で同形。
- 盤面の固体判定: 左右の外・最下段の下は固体、行 0 より上は空。
- 着地行: 何も無い盤面で床に接する。固体の上で止まる。ミノの幅いっぱい／壁際の列でも正しい。
- ミノの落下: DROP_SPEED × MAX_DT（2 セル）の 1 回の移動で、1 セル厚の固体を飛び越えない。固体の直前で固定される。プレイヤーが落下途中の経路上にいれば、途中のセルで潰れが成立する。辺が接するだけなら潰れない。
- 固定: 書き込まれるセルが正しい。外接矩形の上端行が `TOP_OUT_ROW − 1` なら積み上がりすぎ、`TOP_OUT_ROW` なら正常。
- 行消し: 1 行・複数行（離れた行／連続した行）が消えて上が詰まる。何も揃わなければ変化しない。
- 行消しとプレイヤー: 足が消えた行の上にいるとき消えた行数ぶん下がる。足が消えた行の下にいるときは動かない。足の下端が「消えた行の上端 + GOAL_TOL」ちょうどのとき下がる。
- スティック: dx = −STICK_DEADZONE ちょうどと +STICK_DEADZONE ちょうどは入力なし、その外側 1px で左／右。x = 論理幅 / 2 ちょうどの指は右半分（ジャンプ）。左半分に 2 本の指があるときは先に触れた方だけがスティック。
- 開始・リトライの入力: 押しっぱなしのまま RETRY_LOCKOUT が過ぎてもリトライしない（押した瞬間だけ受け付ける）。`playing` の開始時に既に押されているキー／指（リトライに使ったもの、結果画面の間に押したもの、押しっぱなしの移動キー）は、離すまで移動・ジャンプ・スティックの起点にならない（スペースを押したままリトライした直後にジャンプしない）。離したあとに押し直せば有効。無視されている指は、あとからスティックにならない。
- プレイヤー: 壁際で止まる。MAX_DT でも落下速度が最大（行 0 の上から落ちるなど）の状態で、1 セル厚の固体の上に着地する（すり抜けない）。段差 2 のセルの上に跳んで乗れる。段差 3 には乗れない。空中でジャンプしても跳べない。押しっぱなしで着地ごとに再ジャンプ。左右同時入力で止まる。天井にぶつかって vy が 0 になる。dt が大きくても MAX_DT で頭打ち。
- 着地 AI: 穴ができる置き方より穴ができない置き方を選ぶ。空け列に置かない（他に選択肢があるとき）。`TOP_OUT_ROW` 未満になる候補は選ばれない（他に候補があるとき）。通常の選び方では、乱数が 0 のとき最上位（同点は生成順で先）、乱数が 1 に近いとき AI_TOP_K 番目を選ぶ。ミス判定の乱数が AI_MISTAKE_RATE 未満ならミス（AI_MISTAKE_K 番目までから選ぶ）、以上なら通常。積み上がりすぎになる候補は、ミスでも選ばれない（他に候補があるとき）。候補数が AI_TOP_K や AI_MISTAKE_K 未満でも落ちない。
- 着地 AI の統計（模擬）: 種類を一様ランダムに選び、プレイヤー無しで、1 個ずつ固定して行消しを毎回行う模擬を、シード 1〜30 の 30 回（空け列は左右半々）、1 回あたり最大 500 個まで行う。高さは「いちばん上のセルから床まで」の行数。平均の「積み上がりすぎまでのミノ数」が 50〜100 個、消えた行の合計の平均が 8 行以上、高さが 15 以上になるまでのミノ数の平均が 60 個以下で、かつ「高さ 15 以上に届く前に積み上がりすぎになる」回が全体の 5% 以下であること（初期値はそれぞれ約 70・約 13・約 43・0%。高さ 15 に届かない回は 500 個として数える。ミス確率 0 の場合との差をテストに含める: ミス 0 のほうが段差の少ない壁になり、行消しの平均が多い）。
- 予告の表示: t = 0 で「最終 − 3 回転」、t = ROTATE_STEP × 3（浮動小数点の誤差を含めて、0.6 秒ちょうど）以降は最終の向き。幅がはみ出す向きでは右に寄せる。
- 予告の枠: 予告の開始から固定までの間だけ表示され、SPAWN_DELAY の間は表示されない。
- 演出の時間: 光は t = 0 で最大の濃さ、t = D（LOCK_FLASH_TIME / CLEAR_FLASH_TIME）の直前で 0 に近く、ちょうど D 以降は 0。操作ヒントは t = HINT_TIME − HINT_FADE まで一定で、そこから直線で減って t = HINT_TIME でちょうど 0。光は 0 ≤ t < D の間、t が増えるにつれて濃さが（単調に）減る。同じ種類の光が重なったとき、別々の経過時間で数える。
- 出来事（演出のきっかけ）: ミノの固定で 4 セルの位置が 1 回返る。行消しがあればその行（消える瞬間の行番号）が 1 回返る。同じフレームに固定と行消しがあるとき、固定のセルは行消し後の位置で、消える行にあったセルは含まれない（4 セル → 行消しの行数ぶん減る）。潰れ・積み上がりすぎのフレームでは固定の出来事が出ない（積み上がりすぎでは固定の出来事は返さない）。
- クリア判定: 足の下端がちょうど `GOAL_ROW` のとき成立、`GOAL_ROW + 0.02` では不成立。
- 同フレーム優先順位: 潰れとクリア条件が同時に成立したらゲームオーバー。
- HUD の高さ: 床で 0、ゴール行に立って `ROWS − GOAL_ROW`。

Scene / 統合（必要最小限）:

- `ready` から開始操作で `playing` に入り、`playing` に入るまでミノの予告・落下とプレイヤーの操作が始まらない。
- ゲームオーバーでだけ画面が揺れ、クリアでは揺れない。リトライで光・ヒント・揺れが残らない。`Result` の間はスティックの輪が描かれない。
- クリア／ゲームオーバーで `Result` が起動し、RETRY_LOCKOUT 経過後の新しいタップでのみリトライできる。
