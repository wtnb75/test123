# minoclimb（仮称）

## コンセプト

普通のテトリスの盤面（10×20）にミノが 1 個ずつ降ってくる。プレイヤーは小さなキャラを操作して、落ちてくるミノを避けながら積もったミノを登り、上端近くのゴールラインを目指すアクション。一列揃うとその行は消える。

## コアループ

1. 上に現れたミノが回転しながら着地位置（枠）を予告する。予告を見て、落ちてくる列から逃げる。
2. ミノが一気に落ちて積もる。積もった段差にジャンプで乗り、高さを稼ぐ。
3. 行が揃って消えると足場が下がる。足場を保ちつつ登り、ゴールラインに足を届かせる。

## 操作仕様

- キーボード: ←→ / A D で移動、↑ / W / スペースでジャンプ。クリア・ゲームオーバー後は R / スペース / タップでリトライ
- タッチ: 画面の左半分は横方向だけの浮動スティック（最初に触れた位置が起点。そこから左右へ 10px 以上ドラッグした方向へ移動）。右半分はどこを押してもジャンプ。リング／つまみを描画する
- ミノは操作しない。プレイヤーが操作するのはキャラだけ

## ルール

- ミノは常に 1 個だけ。着地位置はゲーム側（簡易 AI）が決める。穴を作らず平らに積む傾向で、左右どちらかの端の列を空けておく。上位 2 候補からランダムに選ぶので、完全には読めない
- 予告（0.9 秒）: 盤面最上部にミノが現れ、0.2 秒ごとに 90 度ずつ回って最終の向きになる。着地位置に点滅する枠が出る。予告中のミノには当たっても潰されない
- 落下: 予告が終わると 40 マス/秒で一気に落ちる。落下中のミノに触れると潰される
- 横一列が埋まると、その行が消えて上の行が 1 段下がる。上にいるプレイヤーも一緒に下がる
- クリア: プレイヤーの足がゴール行（上から 5 行目の上端）に達する
- ゲームオーバー: 落下中のミノに潰される／ミノが上から 2 行目より上で固定される（積み上がりすぎ）

## プレイテストで固まったこと

- 画面スクロールは不要（画面は固定。ステージが下がっていく必要はない）
- ミノは 1 個ずつ、回転して落ちてくる。普通のテトリスの盤面で、一列揃うと消える
- 完全ランダム配置だと登りにくく、行も消えない → 着地位置は簡易 AI が決める
- スマホ操作: 固定位置の 3 ボタンは押しにくかった → 左半分を浮動スティック、右半分をジャンプにした
- 自然落下だけでなく、予告から一気に落とす緩急でスピード感を出す
- AI の重み（シミュレーション 30 回の平均）: 約 100 個目で積み上がりすぎ、約 57 個目で高さ 15 に届く、行消し約 27 回

## パラメータ表

| 名前 | 値 | 意味 |
|---|---|---|
| COLS / ROWS | 10 / 20 | 盤面の列数・行数 |
| CELL | 36 | 1 マスの描画サイズ(px) |
| GOAL_ROW | 5 | ゴール行（上から数えた行番号。足がここまで来たらクリア） |
| TOP_OUT_ROW | 2 | これより上でミノが固定されると積み上がりすぎ |
| PLAYER_W / PLAYER_H | 0.7 / 0.9 | プレイヤーの大きさ（マス単位） |
| WALK_SPEED | 5 | 移動速度（マス/秒） |
| JUMP_V | 13.6 | ジャンプ初速（約 2.3 マス跳べる） |
| GRAVITY | 40 | 重力（マス/秒²） |
| DROP_SPEED | 40 | ミノの落下速度（マス/秒） |
| STICK_DEADZONE | 10 | スティックの遊び（画面 px。これ未満は止まる） |
| TELEGRAPH_TIME | 0.9 | 予告時間（秒） |
| ROTATE_STEP | 0.2 | 予告中の回転間隔（秒） |
| SPAWN_DELAY | 0.3 | 固定から次の予告までの間（秒） |
| AI_TOP_K | 2 | AI が上位何候補からランダムに選ぶか |
| AI_HOLES_W / AI_BUMP_W | 8 / 1 | 穴・凸凹の重み（大きいほど平らに積む） |
| AI_LINES_W | 3 | 行消しの重み |
| AI_WELL_W | 1 | 端の列を空けておく度合い（大きいほど行が揃いにくい） |
