# MINOCLIMB

テトリスのミノが 1 個ずつ降ってくる 10×20 の盤面を、ミノを避けながら登って、上端近くの黄色いゴールラインを目指すアクションゲームです。Phaser 4 + TypeScript + Vite で作られた静的サイトとして動きます。

## 目的

積もったミノを足場にして登り、足をゴールライン（盤面の上から 5 行分の下の黄色い線）に届かせるとクリアです。

## ルール

- ミノは常に 1 個だけ降ってきます。着地位置はゲームが決めます（ときどきミスをします）。
- 上に現れたミノが回転しながら、着地位置を点滅する枠で予告します（約 0.9 秒）。予告中のミノには当たりません。
- 予告が終わるとミノが一気に落ちます。落下中のミノに触れると潰されてゲームオーバーです。
- 横一列が埋まった行は消えて、上の積み重ねが 1 段下がります。プレイヤーはその場に残り、足場が下がったぶんは重力で自然に落ちます。
- ミノが盤面の上から 2 行（色の違う帯）に固定されると「積み上がりすぎ」でゲームオーバーです。
- ジャンプで届くのは約 2 マスです。段差 3 以上は、ほかの足場を使って登ります。
- 壁に触れている空中でジャンプを押し直すと、壁を蹴って反対向きへ跳びます。向かい合う壁の間（幅の狭い穴）なら、左右の壁を交互に蹴って登れます。同じ側の壁は、反対側の壁を蹴るか着地するまで、続けて蹴れません。蹴ったあとは、着地するか反対側の壁に触れるまで、蹴った壁の方へは戻れません（壁が片側だけの段差には、壁蹴りでは登れません）。
- ミノのふたで、上下左右が固体に閉じた空間に閉じ込められたまま約 1 秒たつと、外へ通じる最短の壁のセルが点滅します。約 2 秒の点滅のあとにそのセルが消えて、外につながるまで 1 セルずつ崩れます。
- スコアはありません。クリアできたかどうかだけです。

## 操作方法

| 操作 | キーボード | タッチ |
|---|---|---|
| 左右に移動 | ← → / A D | 画面のどこでもドラッグ（触れた位置から左右へ。指が輪の外へ出ると起点が付いてくるので、行き過ぎても指を約 40 px 戻せば切り返せます） |
| ジャンプ | ↑ / W / スペース | 画面のどこかをタップ（動かさずにすぐ離す）。または、ドラッグ中の指を上へ弾く。または、ドラッグしながら 2 本目の指で画面のどこかに触れる（触れている間ジャンプ） |
| 開始（タイトル画面） | スペース / Enter | 画面のどこかをタップ |
| リトライ | R / スペース | タップ |

ジャンプは押しっぱなしにすると、着地するたびに再ジャンプします。壁蹴りは、押しっぱなしでは出ません。空中でいったん離して、押し直してください（上へ弾いているなら、いったん戻してからもう一度弾きます。2 本目の指なら、離して触れ直します）。タイトル画面の背後では、ボットが同じゲームを遊ぶデモが流れます（操作は受け付けません）。

## 開発

```sh
npm install      # 依存を入れる（モノレポ直下で pnpm install でも可）
npm run dev      # 開発サーバー
npm run build    # dist/ に静的サイトを出力
npm run lint
npm run test
npm run test:coverage
```

仕様は [docs/spec.md](docs/spec.md) にあります。
