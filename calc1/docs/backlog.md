# calc1（Calc Rush）拡張候補（backlog）

公開済みの calc1 に、次に足せるものの候補を、上から順に並べたものです。上のカードが「次の候補」です。仕様（`spec.md`）ではありません。`game-extend` が上から順に 1 件を選び、目的・コアループへの効き方・変えないものを固めてから、仕様に書きます。

- 規模: S = 1 画面と数値の追加程度、M = 複数の画面や仕組みにまたがる追加、L = 大きいので、`game-extend` で 1 PR 分に切り出してから採用する。

### クリア・ゲームオーバーから Title へ戻れるようにする（`back-to-title`）

- 狙い: `Title` を足したが、`Game` から `Title` へ戻る導線が無く、デモをもう一度見る・最初から選び直すにはリロードするしかない。根拠: [Title とデモ](spec/title-demo.md)（`Game` から `Title` へ戻る導線は無い）。first-game・digdle で、同じ導線を後から足した
- 何を足すか: クリア・ゲームオーバーの結果表示に、「TITLE」ボタンと、キー `T` で `Title` へ戻る操作を足す。結果の確認ステップ（クリック / タップで次へ・リトライ）の挙動は変えない。
- コアループへの効き方: 広げない — 動線だけを足す。
- 種別: presentation-only
- 規模: S
- 出どころ: spec 分析
- メモ: 結果表示では、画面のどこをクリックしても次へ・リトライになる（`swallowNextResultClick` で最初の 1 回は無視）ため、ボタンのタップが「次へ」と二重にならないよう、ボタンを優先する（`e.stopPropagation()` を使う「最初から」と同じ扱い）。
