# アイテム（時計）

## 概要

穴から、モグラやネコと同じように「時計」が出ることがある。叩くと残り時間が増える。叩かなくてもよく、叩くか放っておくかの判断が増える。出方、予兆、出ている時間、同時数の上限は、モグラと同じ仕組み（[Game の盤面](../spec.md)・[出現判定](../spec.md)）に従う。

## 操作仕様

追加・変更なし。時計を叩く操作は、モグラを叩く操作（タップ・クリック・Space）と同じ。時計専用の操作はない。

## 画面・Scene構成

対象は Game（盤面に出る Pop）と Demo（Title の背後で流す本編）。Result では出ない。Title は時計を説明しない（操作説明の 3 行は変えない。説明は README と、叩いたときの「+N秒」の文字だけ）。

- **見た目**: 時計は白い丸（本体の直径は、モグラの本体と同じ）に、黒い針を 2 本描いたもの。モグラ（茶色の丸）・ネコ（オレンジの丸）と形と色で区別できる。予兆（土ぼこり）・せり上がり・引っ込みは、モグラと同じ。
- **方向矢印**: 時計には出さない（[方向矢印](../spec.md)の対象は、モグラとおとりのネコだけ）。画面外にあっても出さない。
- **叩いた（時計）**: モグラの「叩いた」と同じ見た目と長さ（本体がつぶれて消える約 160ms、星 8 個が約 350ms）。加算の文字は「+N秒」（N は `itemTimeBonusMs` を秒にした値。黄色ではなく青の文字。大きさは実装裁量で、「+N」と揃える）が上に浮かんで消える（約 600ms）。浮かぶ位置と画面端の扱いは、「+N」と同じ規則（[演出・UI](../spec.md)「画面端」）。画面揺れは、モグラと同じ（`hitShakeMs`、`hitShakeIntensity`）。ネコの揺れが動作中ならそちらを優先して追加しない。
- **同時発生**: 同じフレームに時計とモグラの叩きがあれば、入力の順に効果を 1 つずつ出す（[演出・UI](../spec.md)「同時発生」）。
- **残り時間の HUD**: 時計を叩いた更新で、残り時間の表示を書き換える（切り上げ整数秒。[演出・UI](../spec.md)「残り時間の強調」の規則は表示秒で判定し、加算のあとの表示秒に従う）。上限がないので、60 を超えて表示してよい。
- **ending**: 時計を叩く入力は、[ending](../spec.md) に入ったあとは受けない（モグラと同じ）。時計の「叩いた」の効果は、ending の間も残りを再生してよいが、新しく出さない。

## ルール

- **出現**: [出現判定](../spec.md)の手順 4 で、Pop ごとにネコかどうかを決めたあと、ネコでなかった Pop に対して、確率 `itemRate` で時計にする。判定は Pop 1 体につき 1 回。乱数は、その Pop のネコ判定の直後に、同じ乱数源から 1 回引く（順序は、ネコ判定 → 時計判定 →（時計でなければ）金の判定 → 次の Pop。金の判定は [金のモグラ](golden-mole.md)）。時計になった Pop はモグラと同じ状態遷移（予兆 → 出ている → 消える）をたどる。
- **おとり**: 時計はネコではないので、おとりの抽選の対象にならない（[出現判定](../spec.md)の手順 5）。
- **同時数**: 時計も Pop なので、同時数の上限（`maxActive`／`maxActiveMid`／`maxActiveLate`）に数える。時計がいる分だけ、モグラの出る枠が減る。
- **開始**: 時計は、Game の開始から出る（段階によらない）。
- **叩き**: 時計を叩いたら（up の状態で、[叩きの判定](../spec.md)と同じ判定で当たったとき）、残り時間に `itemTimeBonusMs` を加える。上限はない。残り時間の減りとの順序は、[Game の進行フェーズ](../spec.md)の順（叩きの処理 → 残り時間の減り → 0 の判定）に従う。
- **スコアと連続**: 時計を叩いても、スコアは増減しない。連続（`streak`）も変わらない（増えない、0 に戻らない）。
- **時間切れ**: 叩かれずに時間切れで消えた時計は、何もしない（加点・減点・連続の変化なし）。
- **予兆中**: 予兆（telegraph）の時計は叩けない（モグラと同じ）。予兆中の穴を叩いたときは、空振りとして扱う（[ルール](../spec.md)の「空振り」と同じく、連続は 0 に戻り、スコアは変わらない）。
- **残り時間 0 以降**: ending に入ったあとの叩きは、時計でも無視する（[Game の進行フェーズ](../spec.md)）。
- **Demo**: Demo（Title の背後）でも時計は出る。Demo のボットは時計を叩かないので、Demo で残り時間の加算は起きない（ボットの叩きはモグラだけ。[Title とデモ](title-demo.md)）。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `itemRate` | 0.05 | ネコでなかった Pop が時計になる確率。1 ラウンドに出る時計は、約 46 体（60 本の試走の平均。ネコは約 15 体）のネコでない Pop に対して約 2.3 回（叩かないときの推定。叩けば、この回数のうち叩いた分だけ加算される）。 |
| `itemTimeBonusMs` | 3000 | 時計を叩いたときの残り時間の加算（ms）。上限なし。 |

## テスト観点

- 出現: ネコ判定の乱数が `friendRate` 未満なら、その Pop はネコで時計にならない。`friendRate` ちょうどの乱数は、ネコではない（時計判定へ進む）。
- 出現: ネコでない Pop の時計判定は、乱数が `itemRate` 未満なら時計、`itemRate` ちょうどなら時計にならない（モグラ）。
- 出現: 時計判定の乱数は、ネコでない Pop ごとに 1 回だけ引く。ネコの Pop では引かない。乱数の順序（ネコ判定 → 時計判定 →（時計でなければ）金の判定 → 次の Pop）が固定されている（注入した乱数列で確かめる。時計の Pop は金の判定の乱数を引かない）。
- おとり: 時計はおとりにならず、方向矢印は出ない（矢印の対象判定で時計を外す）。
- 叩き: up の時計を叩くと残り時間が `itemTimeBonusMs`（3000ms）増え、スコアは変わらない。境界: 叩く直前の `streak` が 0・4・7 のとき、叩いたあとも同じ値のまま。
- 叩き: telegraph の時計は叩けない。叩くと空振りになり、連続は 0 に戻る（スコアは変わらない）。
- 時間切れ: 叩かれずに消えた時計は、残り時間・スコア・連続のどれも変えない。
- 上限なし: 残り 58 秒の時に叩くと、残りは 61 秒（表示は 61）。
- ending: ending に入った後の更新で届いた時計の叩きは無視する（ending に入るフレームの叩きは有効。[Game の進行フェーズ](../spec.md)の順序による）。
- 残り時間の順序（Scene の処理なので単体テストの対象外。`game-qa` で確かめる）: 残り 0.3 秒の更新で、経過 0.5 秒の更新中に時計を叩く → 叩きの加算のあとで残りを減らすので、ending にならず残りは 2.8 秒（加算 3 秒 − 0.5 秒 ＋ 残り 0.3 秒 = 2.8 秒）。
- 同時の叩き: 同じ更新に時計とモグラの叩きがあるとき、入力の順に 1 つずつ処理する（連続は、その時点の値で倍率を決める）。
- 同時数: 時計も Pop として数える（上限が 4 のとき、時計 3 体とモグラ 1 体で、新しい Pop は出ない）。
- Demo: ボットが時計を叩くことはない（seeded の試走で、時計への叩きが 0）。
- 回帰（[完了条件](#完了条件)の変えないもの）: 既存のモグラ・ネコの加点・減点・連続、判定の段階・間隔・上限、おとりの規則、方向矢印の規則、操作、Title・Result の遷移を変更せずに通ること。

## 完了条件

- 時計を叩くと残り時間が `itemTimeBonusMs`（3 秒）増え、スコアと連続が変わらないこと（テスト観点・`game-qa` で確かめる）。
- 時計に方向矢印が出ないこと（テスト観点・`game-qa`）。
- 時計の上限がないこと: 60 秒を超えて残り時間が表示されること（`game-qa`）。
- 時計の「叩いた」の演出と「+N秒」の文字が、390 × 844 と 375 × 550 で画面に収まること（`game-qa` のスクリーンショット）。
- Demo のボットが時計を叩かないこと（テスト観点）。
- 残り時間の順序（上の「残り時間の順序」）と、同じ更新の複数の叩きの順（入力の順）は、Scene の処理なので `game-qa` で確かめる。
- Demo のボットの品質（[Title とデモ](title-demo.md)の品質の閾値）は、時計を足した後も変えずに通ること。通らなければ閾値は動かさず、出方の仕様を `game-spec` に戻して見直す。
- 変えないもの（回帰条件。時計を足しても変わらないこと）: モグラとネコの加点・減点・連続の規則、判定の段階・間隔・同時数の上限の数（ただし同時数には時計も入る）、おとりの規則、方向矢印の規則（モグラとおとり）、操作、Title・Result の遷移（ブラウザ QA で前回と同じ結果。spec.md の完了条件 325・326 と同じ）。
- README の遊び方に、時計を叩くと残り時間が増えることを 1 行足すこと。

## 実装裁量

- 時計の本体の色（白い丸と黒い針の濃さ、枠の色）。形と色でモグラ・ネコと区別できること。
- 時計の針の長さと太さ、本体の細かな描き方。
- 「+N秒」の文字の縁取り・影と、浮かぶ向きの細かな扱い（「+N」と同じ規則に従う）。色は青のまま、大きさは「+N」と揃える。
- 時計判定の乱数源の注入の仕方、内部のモジュール構成と関数名。
