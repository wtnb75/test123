# 演出・UI

`docs/spec.md` の一部。`Game` の演出・UI の一覧（トリガー・見た目と長さ・描画順・同時発生・画面端・スコア表示・Result）と、その単体テスト観点・完了条件を、独立して書いたもの。パラメータ名・用語（`catFlashMs`、`lowTimeSeconds` など）と、本文中の節名（「方向矢印」「連続」など）は `docs/spec.md` のものを指す。`docs/spec.md` と合わせて 1 つの spec である。

## 概要

`Game` の演出と UI の表示を、トリガーごとに定める。ルール・スコア・出現・当たり判定は変えない。

## 画面・Scene構成

### 演出・UI

効果はすべて、トリガーのフレームを t = 0 として、指定の長さのちょうど後に消える。同じ効果が再度トリガーされたら重ねて出す（各効果は独立。ただしネコの赤い面とカメラの揺れは、各行に書いた「再度起きたら」の指定に従う）。`ending` に入ると、残っている効果は Game を離れるまで再生してよいが、叩きによる新しいトリガーは起きない（「タイムアップ」の表示だけは `ending` に入ったフレームがトリガー）。Game を離れるとき（Scene の終了）に残りはすべて破棄する。

| 効果 | トリガー | 見た目と長さ |
|---|---|---|
| 予兆 | Pop の出現 | 穴に土ぼこりの楕円（約 120 × 50）が出て、左右に小刻みに揺れ続ける。telegraph 終了で消える |
| せり上がり | telegraph の終了 | 本体が穴から下から上へせり上がる（約 150ms）。叩けるのは up の開始から（せり上がり中も叩ける） |
| 叩いた（モグラ） | モグラへの叩き | 本体がつぶれて消える（約 160ms）、黄色い星 8 個が放射状に広がって消える（約 350ms）、「+N」の黄色い文字（N は実際に加点した量。倍率を含み、10／20／30）が上に浮かんで消える（約 600ms）、画面がごく軽く揺れる（`hitShakeMs`、強さ `hitShakeIntensity`。ネコの揺れが動作中ならそちらを優先して追加しない） |
| 叩いた（ネコ） | ネコへの叩き | 画面全体を覆う赤い半透明の面（色は `catFlashColor`、トリガーの時点の濃さが `catFlashAlpha`）が、`catFlashMs` かけて濃さ 0 までなめらかに消える（t = 0 で濃さ `catFlashAlpha`、t = `catFlashMs` で 0。動作中に再度起きたら濃さを `catFlashAlpha` に戻して最初からやり直す。面は盤面とともにスクロールしない）、強く揺れる（`catShakeMs`、強さ `catShakeIntensity`。モグラの揺れが動作中でもこちらで上書きする）、本体が赤くなって上に跳ね飛びながら回転して消える（約 400ms）、赤い文字が上に浮かんで消える（約 600ms）。文字は実際に減った量を表し、「-N」（N は実際に減った量。スコアが 0 で減らなかったときは「0」）。演出はスコアが減らなくても出す |
| 連続の倍率の予告 | モグラ（金のモグラを含む）を叩いて加点したあと、`streak` が `streakStep` の倍数のうち倍率が上がる値になったとき（既定では `streak` が 5 になったとき「×2!」、10 になったとき「×3!」。文字の数は、その次の叩きの倍率）。`streak` が 4・6・9・11・15 などになったとき、または `streak` が 0 に戻ったときは出さない | 黄色い文字（大きさ `streakTextSize`）が、画面に固定して（盤面とともにスクロールしない）、横は画面の中央、縦は画面の中央より `streakTextOffsetY` 上を中心に出て、`streakTextRisePx` だけ上へ浮かびながら `streakTextMs` かけて消える（t = 0 で濃さ 1、t = `streakTextMs` で 0）。出した位置は、画面の端から十分に離れていて切り詰めない。同じ効果が再度起きたら重ねて出す（0 に戻ってまた 5 に達したときなど）。`ending` に入ったあとは新しく出さない。`Demo` では出さない。描画順は、方向矢印の手前、ネコ叩きの赤い面の奥 |
| 時間切れ | Pop の up が終わる | 本体が穴へ引っ込んで消える（約 150ms）。土ぼこりは出ない。加点・減点なし |
| 空振り | 空振り（予兆中の穴への叩きを含む） | 叩いた位置に白いリングが広がって消える（約 300ms）、「miss」の灰色の小さな文字が上に浮かんで消える（約 600ms）。減点はない |
| 方向矢印の脈動 | 矢印が出ている間ずっと | 矢印の大きさがなめらかに拡縮する。大きさ = 基準（長さ 40 × 幅 32）× `arrowScale` × (1 + `arrowPulseAmp` × sin(2π × t / `arrowPulsePeriodMs`))。t は Game の経過時間（ms、開始が 0）。全矢印で同じ位相。拡縮の中心は矢印の中心（位置は方向矢印の節のとおりで変わらない） |
| 残り時間の強調 | 残り時間の表示が `lowTimeSeconds` 以下になる（表示秒 ≤ `lowTimeSeconds`） | 残り時間の文字が赤くなり、表示秒が切り替わる瞬間に `1 + lowTimePulse` 倍（拡大の基点は文字の右上）に大きくなって、次の切り替えにかけて 1 倍まで小さくなる（倍率 = 1 + `lowTimePulse` × (残りミリ秒を 1000 で割った余り ÷ 1000)）。表示秒が `lowTimeSeconds` を超えている間は常に 1 倍で通常色 |
| タイムアップ | `ending` に入ったフレーム | 画面中央に「タイムアップ！」を大きく表示し、`ending` の間（`endingMs`）出し続ける。Result へ遷移するときに消える。入力は元から無視される |
| Scene の切り替え | Title／Game／Result の開始 | 開始した Scene が黒から `sceneFadeMs` かけて通常の表示へフェードインする。フェードアウトはしない（切り替えは遅らせない）。フェード中も入力を受け付ける（Result の `inputGuardMs` は別に数える） |

- **描画順（手前ほど後）**: 盤面・穴 < 土ぼこり < 本体（モグラ・ネコ・時計・金のモグラ）< 叩きの効果（リング・星・文字）< 方向矢印 < 連続の倍率の予告 < ネコ叩きの赤い面 < HUD・照準リング・メッセージ（「タイムアップ！」を含む）。赤い面は HUD の下なので、HUD は赤い面の上でも読める。
- **同時発生**: 同じフレームに複数の叩きがあれば効果を 1 つずつ出す。「叩いた」の文字が同じ穴の上で重なってもよい。
- **画面端**: 浮かぶ文字（「+N」「+N秒」「-N」「0」「miss」）はすべて文字の中心を基準に置き、`floatTextRisePx` だけ上へ浮かんで消える（約 600ms）。調整前の出現位置は、「+N」「-N」「0」が叩いた Pop の穴の中心の 90px 上、「miss」が叩いた位置の 30px 上。出た時点の位置と、上へ浮かび終わった位置の両方が、画面の端から `floatTextMargin` 以上内側に収まるように、出現位置を調整する（文字の大きさを含めて測り、上下左右とも同様。文字が画面に収まらないほど大きい場合は画面中央に置く）。調整するのは出現のときだけで、文字が盤面とともに動くのは今までどおりなので、その後の画面スクロールで端に近づいてもよい。
- **スコアの表示**: HUD は、スコア（左上）と残り時間（右上）を別の文字として常に表示する。表記は「スコア N」「残り T」。スコアが変わった更新で書き換える（アニメーションなし）。残り時間は「残り時間の強調」のとおり。
- **Result**: スコアを大きく表示し、「もう一度」「タイトルへ」ボタンを出す。Result に入ってから `inputGuardMs` の間はボタンを受け付けない（直前の叩きの指が誤ってリトライを押さないようにするため）。

## テスト観点

- **残り時間の強調**: 残り 10.000 秒（表示 10）は強調、10.001 秒（表示 11）は強調なし、0 秒（表示 0）は強調（倍率 1）。倍率は手計算で、残り 9.999 秒 → 1 + 0.2 × 0.999 = 1.1998、9.500 秒 → 1.1、9.000 秒 → 1.0（ちょうど秒の境目は 1 倍）、強調なしのとき（例: 30 秒）は常に 1。
- **方向矢印の脈動**: 経過 0ms → 1.0、125ms（周期の 1/4）→ 1.1、250ms → 1.0、375ms → 0.9、500ms → 1.0（周期ごとに繰り返す）。基準の大きさは `arrowScale` を掛けて長さ 56 × 幅 44.8 になる。
- **浮かぶ文字の位置調整**: 横画面の画面（1024 × 768。縦画面は [縦画面レイアウト](portrait.md)）の中央に出る文字は動かさない。左端の外（x = 0）に出ようとすると、文字の幅の半分 + 24 まで右へ寄る。右端・下端も同様。上端（y = 0）に出ようとすると、文字の高さの半分 + 24 + `floatTextRisePx`（70）まで下げる（浮かび終わっても余白内に入る）。画面に収まらないほど大きな文字は中央に置く。

## 完了条件

- 矢印は大きく、ゆるく拡縮する（バーストのスクリーンショットで大きさが変わっている）。
- ネコを叩いても画面全体は真っ赤にならず、赤い面の下でも HUD と盤面が読める（スクリーンショットで確認）。
- 画面上端の穴を叩いても「+10」「+30」などの文字が画面外に切れない（スクリーンショットで確認。位置は単体テスト）。
- 残り 10 秒以下で、残り時間が赤くなり脈動する（スクリーンショットで確認。倍率と判定は単体テスト）。
- 時間切れで、Result へ進む前に「タイムアップ！」が画面中央に出る（スクリーンショットで確認）。
- Title・Game・Result の開始時に、短いフェードインがある。フェード中でも入力を受け付ける（ブラウザ QA で確認）。
