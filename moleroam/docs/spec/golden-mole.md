# 金のモグラ

## 概要

穴から、まれに「金のモグラ」が出る。出ている時間が短く（`goldenLifetimeMs`）、叩くと高得点（`scoreGolden`）。画面外にいる間は、モグラ・おとりのネコの黄色い矢印とは違う、金色の矢印が出る。遠くの金のモグラへ駆けつけるか、近くのモグラを取るかを選ぶ判断が増える。出方、予兆、同時数の上限は、モグラ・時計と同じ仕組み（[Game の盤面](../spec.md)・出現判定）に従う。

## 操作仕様

追加・変更なし。金のモグラを叩く操作は、モグラを叩く操作（タップ・クリック・Space）と同じ。

## 画面・Scene構成

対象は Game（盤面に出る Pop）と Demo（Title の背後で流す本編）。Result では出ない。Title は金のモグラを説明しない（操作説明の文は変えない。説明は README と、叩いたときの「+50」の文字だけ）。

- **見た目**: 本体は金色の丸（直径はモグラの本体と同じ）で、きらめき（小さな光の点か星。細部は実装裁量）が付く。モグラ（茶色の丸）・ネコ（オレンジの丸）・時計（白い丸）と形と色で区別できる。予兆（土ぼこり）は、モグラ・ネコ・時計と同じで、予兆の見た目では区別できない。せり上がり・引っ込みは、モグラと同じ。
- **方向矢印**: 金のモグラは、telegraph または up の間、穴の中心が画面外にあるときに矢印が出る（出る条件・位置・大きさ・脈動は、モグラの矢印と同じ。[方向矢印](../spec.md)）。色だけが違い、`goldenArrowColor` の金色の三角形に、白い縁取り（太さ `goldenArrowOutlinePx`）を付ける。モグラとおとりのネコの矢印（黄色・縁取りなし）と見分けがつく。金色の矢印が出るのは金のモグラだけで、おとりのネコが金色の矢印を出すことはない。金のモグラが叩かれる、または引っ込んで消えたときに、矢印も消える。同時に出せる矢印の数の上限（`maxActiveLate`）は変わらない。
- **叩いた（金のモグラ）**: モグラの「叩いた」と同じ見た目と長さ（本体がつぶれて消える約 160ms、星 8 個が約 350ms、画面揺れは `hitShakeMs`・`hitShakeIntensity`。ネコの揺れが動作中ならそちらを優先して追加しない）。加算の文字は「+50」（`scoreGolden` の実際の加点。金色。大きさは実装裁量で、モグラの「+N」と揃える）が上に浮かんで消える（約 600ms。位置と画面端の扱いは「+N」と同じ規則。[演出・UI](../spec.md)「画面端」）。
- **時間切れ**: 叩かれずに up が終わると、モグラと同じ「時間切れ」の演出（本体が穴へ引っ込んで消える約 150ms）。加点・減点なし。
- **連続の倍率の予告**: 金のモグラを叩いて加点したあと、`streak` が 5・10 になったとき（モグラのときと同じ条件・同じ見た目。[演出・UI](../spec.md)）、「×2!」「×3!」を出す。
- **ending**: 金のモグラを叩く入力は、`ending` に入ったあとは受けない（モグラと同じ）。金のモグラの「叩いた」の効果は、ending の間も残りを再生してよいが、新しく出さない。
- **Demo**: Demo（Title の背後）でも金のモグラは出る（見た目・矢印は Game と同じ）。Demo のボットは金のモグラを叩かない（[Title とデモ](title-demo.md)）。

## ルール

- **出現**: [出現判定](../spec.md)の手順 4 で、Pop ごとにネコかどうか、ネコでなければ時計かどうかを決めたあと、ネコでも時計でもなかった Pop に対して、確率 `goldenRate` で金のモグラにする。判定は Pop 1 体につき 1 回。乱数は、その Pop の時計判定の直後に、同じ乱数源から 1 回引く。順序は、ネコ判定 → 時計判定 → 金の判定 → 次の Pop。ネコの Pop と時計の Pop では金の判定の乱数を引かない。乱数が `goldenRate` 未満なら金のモグラ、`goldenRate` ちょうど以上ならモグラ。金のモグラは、ネコでも時計でもないので、おとりの抽選（手順 5）の対象にならない。
- **状態遷移**: 予兆（telegraph）は `telegraphMs`（モグラと同じ）。そのあとの up の長さだけが `goldenLifetimeMs`（モグラは `popLifetimeMs`）。出現時刻を s とすると、s ≤ t < s + `telegraphMs` が telegraph、s + `telegraphMs` ≤ t < s + `telegraphMs` + `goldenLifetimeMs` が up、それ以降は消えている。
- **同時数**: 金のモグラも Pop なので、同時数の上限（`maxActive`／`maxActiveMid`／`maxActiveLate`）に数える。
- **開始**: Game の開始から出る（段階によらない）。
- **叩き**: up の金のモグラを、[叩きの判定](../spec.md)と同じ判定（距離が `hitRadius` 以下のうち最も近い 1 体、同じ距離なら穴の番号が小さいほう）で叩いたら、スコアに `scoreGolden`（+50）を加算し、`streak` を 1 増やす。連続の倍率はかけない（`streak` が何でも +50）。ネコの減点・スコアの下限の規則は変わらない。
- **連続**: 金のモグラを叩くと、`streak` はモグラと同じく 1 増える（途切れない）。その叩きの加点は倍率の影響を受けないが、叩いたあとの `streak` が、次のモグラの倍率の決定に使われる（例: `streak` 4 で金を叩くと +50、`streak` 5 になり、次のモグラは ×2 の +20）。
- **時間切れ**: 叩かれずに時間切れで消えた金のモグラは、何もしない（加点・減点・`streak` の変化なし）。
- **予兆中**: 予兆（telegraph）の金のモグラは叩けない。予兆中の穴を叩いたときは、空振りとして扱う（連続は 0 に戻り、スコアは変わらない）。
- **残り時間 0 以降**: `ending` に入ったあとの叩きは、金のモグラでも無視する（`ending` に入るフレームの叩きは有効。[Game の進行フェーズ](../spec.md)の順序による）。
- **Demo のボット**: 金のモグラを候補にも叩く対象にもしない（ボットは金のモグラを叩かないので、Demo で金の加点は起きない）。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `goldenRate` | 0.05 | ネコでも時計でもなかった Pop が金のモグラになる確率。ネコでない Pop は 1 ラウンドに約 46 体（時計を含む。60 本の試走の平均）なので、時計を除く約 44 体に対して約 2 回（叩かないときの推定）。 |
| `goldenLifetimeMs` | 1500 | 金のモグラが up（叩ける）でいる時間。モグラの `popLifetimeMs`（3000）の半分。予兆 `telegraphMs`（800）と合わせて約 2.3 秒で駆けつける必要がある。 |
| `scoreGolden` | +50 | 金のモグラを叩いた加点（連続の倍率はかけない。モグラの +10 の 5 倍で、倍率 ×3 の +30 より大きい）。 |
| `goldenArrowColor` | RGB(255, 170, 0) | 金のモグラの方向矢印の色（オレンジ寄りの濃い金色）。 |
| `goldenArrowOutlinePx` | 3 px | 金のモグラの方向矢印の白い縁取りの太さ（論理 px）。 |

## テスト観点

- 出現（乱数は注入する）: ネコでも時計でもない Pop の金の判定は、乱数が `goldenRate`（0.05）未満（例: 0.0499）で金のモグラ、ちょうど 0.05 と、それ以上（0.05、0.9）ではモグラ。
- 出現: 金の判定の乱数は、ネコでも時計でもない Pop ごとに 1 回だけ引く。ネコの Pop では引かない（引いた回数 0）。時計の Pop でも引かない。順序（ネコ判定 → 時計判定 → 金の判定 → 次の Pop）が固定されている（注入した乱数列で、`friendRate` = 0.25・`itemRate` = 0.05・`goldenRate` = 0.05 のとき、例: 乱数列 0.9（ネコではない）・0.5（時計ではない）・0.01（金のモグラ）・0.1 … のとき、1 体目は金のモグラで、4 つ目の乱数（0.1）が次の Pop のネコ判定に使われる）。
- 出現: 金のモグラはおとりにならない（おとりの抽選はネコの Pop だけが引く）。
- 状態: 出現からちょうど `telegraphMs`（800ms）で up になり（その直前は telegraph）、up の開始からちょうど `goldenLifetimeMs`（1500ms）で消える（出現から 2299ms は up、2300ms は消えている。モグラは 3799ms まで up）。
- 叩き: up の金のモグラを叩くと `scoreGolden` が加わる。叩く直前の `streak` が 0・4・5・12 のとき、いずれも +50（倍率 ×1・×1・×2・×3 のどれでも倍率をかけない）。叩いたあとの `streak` は 1 増える（0 → 1、4 → 5、12 → 13）。
- 叩き: `streak` 4 で金を叩く → `streak` 5・スコア +50。次のモグラは ×2 で +20。`streak` 9 で金を叩く → `streak` 10。次のモグラは ×3 で +30。
- 叩き: 距離ちょうど `hitRadius` は当たり、それを超えると外れる。金のモグラとモグラが範囲内にあるとき、距離が近いほう。距離が同じなら穴の番号が小さいほう（金でもモグラでも）。
- 叩き: telegraph の金のモグラは叩けない（空振りになり、`streak` は 0 に戻る。スコアは変わらない）。
- 時間切れ: 叩かれずに消えた金のモグラは、スコア・`streak` のどれも変えない（`streak` 7 のままで、次のモグラは ×2）。
- 倍率の予告: 金のモグラを叩いて `streak` が 5（または 10）になったとき、「×2!」（「×3!」）が返る。`streak` が 0 に戻ったあとのことも、モグラと同じ。
- ending: `ending` に入った後の更新で届いた金のモグラの叩きは無視する（ending に入るフレームの叩きは有効）。
- 同時数: 金のモグラも Pop として数える（上限が 4 のとき、金 1 体とモグラ 3 体で、新しい Pop は出ない）。
- 矢印の対象と色（Pop の種類から、矢印を出すか・どの色かを返すロジックで、手計算の値で）: 金のモグラは、telegraph または up で穴の中心が画面外なら矢印が出て、色は `goldenArrowColor`・縁取りは `goldenArrowOutlinePx`。画面内（境界上を含む）なら出ない。モグラとおとりのネコの矢印は、黄色・縁取りなしのまま。通常のネコと時計は対象外のまま。おとりのネコが金色になることはない。叩かれた、または消えた金のモグラは対象外。
- Demo: ボットが金のモグラを叩くことはない（seeded の試走で、金のモグラへの叩きが 0。金のモグラは出ている試走で）。ボットの目標にも選ばない。
- 回帰（[完了条件](#完了条件)の変えないもの。既存の単体テストがそのまま通ること。次の値で確かめる）:
  - スコアと連続: モグラ +10（`streak` 0〜4）・5〜9 で +20・10 以上で +30、ネコ −20（倍率なし。0 未満にならない）、時計を叩いても `streak` とスコアは変わらず残り時間が 3000ms 増える。
  - 当たり判定と時間: `hitRadius` = 70（ちょうどは当たり）、`telegraphMs` = 800、モグラの `popLifetimeMs` = 3000（出現から 3799ms まで up、3800ms で消える）。
  - 出現: 前半の間隔 1200・上限 4、中盤 1000・5、終盤 800・6（段階の境目 20000・40000）、`friendRate`・`decoyRate`・`comboRate`・`comboSize` の値と、コンボとおとりの規則。
  - 矢印: モグラとおとりのネコの矢印は、黄色・縁取りなしのまま、位置・大きさ・脈動も同じ。通常のネコと時計に矢印は出ない。矢印の数の上限は `maxActiveLate`。
  - 演出・レイアウト・操作・Title と Result の遷移は変わらない（QA のスクリーンショット）。Demo のボットの品質の閾値（`demoBot.play.test.ts`）は変えずに通る。
  - 出現計画の乱数の列を決める既存のテストは、金の抽選を含めた期待値に更新する（金の抽選の乱数が、ネコでも時計でもない Pop ごとに挿入され、以降の乱数の位置がずれる。合意済みの変更。更新するのは期待値だけで、出現の規則の判定は変えない）。

## 完了条件

- 金のモグラを叩くと +50 が加わり、倍率がかからず、`streak` が 1 増えること（テスト観点・`game-qa` で確かめる）。
- 金のモグラの up は `goldenLifetimeMs`（1.5 秒）で、モグラ（3 秒）より短いこと（テスト観点）。
- 画面外の金のモグラに、モグラ・おとりと見分けのつく金色の矢印（縁取りつき）が予兆から出ること。モグラとおとりの矢印は変わらないこと。おとりのネコに金色の矢印が出ないこと（単体テストとスクリーンショット）。
- 金のモグラの「叩いた」の演出と「+50」の文字が、390 × 844 と 375 × 550 で画面に収まること（`game-qa` のスクリーンショット）。
- Demo のボットが金のモグラを叩かないこと（テスト観点）。Demo のボットの品質（[Title とデモ](title-demo.md)の品質の閾値、`demoBot.play.test.ts`）は、金のモグラを足したあとも、閾値を変えずに通ること。通らなければ閾値は動かさず、出方の仕様を `game-spec` に戻して見直す。
- 難しさへの影響は、実装後に、seeded の試走（Demo のボットとは別の、金のモグラを叩くボット）で測る。測った値は PR の説明に書く（この仕様の完了条件の閾値にはしない）。
- 変えないもの（回帰条件。金のモグラを足しても変わらないこと）: 操作の効き方（ドラッグ、タップ、クリック、Space、矢印キー、端スクロール、複数の指）、モグラとネコの加点・減点・連続の規則（モグラ +10・倍率、ネコ −20、0 未満にならない）、時計の規則、判定の段階・間隔・同時数の上限の数（同時数には金のモグラも入る）、当たり判定（`hitRadius`）、予兆（`telegraphMs`）と、モグラの出ている時間（`popLifetimeMs`）、おとりの規則と抽選、方向矢印の規則・位置・大きさ・脈動（モグラとおとりの矢印の色・縁取りも）、既存の演出、縦画面・横画面のレイアウト、Title・Result の遷移（ブラウザ QA で前回と同じ結果）。
