# モグラ巡り (moleroam)

## コンセプト

画面に収まらない広い盤面をスクロールしながら遊ぶモグラ叩き。画面外に出たモグラは画面端の矢印で方向がわかる。モグラに混じって出る「叩いてはいけない相手（ネコ）」を叩くと減点になり、ネコには矢印が出ない。60秒間のスコアを競う。

## ターゲットプレイヤー

スマホ（主）やPCで、隙間時間にサッと遊びたいカジュアル層。説明を読まなくても、タイトル画面の一言説明だけで遊べること。

## コアループ

矢印を見て盤面をスクロールする → 穴の予兆を見つけ、出てきたモグラを叩く（加点）。ネコは叩かない（叩くと減点）。放置したモグラは引っ込む。60秒で終了し、スコアを表示する。隣り合う穴に3匹がまとめて出る「コンボ出現」が時々ある。

## 操作仕様

入力デバイスは次の3系統。どれでも最後まで遊べること。

| 系統 | スクロール | 叩く |
|---|---|---|
| タッチ | ドラッグ | タップ（ドラッグ量が `dragThresholdPx` 未満） |
| マウス | ドラッグ、または矢印キー、またはカーソルを画面端に寄せる（端スクロール） | クリック（ドラッグ量が `dragThresholdPx` 未満）、または Space |
| キーボードのみ | 矢印キー | Space |

Title と Result はキーボードでも進められる: Title は Enter／Space でスタート、Result は Enter／Space で「もう一度」、Esc で「タイトルへ」。Result のキー・ボタンは `inputGuardMs` の間は無視する。

- **叩く位置**: タップ／クリックは離した位置。Space は、最後に観測したマウスカーソルがキャンバス内にあればその位置、なければ（マウスを一度も動かしていない、タッチ操作中、キャンバス外に出た後）画面中央（画面中央には常に白い照準リングを表示する）。Space は keydown の 1 回につき 1 回だけ叩く（キーの自動リピートは無視する）。Title／Result で押した Space や Enter は、遷移先の Game では叩きとして数えない。
- **ドラッグ**: 左ボタン（またはタッチ）のみ。押した位置からの移動量が `dragThresholdPx` 以上（ちょうど 10px もドラッグ）になったらスクロール開始。以降の移動分だけ盤面が指（カーソル）に追従する（盤面が指と同じ向きに動く＝視点は逆向きに動く）。ドラッグだった操作は離しても叩かない。キャンバスの外で離したときも叩かない。盤面の端でカメラが止まっている間の指の移動は捨てる（溜めない）。
- **矢印キー**: 押している間 `scrollSpeed` でその向きに視点（カメラ）が動く（右キー＝視点が右へ＝盤面は左へ流れる）。複数キーの同時押しは各軸を足す（斜めは正規化しない）。
- **端スクロール**: マウス（タッチ以外）のカーソルがキャンバス内にあり、ボタンを押していないとき、画面の端から `edgeScrollZonePx` 以内でスクロールする。左端に寄せれば視点が左へ、右端なら右へ動く（上下も同様）。速さは 端=`edgeScrollSpeed`、帯の内側の境界=0 の線形で、軸ごとに独立。カーソルがキャンバス外に出たら止まる。
- **スクロール範囲**: 盤面の外には出ない（カメラを盤面の範囲内に収める）。スクロール源（ドラッグ・矢印キー・端スクロール）は同時に効き、足し合わせる。
- **複数ポインタ**: 最初に押したポインタだけを扱い、追加の指は無視する。
- **入力を受けない期間**: Game の `ending` 期間（下記）はスクロールも叩きも無視する。予兆中の穴を叩くと空振り扱い（モグラはまだ叩けない）。

## 画面・Scene構成

画像・音声アセットは使わず、Phaser の図形（Graphics／Shape）とテキストだけで描く。UIの文言は日本語。

| Scene | 役割 | 次へ進む条件 |
|---|---|---|
| Title | ゲーム名、一言説明、操作説明、スタートボタン | スタートボタンのクリック／タップ、または Enter／Space → Game |
| Game | 盤面・モグラ・ネコ・HUD・矢印の表示と進行 | 残り時間が 0 になり `ending` が終わる → Result |
| Result | スコア表示、リトライ | 「もう一度」ボタン、または Enter／Space → Game。「タイトルへ」ボタン、または Esc → Title |

### レイアウト方針

- キャンバスは 1024 × 768（4:3）の固定論理サイズ。ウィンドウに FIT で拡縮し、余白は背景色で埋める。縦画面でも FIT のまま（縦画面専用レイアウトは作らない）。
- Title: ゲーム名を上部、一言説明と操作説明を中央、スタートボタンを下部中央。
- Game: HUD（スコアと残り時間）は画面左上に固定表示。方向矢印は画面端の内側、照準リングは画面中央、ともに盤面と一緒にスクロールしない。
- Result: スコアを中央に大きく、その下に「もう一度」「タイトルへ」ボタンを縦に並べる。

### Game の盤面

- 盤面は `boardCols` × `boardRows` 個の穴を `holeSpacing` 間隔の格子に並べたもの。穴 i（0 始まり、行優先）の中心は ( `holeSpacing`/2 + (i mod `boardCols`) × `holeSpacing`, `holeSpacing`/2 + floor(i / `boardCols`) × `holeSpacing` )。盤面全体は 2560 × 1920 で、画面の約 2.5 倍。
- 開始時のスクロール位置は盤面の中央（画面中央が盤面中央に来る位置）。
- 背景は緑一色（芝）、穴は暗い茶色の楕円。

### 出ているもの（Pop）の状態遷移

モグラまたはネコ 1 体を Pop と呼ぶ。Pop は穴ごとに同時に 1 体まで。

| 状態 | 期間 | 見た目 | 叩けるか |
|---|---|---|---|
| telegraph（予兆） | 出現から `telegraphMs` | 穴の土ぼこりが揺れる。モグラかネコかは見た目では分からない | 叩けない |
| up（出ている） | telegraph 終了から `popLifetimeMs` | モグラ（茶色の丸）またはネコ（オレンジの丸）が穴から出る | 叩ける |
| 消える | up が `popLifetimeMs` 経過、または叩かれた | 取り除かれる。時間切れで消えても加点・減点はない | — |

- 状態遷移は時間だけで起こる（telegraph → up → 消える）。叩きによる消去は up のときだけ。
- 状態は時刻 t の関数: 出現時刻を s とすると、s ≤ t < s + `telegraphMs` が telegraph、s + `telegraphMs` ≤ t < s + `telegraphMs` + `popLifetimeMs` が up、それ以降は消えている。叩きは、その入力を処理する時刻 t での状態で判定する（入力はその更新の Pop の遷移より先に処理する）。
- 同時に存在する Pop（telegraph と up の合計）は `maxActive` まで。

### Game の進行フェーズ

| フェーズ | 内容 | 次のフェーズへの遷移 |
|---|---|---|
| playing | 残り時間が減り、Pop が出る。入力を受ける | 残り時間が 0 になった更新で `ending` へ |
| ending | 残っている Pop と矢印をすべて消す。入力は無視。HUD は残り 0 で止める | `endingMs` 経過で Result へ（スコアを渡す） |

- Game に入った時点が playing の開始（カウントダウンはない）。最初の出現判定は開始から `firstSpawnDelayMs` 後。
- 叩きの入力処理は、その更新より前に届いたものを残り時間 0 の判定より先に反映する。残り時間 0 の更新以降の入力は無視する（同フレームで入力が先に処理された場合のみ加点・減点される）。

### 方向矢印

- 対象は、状態が telegraph または up のモグラ（ネコには出さない）で、穴の中心が画面外にあるもの。画面内にあるものには出さない。穴の中心がちょうど画面の境界上にあるときは画面内として扱う。
- 矢印は、画面中央から穴の中心へ引いた線を、画面の各辺から `arrowMargin` だけ内側に入れた長方形に切り詰めた位置に置き、穴の中心の方角を向く。黄色の三角形。
- 同時に出せる矢印は `maxActive` 個まで（Pop の上限と同じなので足りなくなることはない）。
- 予兆の段階から矢印は出る（ネコの予兆には出ないので、矢印が出ない予兆はネコとわかる。これは仕様）。

## ルール

- **勝利条件・失敗条件**: なし。60 秒間の合計スコアが結果。時間切れで必ず終わる。
- **スコア**: モグラを叩くと `scoreMole` 加算。ネコを叩くと `scoreFriend`（負値）を加算するが、合計スコアは 0 未満にならない（0 で止まる）。叩いても何も当たらない空振りと、予兆中の穴を叩いたときは増減しない。時間切れで消えた Pop も増減しない。
- **叩きの判定**: 叩いた位置（盤面座標）と、up 状態の各 Pop の穴の中心との距離が `hitRadius` 以下のもののうち、最も近い 1 体を叩いたことにする（距離が同じなら穴の番号が小さいほう）。該当なしは空振り。telegraph の Pop は判定の対象にならない。
- **出現判定**: 最初の判定は開始から `firstSpawnDelayMs` 後。判定を行った時刻に `spawnIntervalMs` を足した時刻が次の判定時刻になる（出現の有無にかかわらず）。1 回の更新で行う判定は最大 1 回（フレームが大きく飛んでも判定をためてまとめて行わない）。判定のとき:
  1. 空き枠（`maxActive` − 現在の Pop 数）が 0 なら何も出さない（空いている穴は 48 個に対し上限が 4 なので、空き枠があれば空いている穴は必ずある）。
  2. 空き枠が `comboSize` 以上で、確率 `comboRate` に当たったら **コンボ出現**: 空いている穴から 1 つを一様ランダムに選び（基点）、基点と、基点の上下左右斜め 8 近傍（盤面の外は含めない）の空いている穴から一様ランダムに（重複なく）選んだ穴を合わせて最大 `comboSize` 個に Pop を出す（近傍の空きが足りなければ少なくなる）。
  3. そうでなければ **通常出現**: 空いている穴から一様ランダムに 1 つに Pop を 1 体出す。
  4. 出す Pop それぞれについて、確率 `friendRate` でネコ、そうでなければモグラ（独立に抽選。コンボがすべてネコになることもある）。
- **時間**: 残り時間は `gameSeconds` 秒から実時間で減る。HUD には切り上げた整数秒を出す。

## 演出・UI

効果はすべて、トリガーのフレームを t = 0 として、指定の長さのちょうど後に消える。同じ効果が再度トリガーされたら重ねて出す（各効果は独立）。`ending` に入ると残っている効果は Game を離れるまで再生してよいが、新しいトリガーは起きない。Game を離れるとき（Scene の終了）に残りはすべて破棄する。

| 効果 | トリガー | 見た目と長さ |
|---|---|---|
| 予兆 | Pop の出現 | 穴に土ぼこりの楕円（約 120 × 50）が出て、左右に小刻みに揺れ続ける。telegraph 終了で消える |
| せり上がり | telegraph の終了 | 本体が穴から下から上へせり上がる（約 150ms）。叩けるのは up の開始から（せり上がり中も叩ける） |
| 叩いた（モグラ） | モグラへの叩き | 本体がつぶれて消える（約 160ms）、黄色い星 8 個が放射状に広がって消える（約 350ms）、「+10」の黄色い文字が上に浮かんで消える（約 600ms）、画面がごく軽く揺れる（`hitShakeMs`、強さ `hitShakeIntensity`。ネコの揺れが動作中ならそちらを優先して追加しない） |
| 叩いた（ネコ） | ネコへの叩き | 画面が赤くフラッシュ（`catFlashMs`、色は `catFlashColor`。動作中に再度起きたら最初からやり直す）、強く揺れる（`catShakeMs`、強さ `catShakeIntensity`。モグラの揺れが動作中でもこちらで上書きする）、本体が赤くなって上に跳ね飛びながら回転して消える（約 400ms）、赤い文字が上に浮かんで消える（約 600ms）。文字は実際に減った量を表し、「-N」（N は実際に減った量。スコアが 0 で減らなかったときは「0」）。演出はスコアが減らなくても出す |
| 時間切れ | Pop の up が終わる | 本体が穴へ引っ込んで消える（約 150ms）。土ぼこりは出ない。加点・減点なし |
| 空振り | 空振り（予兆中の穴への叩きを含む） | 叩いた位置に白いリングが広がって消える（約 300ms）、「miss」の灰色の小さな文字が上に浮かんで消える（約 600ms）。減点はない |

- **描画順（手前ほど後）**: 盤面・穴 < 土ぼこり < 本体（モグラ・ネコ）< 叩きの効果（リング・星・文字）< 方向矢印 < HUD・照準リング・メッセージ。
- **同時発生**: 同じフレームに複数の叩きがあれば効果を 1 つずつ出す。「叩いた」の文字が同じ穴の上で重なってもよい。
- **画面端**: 浮かぶ文字は盤面座標に置くので、画面端付近では一部がはみ出して切れてよい。
- **スコアの表示**: HUD は「スコア N　残り T」のように、スコアと残り秒を常に表示する。スコアが変わった更新で書き換える（アニメーションなし）。
- **Result**: スコアを大きく表示し、「もう一度」「タイトルへ」ボタンを出す。Result に入ってから `inputGuardMs` の間はボタンを受け付けない（直前の叩きの指が誤ってリトライを押さないようにするため）。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| viewW × viewH | 1024 × 768 | 論理キャンバスサイズ |
| boardCols × boardRows | 8 × 6 | 穴の数（48 個） |
| holeSpacing | 320 px | 穴の間隔。盤面は 2560 × 1920、画面の約 2.5 倍 |
| gameSeconds | 60 | 制限時間 |
| firstSpawnDelayMs | 500 | 開始から最初の出現判定までの時間 |
| spawnIntervalMs | 1200 | 出現判定の間隔（予兆と出ている時間を延ばしたので 900 から広げた） |
| maxActive | 4 | 同時に存在できる Pop の上限（予兆中も数える） |
| friendRate | 0.25 | 出た Pop がネコである確率 |
| comboRate | 0.2 | 出現判定のとき、コンボ出現になる確率（空き枠が `comboSize` 以上のとき） |
| comboSize | 3 | コンボ出現で同時に出す最大数（隣り合う穴） |
| telegraphMs | 800 | 予兆の長さ。この間は叩けない（スクロールしている間に引っ込むという声から、予兆を足した） |
| popLifetimeMs | 3000 | 予兆のあと、出ている（叩ける）時間（1800 では画面外から駆けつけるのに足りなかった） |
| hitRadius | 70 px | 叩きの当たり半径（穴の中心から）。本体の半径は 50 px |
| scoreMole | +10 | モグラを叩いた加点 |
| scoreFriend | -20 | ネコを叩いた減点（合計は 0 未満にならない） |
| scrollSpeed | 700 px/s | 矢印キーのスクロール速度（軸ごと） |
| dragThresholdPx | 10 | タップ（クリック）とドラッグの境目 |
| arrowMargin | 40 px | 方向矢印を画面端から内側に置く距離 |
| edgeScrollZonePx | 90 px | マウスの端スクロールの帯の幅 |
| edgeScrollSpeed | 600 px/s | 端スクロールの最大速度（画面の端で最大、帯の内側の境界で 0） |
| endingMs | 500 | 時間切れから Result へ進むまでの時間 |
| inputGuardMs | 300 | Result に入ってからボタンを受け付けない時間 |
| hitShakeMs | 70 | モグラを叩いたときの画面揺れの長さ |
| hitShakeIntensity | 0.003 | モグラを叩いたときの画面揺れの強さ（Phaser のカメラ shake の intensity） |
| catFlashMs | 180 | ネコを叩いたときの赤フラッシュの長さ |
| catFlashColor | RGB(255, 40, 40) | ネコを叩いたときのフラッシュの色 |
| catShakeMs | 260 | ネコを叩いたときの画面揺れの長さ |
| catShakeIntensity | 0.012 | ネコを叩いたときの画面揺れの強さ（モグラの 4 倍） |

演出・UI の節に書いた、上の表にない長さ・大きさ（約 150ms、約 350ms など）は、その節の値を初期値とする。「約」が付く値は目安で、見た目の調整のために ±30% 程度動かしてよい。

## MVP範囲

- 60 秒 × 1 ステージ（固定盤面 8 × 6 穴）
- モグラと、叩いてはいけない相手（ネコ）1 種類
- 予兆、通常出現とコンボ出現
- 方向矢印（モグラのみ）
- タッチ／マウス／キーボードの 3 系統の操作（端スクロールを含む）
- スコア（加点・減点）、HUD、Result とリトライ
- 叩いた／ネコを叩いた／空振りの 3 種類の演出
- Title、Game、Result の 3 Scene

- モグラやネコ以外の種類、アイテム、特殊な動きの敵
- ミニマップ
- 効果音・BGM
- オンラインランキング、共有
- ポーズ機能

## 技術要件

- Phaser 4 / TypeScript / Vite。ESLint エラー 0、Vitest のカバレッジ 90% 以上（ステートメント・分岐・関数・行）。
- 画像・音声アセットを使わない。テンプレートに付いてきた未使用の `public/assets` などは削除する。
- Scene は Title / Game / Result の 3 つ。`preload`・`create`・`update` の責務を分け、入力リスナーは Scene 終了時に解除する。ゲーム状態は Scene のインスタンスに持ち、グローバルに置かない。
- 演出は Phaser の標準機能（カメラの shake／flash、Tween、Shape）を使い、自前で再実装しない。
- 毎フレームの `update` で不要なオブジェクトを作らない（矢印は `maxActive` 個を最初に作って使い回す。Pop の本体・効果は発生時に作り、消えたら破棄する）。
- **純粋ロジック**（Phaser に依存せず、時刻と乱数を引数で受け取って単体テストできる形にする）:
  - 出現判定: 通常出現・コンボ出現の穴選び、ネコ／モグラの抽選（空き枠・空き穴の扱いを含む）、次の判定時刻の計算（1 更新で最大 1 回）
  - ドラッグとタップの判別（移動量が `dragThresholdPx` 以上か）、複数のスクロール源の合成
  - Pop の状態判定（telegraph／up／消える。時刻から決まる）
  - 叩きの判定（up の Pop のうち距離が `hitRadius` 以内で最も近いもの）
  - スコア計算（加点・減点、0 未満にならない）
  - 方向矢印の位置と向き（画面内の判定、画面端への切り詰め）
  - 端スクロールの速度（カーソル位置から軸ごとに −1〜1）
  - 穴の座標、カメラ位置の範囲内への収め方
  - 残り時間の表示用の秒数（切り上げ）
- **Scene の接着部分**（Scene クラスに置く。単体テストの対象外でもよく、ブラウザ QA で確認する）: 入力の受け取りとドラッグ／タップの判別、Pop の本体・効果の生成と破棄、HUD、Scene 遷移。
- 配布は静的サイト。単体ビルド（`npm run build`）と共有ビルド（`task build`）の両方で起動できること。

## テスト観点

純粋ロジックについて、最低限次のケースを単体テストにする（乱数・時刻は注入する）。

- **出現（通常）**: 空いている穴からだけ選ばれる。空きが 1 つなら必ずその穴。空きがなければ出さない。乱数の境界で、ネコの確率ちょうど（`friendRate` 未満でネコ、以上でモグラ）が切り替わる。
- **出現（コンボ）**: 基点と選ばれた穴が基点の 8 近傍に収まる。盤面の角・端の穴が基点のとき、盤面の外の穴を選ばない。近傍の空きが足りないときは `comboSize` より少なくなる。使用中の穴を選ばない。重複しない。
- **空き枠**: 現在の Pop 数が `maxActive` のとき出さない。空き枠が `comboSize` 未満のとき、コンボにならず通常出現になる（`comboRate` 当たりでも）。
- **出現の時刻**: 最初の判定は開始から `firstSpawnDelayMs`（その直前は判定しない）。次の判定は判定時刻 + `spawnIntervalMs`。時刻が大きく飛んだ（例: 10 秒進んだ）更新でも判定は 1 回だけで、次の判定時刻はその判定時刻から数える。
- **ドラッグ判別**: 移動量が `dragThresholdPx` 未満（例: 9.99px）はタップ、ちょうど `dragThresholdPx` 以上はドラッグ。
- **スクロールの合成**: 矢印キー（右＋下の同時押しで両軸）、端スクロール、ドラッグの移動量を足し合わせ、盤面の範囲内に収める。
- **Pop の状態**: 出現からちょうど `telegraphMs` で up になる（その直前は telegraph）。up の開始からちょうど `popLifetimeMs` で消える（その直前は up）。
- **叩きの判定**: 距離ちょうど `hitRadius` は当たり、それを超えると外れる。複数が範囲内なら最も近い 1 体。距離が同じなら穴の番号が小さいほう。telegraph の Pop は対象外。Pop がないとき空振り。
- **スコア**: モグラで `scoreMole` 加算、ネコで `scoreFriend` 加算。スコア 0 でネコを叩いても 0 のまま。スコア 5 でネコを叩くと 0（負にならない）。空振り・予兆中の叩き・時間切れの消滅で増減しない。
- **方向矢印**: 穴の中心が画面内（境界上を含む）なら矢印なし。画面外なら、矢印の位置が `arrowMargin` だけ内側の長方形の上にあり、向きが穴の中心の方角を向く（真上・真下・真横・斜めの手計算の値で確認）。矢印の位置が画面中央と穴の中心を結ぶ線上にある。
- **端スクロール**: カーソルが帯の外なら 0。画面の端で −1／+1。帯の内側の境界で 0、その中間は線形（例: 帯の半分で ±0.5）。軸ごとに独立。
- **カメラ位置**: 盤面の左上・右下を超えるスクロールが範囲内に収まる。開始位置が盤面の中央。
- **穴の座標**: 0 番、`boardCols` − 1 番、`boardCols` 番（2 行目の先頭）、最後の穴の中心座標。
- **残り時間の表示**: 59.001 秒 → 60、1.0 秒 → 1、0.001 秒 → 1、0 秒 → 0。

## 完了条件

- `npm run lint`・`npm run test`・`npm run test:coverage`（90% 以上）・`npm run build` がすべて通る。
- 単体ビルドと共有ビルドの両方で、Title → Game → Result → Game（もう一度）、Result → Title の遷移ができる（スクリーンショットで確認）。キーボードだけ（Enter／Space と Esc）でもこの遷移ができる。
- Game で、タッチ（ドラッグ＋タップ）・マウス（ドラッグ＋クリック、端スクロール）・キーボード（矢印キー＋Space）のそれぞれで、スクロールして叩く遊び方ができる（ブラウザ QA で操作して確認）。
- 画面外のモグラには方向矢印が出て、ネコには出ない。予兆中のモグラにも矢印が出る（スクリーンショットで確認。位置・向きは単体テスト）。
- 予兆の間は叩けず、up の間に叩ける（単体テスト）。叩いた／ネコを叩いた／空振りの 3 つの演出が、それぞれ 1 枚ずつスクリーンショットに撮れて、見た目が互いに違う。
- 60 秒で必ず終わり、Result にスコアが出る。ネコを叩いても合計スコアは 0 未満にならない（単体テスト）。
- コンボ出現: 乱数を固定した単体テストで、隣り合う穴に最大 `comboSize` 個が出る。実機でも遊んでいるうちに時々起こる。
- ハイスコア等は保存されない（ブラウザの保存領域に何も書かない）。
- README.md に、ゲームの目的・ルール・操作方法が書かれている。
