# moleroam（モグラ巡り）

画面に収まらない広い盤面をスクロールしながら遊ぶモグラ叩きです。

## 遊び方

- 盤面は画面の約2.5倍の広さで、48個の穴が並んでいます。モグラは穴から出てきて、しばらくすると引っ込みます。
- 穴の土ぼこりが揺れたら、そこにモグラ・ネコ・時計・金のモグラのどれかが出る合図です。揺れている間（約0.8秒）は叩けません。
- 画面の外にいるモグラは、画面の端の黄色い矢印が方向を教えてくれます。ネコの多くには矢印が出ませんが、一部のネコ（おとり）にはモグラと同じ矢印が出ます。矢印が出ていない穴は必ずネコですが、矢印が出ていてもモグラとは限りません。
- ときどき、隣り合う穴に3匹がまとめて出ます。
- 約20秒ごとに、モグラやネコの出る間隔が短く、同時に出る数が多くなります（最初の20秒は最大4匹、次の20秒は最大5匹、最後の20秒は最大6匹）。

## ルール

- 制限時間は60秒です。時間になると結果画面でスコアが出ます。
- モグラを叩くと +10 点です。ネコを叩くと −20 点です（スコアは0未満になりません）。
- 途切れずにモグラを叩き続けると、点が増えます。5 匹叩くと次の 1 匹から +20 点、10 匹叩くと次の 1 匹から +30 点です（上限は +30 点）。倍率が上がるときは、画面に「×2!」「×3!」と出ます。
- 何もない場所を叩いたときや、予兆中の穴を叩いたとき（空振り）と、ネコを叩いたときは、連続が途切れて +10 点に戻ります。モグラが自分で引っ込んでも途切れません（引っ込んだ跡を叩くと空振りで途切れます）。ネコの −20 点は変わりません。
- 何もない場所を叩いたときや、予兆中の穴を叩いたときは、スコアは増減しません。
- 引っ込んだモグラやネコは、点数に影響しません。
- 時計（白い丸に針の絵）を叩くと、残り時間が +3 秒増えます。スコアと連続は変わりません。時計は叩かなくても構いません。
- ときどき、金色のモグラ（金のモグラ）が出ます。出ている時間が短く（約1.5秒）、叩くと +50 点です（連続の倍率はかかりません。連続は 1 つ増えます）。画面の外にいるときは、金色（白い縁取りつき）の矢印が方向を教えてくれます。叩かずに引っ込んでも、点も連続も変わりません。
- スコアは保存しません。

## 操作方法

| | スクロール | 叩く |
|---|---|---|
| タッチ | ドラッグ（1 本の指） | タップ（スクロール中でも、もう 1 本の指のタップで叩けます。指は 2 本まで） |
| マウス | ドラッグ、矢印キー、マウスを画面の端に寄せる | クリック、または Space（カーソルの位置を叩く） |
| キーボードのみ | 矢印キー | Space（画面中央の白い丸の位置を叩く） |

- スマホは、横持ちでも縦持ちでも遊べます。縦持ちでは、盤面が縦長（6 列 × 8 行）になり、画面の高さいっぱいに表示されます（縦に長い端末ほど、盤面の見える範囲が広がります）。向きは、画面が切り替わるとき（スタート、結果、もう一度）に決まります。
- タイトル画面は Enter／Space でスタートできます。
- タイトル画面の背後では、ボットが本物のゲームを遊ぶ様子（矢印をたどってスクロールし、モグラを叩き、おとりのネコは見送る）が約 40 秒ごとに流れます。
- 結果画面は Enter／Space で「もう一度」、Esc で「タイトルへ」です。

## 開発

```bash
pnpm install
pnpm --filter moleroam dev            # 開発サーバー
pnpm --filter moleroam lint           # ESLint
pnpm --filter moleroam test           # Vitest
pnpm --filter moleroam test:coverage  # カバレッジ (90%以上)
pnpm --filter moleroam build          # 静的サイトのビルド
```

詳細な仕様は [`docs/spec.md`](docs/spec.md) を参照してください。
