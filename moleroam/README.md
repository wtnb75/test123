# moleroam（モグラ巡り）

画面に収まらない広い盤面をスクロールしながら遊ぶモグラ叩きです。

## 遊び方

- 盤面は画面の約2.5倍の広さで、48個の穴が並んでいます。モグラは穴から出てきて、しばらくすると引っ込みます。
- 穴の土ぼこりが揺れたら、そこにモグラかネコが出る合図です。揺れている間（約0.8秒）は叩けません。
- 画面の外にいるモグラは、画面の端の黄色い矢印が方向を教えてくれます。ネコには矢印が出ません。
- ときどき、隣り合う穴に3匹がまとめて出ます。

## ルール

- 制限時間は60秒です。時間になると結果画面でスコアが出ます。
- モグラを叩くと +10 点です。ネコを叩くと −20 点です（スコアは0未満になりません）。
- 何もない場所を叩いたときや、予兆中の穴を叩いたときは、増減なしの空振りです。
- 引っ込んだモグラやネコは、点数に影響しません。
- スコアは保存しません。

## 操作方法

| | スクロール | 叩く |
|---|---|---|
| タッチ | ドラッグ | タップ |
| マウス | ドラッグ、矢印キー、マウスを画面の端に寄せる | クリック、または Space（カーソルの位置を叩く） |
| キーボードのみ | 矢印キー | Space（画面中央の白い丸の位置を叩く） |

- タイトル画面は Enter／Space でスタートできます。
- 結果画面は Enter／Space で「もう一度」、Esc で「タイトルへ」です。

## 開発

```bash
pnpm install
pnpm --filter moleroam dev            # 開発サーバー
pnpm --filter moleroam lint           # ESLint
pnpm --filter moleroam test           # Vitest
pnpm --filter moleroam test:coverage  # カバレッジ (90%以上)
pnpm --filter moleroam build          # 静的サイトのビルド
```

詳細な仕様は [`docs/spec.md`](docs/spec.md) を参照してください。
