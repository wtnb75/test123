# ゲームオーバーの表示

`docs/spec.md` の「画面・Scene 構成」の一部。`Game` で死亡したときの表示（全爆弾の開示・色分け、墓石画面）と、RETRY / NEW GAME / TITLE のボタンと入力を、独立して書いたもの。`docs/spec.md` と合わせて 1 つの spec である。

## 概要

死亡の表示は 2 段階で、1 段目は全爆弾を開示して色分けした盤面、2 段目は盤面を暗くして墓石と RETRY / NEW GAME / TITLE のボタンを重ねた墓石画面である。死んだステージをやり直す（RETRY）・新しいゲームを始める（NEW GAME）・`Title` へ戻る（TITLE）の 3 つの出口がある。墓石画面は、失敗を「やり直し」でなく「どこまで潜ったかの記録」として見せる（ルール・スコアは変えない）。

## 操作仕様

ゲームオーバーの画面の入力（R / T / 他のキー、押し始めと離し、`resize`）は、下の「画面・Scene構成」の「ゲームオーバーの表示」と「状態遷移（死亡後）」に書く。要点: R は 1 段目からでも RETRY、T は TITLE。1 段目のそれ以外のキーと、1 段目の画面の押して離す操作は、2 段目（墓石画面）へ進むだけ。2 段目では、R は RETRY、T は TITLE、それ以外のキーと、RETRY / TITLE の外で離すことは NEW GAME。

## 画面・Scene構成

### ゲームオーバーの表示

- ゲームオーバーの表示（1 段目）: 全爆弾の開示。論理的に確定できた爆弾（橙）・安全マス（緑）・誤ったフラグ（紫）の色分け。`DeathDelay` の間は、「STAGE」を除くキー・ポインタの入力を受け付けない。1 段目では盤面のスクロール・移動・フラグ・仮想パッドは受け付けない（盤面は死亡時のカメラの位置のまま）。「RETRY [R]」「NEW GAME」ボタンと、その 1 段下に「TITLE [T]」ボタンは、2 段目（墓石画面）に入ったときに出す（「TITLE」は、ゲームオーバーの画面だけにある）
  - R キー（1 段目・2 段目のどちらでも）・「RETRY」ボタンの上で離す（2 段目）: 死んだステージ番号を、新しく生成した盤面でやり直す（同じ盤面ではなく、乱数で作り直す）。
  - T キー（1 段目・2 段目のどちらでも）・「TITLE」ボタンの上で離す（2 段目）: `Title` へ戻る（`Game` の状態を捨てて `Title` を始める。`Title` はデモを最初から流し、開始の門も新しい（[spec/title.md](title.md)）。そこで Start すると、`Game` は開始ステージ（`docs/spec.md` の「開始ステージの決め方」）から始まる。ハイスコアのセッション最大は残り、保存された値・開始ステージはこの遷移で書き換えない）。
  - 2 段目で、それ以外のキー、「RETRY」「TITLE」の外のどこかで離す（NEW GAME ボタンの上を含む）: 新しいゲーム（`Game` を作り直し、開始ステージ（`docs/spec.md` の「開始ステージの決め方」）から）
  - 再開・遷移の要求（RETRY・NEW GAME・TITLE）は、最初の 1 回だけを受け付ける（同じフレームに 2 つ以上届いても、先に処理された 1 つだけが効く）
  - 1 段目で、R・T 以外のキー（修飾キーだけを含む。自動リピートは除く）と、1 段目の画面で押し始めた指の離し（どこで離しても。押し始めが「STAGE」ボタンの上だった指を除く）: 2 段目へ進む（下の「状態遷移（死亡後）」）。`dying`（`DeathDelay`）の間に押し始めた指は、1 段目で離しても何もしない（1 段目に入ってから押し始めた指だけがきっかけになる）。システムによって中止された（cancel）タッチは、遷移のきっかけにならない。
  - T キーは、プレイ中・`DeathDelay`・`ClearDelay` の間は何も起こさない。ボタンの範囲は、画面の座標（ポインターの位置）で、境界を含み、どのマウスボタンの離しでもよい。ボタンの位置は、画面の大きさ（幅・高さ）から「ボタン（RETRY / NEW GAME）」「ボタン（TITLE）」の式で決める。ボタンが出ている間（2 段目）に画面の大きさが変わった（`resize`。端末の回転・ウィンドウの変更）ときは、そのたびに、新しい大きさで 3 つのボタンの絵と範囲、墓石（下の「墓石画面（2 段目）」）を置き直す。暗幕は新しい画面全体を覆う大きさにし、「†」は盤面の一部として盤面と同じ位置のままにする（押し始めの記録は変えない。離したときは、離した時点の配置で判定する。リサイズより前に押し始めた指でも、ボタンが出てからの押し始めなら、離した位置で決まる。ボタンが出る前に押し始めた指は、`resize` があっても離しは何もしない）。ボタンが出る前（`DeathDelay` の間と 1 段目）に変わったときは、ボタン・墓石・暗幕を出さず、出る（2 段目に入る）ときの大きさで置く。ボタンが出ていない間（`DeathDelay` の前、RETRY / NEW GAME / TITLE・STAGE のジャンプで取り消された後、`Game` を離れた後）の `resize` は、ボタンを作らず・出さず、何も起こさない。幅・高さとも 320 px 以上の画面で、3 つのボタンは画面に収まる。ボタンは仮想パッド・FLAG の絵より手前に描き、ゲームオーバーの画面ではパッドは押し始めを受け付けない（小さい画面でボタンがパッドの絵に重なってもよい）
- 死亡したとき、仮想パッドの押下の状態とリピートを解除する（RETRY の後に、指を置いていないのに動かない）。押しっぱなしのキーの自動リピート（`repeat`）は、RETRY / NEW GAME / TITLE のきっかけにならない（押し直したキーだけがきっかけ。`KeyR` は修飾キーが付いていても RETRY、`KeyT` は修飾キーが付いていても TITLE、それ以外のキー（修飾キーだけを含む）は、2 段目では NEW GAME、1 段目では 2 段目へ進むだけ）

### 状態遷移（死亡後）

| 段階 | 期間 | 見えるもの | 受け付ける入力 | 次へ |
|---|---|---|---|---|
| 死亡直後（`dying`） | 死亡の瞬間から `DeathDelay` | 全爆弾の開示・色分け・HUD の凡例の行・「†」 | 「STAGE」だけ | `DeathDelay` が過ぎると 1 段目 |
| 1 段目（`gameover`） | `DeathDelay` が過ぎてから、2 段目に入るまで | 死亡直後と同じ（ボタン・墓石は無い） | R（RETRY）・T（TITLE）、R・T 以外のキーと押して離す操作（2 段目へ）、「STAGE」 | 入力で 2 段目 |
| 2 段目（`grave`） | 2 段目に入ってから、RETRY / NEW GAME / TITLE か STAGE のジャンプまで | 盤面を暗くした上の墓石と 3 つのボタン | `GraveInputLock` の間は「STAGE」だけ。過ぎたら R（RETRY）・T（TITLE）・それ以外のキー（NEW GAME）、押して離した位置（RETRY / TITLE / それ以外は NEW GAME）、「STAGE」 | RETRY・NEW GAME・TITLE・STAGE のジャンプ |

- 2 段目への遷移は、トリガーの入力を処理したそのフレームのうちに行い（待ち時間・アニメーションは無い）、墓石と暗幕とボタンを同じフレームに出す。1 回だけ起きる（同じフレームに 2 つ以上届いても、先に処理された 1 つだけが効く。R・T も同じ「最初の 1 回」で、先に処理されたものが勝つ）。
- 2 段目に入るとき、押し始めの記録をすべて破棄する。1 段目で押し始めた指（2 段目への遷移のきっかけの指を含む）は、離しても何も起こさない（遷移のきっかけの離しが、そのまま NEW GAME・RETRY・TITLE にならない）。2 段目で受け付けるのは、2 段目に入ってから押し始めた指の離しだけである（既存の「ボタンが出てからの押し始め」の規則と同じ）。`GraveInputLock` の間に押し始めた指は、ロックが明けてから離しても何もしない（`DeathDelay` の間に押し始めた指と同じ。続けて押したタップが NEW GAME にならない）。
- キーは、押し直したキーだけがきっかけになる（自動リピートは、1 段目の遷移のきっかけにも、2 段目の RETRY / NEW GAME / TITLE のきっかけにもならない）。2 段目に入る前から押し続けているキーが、2 段目の NEW GAME のきっかけにならない（押し直しが要る）。
- 「STAGE」のジャンプは、どの段階でも受け付け、待っている次のステージの開始・墓石・暗幕・ボタン・「†」・`DeathDelay` を取り消す（ジャンプしたステージの開始で、すべて消える）。RETRY・NEW GAME・TITLE も同じく、墓石・暗幕・「†」を残さない。
- 2 段目から 1 段目へ戻る操作は無い。

### 墓石画面（2 段目）

- **「†」**: 死亡したとき、`player` の位置のマス（移動・コード操作のどちらで死んでも、そのときのプレイヤーのマス。移動で死んだときは踏んだマス、コード操作で死んだときは自分のマス）の「@」の印を「†」に置き換える。同じ位置・同じ大きさで、盤面の一部として「@」と同じ層に描く（「HUD のメッセージとステータス」の描画順のとおり、帯の奥）。死亡直後から出ており、RETRY・NEW GAME・TITLE・STAGE のジャンプで消える。「@」の印は、死亡後は出さない。
- **暗幕**: 画面全体を覆う黒（`GraveDimColor`）の矩形を不透明度 `GraveDimAlpha` で、2 段目に入ったときから重ねる。`scrollFactor` 0。層は、盤面（プレイヤーの強調・「@」・「†」を含む）の手前、HUD の帯・HUD の文字の奥。したがって HUD（帯・文字）は暗くならず、仮想パッド・FLAG・STAGE・GOAL の矢印は暗幕の手前（変更前の層のまま）に残る。入力は遮らない（押し始めの判定は暗幕と関係なく、画面の座標で決まる）。
- **墓石**: 画面の横中央（中心 x = W / 2）に、文字で描いた Rogue 風の墓石の絵を出す。絵の下端 = RETRY / NEW GAME の行の上端 − `GraveGap`（RETRY / NEW GAME の行の上端 = H × 0.72 − 22）。絵は等幅フォント（`GraveArtFont`）の文字を、1 行ずつ `GraveArtRowHeight` の高さで上から並べたもので、すべての行を同じ長さ（絵の幅 = max(`GraveArtWidth`, 最も長い行の文字数)）に右の空白で埋め、1 つのかたまりとして横中央に揃える（行ごとに中央揃えにしない。文字の列が縦に揃うこと）。行の位置は、各行の行ボックス（高さ `GraveArtRowHeight`）の上端から順に積み、絵の下端 = 最後の行ボックスの下端とする。絵の裏に、絵の幅（1 文字の幅 × 文字数）+ 左右 `GravePlatePadX`、高さは絵と同じ（縦の余白は 0）の矩形（`GravePlateColor`・不透明度 `GravePlateAlpha`）を敷く。層は、仮想パッド・FLAG・STAGE の手前、3 つのボタンの奥。入力は遮らない。
- **絵の行**（`center(s, w)` = 文字列 `s` を幅 `w` の中央に置く。左の空白 = floor((w − `s` の長さ) / 2)、残りが右の空白。`s` が `w` より長いときは `s` のまま。内側の幅 `GraveInner` = 22、外側の幅 `GraveArtWidth` = 24。`<n>` = 死んだステージ番号、`<s>` = ステージ番号 − 1、`<h>` = 死亡後のハイスコア（HUD のステータス行の `High` と同じ値）。英語）:

  変形 A（全部。新記録のときだけ 11 行目が入る。12 行・新記録で 13 行）:

  | 行 | 内容 |
  |---|---|
  | 1 | 空白 4 + `_` 16 |
  | 2 | 空白 3 + `/` + 空白 16 + `\` |
  | 3 | 空白 2 + `/` + center(`REST`, 18) + `\` |
  | 4 | 空白 1 + `/` + center(`IN`, 20) + `\` |
  | 5 | `/` + center(`PEACE`, 22) + `\` |
  | 6 | `\|` + 空白 22 + `\|` |
  | 7 | `\|` + center(`Stage <n>`, 22) + `\|` |
  | 8 | `\|` + center(死因 1, 22) + `\|` |
  | 9 | `\|` + center(死因 2, 22) + `\|` |
  | 10 | `\|` + center(`Score:<s>  High:<h>`, 22) + `\|`（区切りは半角スペース 2 つ） |
  | 11（新記録のときだけ） | `\|` + center(`New record!`, 22) + `\|` |
  | 次 | `\|` + `_` 22 + `\|` |
  | 最後 | 地面: `_)/\_//(\/(/\)/\//\/\|_)_`（24 文字） |

  死因 1 / 死因 2: 結果が `bomb-without-flag`（爆弾を旗なしで踏んだ・コード操作で開いたマスが爆弾だった）→ `killed by a` / `mine`。結果が `false-flag`（爆弾でないマスの旗を踏んだ）→ `stepped on a` / `false flag`。

  変形 B（`REST IN PEACE` を 1 行にする。9 行・新記録で 10 行）: 1 行目・2 行目は A と同じ。3 行目 = 空白 2 + `/` + center(`R.I.P.`, 18) + `\`、4 行目 = 空白 1 + `/` + center(`Stage <n>`, 20) + `\`、5 行目 = `/` + center(死因 1, 22) + `\`、6 行目 = `\|` + center(死因 2, 22) + `\|`、7 行目 = スコアの行（A の 10 行目と同じ）、（新記録のときだけ）新記録の行、`\|` + `_` 22 + `\|`、地面。

  変形 C（小さい石。地面なし。5 行・新記録で 6 行）: 1 行目 = 空白 2 + `_` 20、2 行目 = 空白 1 + `/` + center(`R.I.P. Stage <n>`, 20) + `\`、3 行目 = `\|` + center(死因の 1 行, 22) + `\|`、4 行目 = スコアの行、（新記録のときだけ）新記録の行、`\|` + `_` 22 + `\|`。死因の 1 行: `bomb-without-flag` → `killed by a mine`、`false-flag` → `stepped on false flag`。

  行が内側の幅（22 文字）より長いとき（例: `Score:<s>  High:<h>` が、スコアとハイスコアが 5 桁以上で 23 文字になる）は、切らずにそのまま置く。その行の右の `|` だけが 1 文字右に出て、絵の幅は最も長い行に合わせて広がる（石の輪郭は崩れてよい）。表の `\|` は文字としての `|`、`\` は 1 文字のバックスラッシュである。変形 C の死因の行 `stepped on false flag`（21 文字）が左だけ壁に接するのは、左の空白を切り捨てる規則のとおり（意図どおり）。
- **新記録**の行: `<s>` が、この死亡の前のハイスコア（max(保存値, セッション最大)）より大きいときだけ入れる。保存の書き込みの成否には関係しない。同じ・小さいとき、`<s>` = 0 でハイスコア 0 のときは入れない。
- **変形（画面が狭いとき）**: 使える高さ = 絵の下端 − (HUD の帯の下端 + `GraveTopMargin`)。A → B → C の順に、絵の高さ（行数 × `GraveArtRowHeight`）が使える高さ以内の最初のものを使う。C が収まらなくても C を使う（上端は帯に重なってよく、そのとき絵と矩形は帯・HUD の文字・「STAGE」の絵の手前に出て隠してよい。「STAGE」の入力は生きている。下端は固定なのでボタンには重ならない。規定の最小画面（667x310・568x320・375x550・390x844・1280x720・320x568）では、C が収まるので起きない）。画面の大きさが変わったとき（`resize`）は、新しい大きさと帯の下端で選び直す。
- 絵の文字の色は、本文を明るい灰色、新記録の行を目立つ色（`GraveRecordColor`）とする（色の値は実装裁量）。
- HUD のメッセージ行・ステータス行・凡例の行は、1 段目・2 段目とも変えない（文言・位置・帯）。
- 墓石・暗幕は `Game` の Scene にだけあり、`Title` とデモには出ない。時間による変化は無い（出るフレームから、消えるまで一定。`GraveDimAlpha` も一定）。

## ルール

なし（死亡条件・スコア・ハイスコアの保存は `docs/spec.md` の「ルール」「スコア」のとおり）。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `DeathDelay` | 600 ms | 死亡してから 1 段目（入力を受け付けるまで）。RETRY / NEW GAME / TITLE のボタンは 2 段目で出す |
| `GraveInputLock` | 300 ms | 2 段目に入ってから、RETRY / NEW GAME / TITLE の入力を受け付けるまで（続けて押したキー・タップが、墓石を見る前に NEW GAME にならない）。2 段目に入ったフレームを t = 0 として、`t < GraveInputLock` は受け付けない（ちょうど 300 ms から受け付ける） |
| `GraveDimColor`・`GraveDimAlpha` | `#000000`・0.55 | 2 段目の暗幕。盤面の色分けがまだ読め、墓石が読める濃さ（初期値。`game-polish` で見て調整してよい） |
| `GraveArtFont`・`GraveArtRowHeight` | 14 px 等幅・18 px | 墓石の絵の文字の大きさと、1 行の高さ（主な情報は 14 px 以上。AGENTS.md 4.6） |
| `GraveInner`・`GraveArtWidth` | 22 文字・24 文字 | 石の内側の幅と、絵全体（外側）の幅。幅 24 文字 ≒ 200 px なので、`W` ≥ 320 で左右に 50 px 以上残る |
| `GraveGap` | 12 px | 絵の下端と、RETRY / NEW GAME の行の上端の間隔 |
| `GraveTopMargin` | 8 px | 使える高さを決める、HUD の帯の下端と絵の上端の最小の間隔 |
| `GravePlateColor`・`GravePlatePadX`・`GravePlateAlpha` | 盤面の背景色と同じ濃い色・8 px・0.85 | 絵の裏の矩形の左右の余白と不透明度（暗幕を通して盤面の数字が透けても、絵が読める濃さ。初期値） |
| 墓石の絵の高さ | A: 12 行 = 216 px（新記録で 13 行 = 234 px）、B: 9 行 = 162 px（10 行 = 180 px）、C: 5 行 = 90 px（6 行 = 108 px） | 行数 × `GraveArtRowHeight` |
| ボタン（RETRY / NEW GAME） | 140 × 44 px・隙間 16 px・画面の高さの 0.72 の位置 | 2 段目（墓石画面）に出す。RETRY の中心 x = W / 2 − 78、NEW GAME の中心 x = W / 2 + 78、中心 y = H × 0.72（W・H は画面の幅・高さ） |
| ボタン（TITLE） | 140 × 44 px・RETRY / NEW GAME の行の 16 px 下 | 中心 x = W / 2、中心 y = H × 0.72 + 60（= 行の中心 + 44 + 16）。ボタンの範囲は中心から幅 ±70、高さ ±22（境界を含む） |

## テスト観点

- **キーの判定**（2 段目。1 段目は下の「段階つきのキーの判定」）：ゲームオーバー後のキーは、`repeat` が true のとき RETRY / NEW GAME / TITLE のきっかけにならない。`repeat` が false の `KeyR` は RETRY、`KeyT` は TITLE、他のキーは NEW GAME（修飾キー単独の `ShiftLeft` も NEW GAME）。判定は `KeyboardEvent.code` で、`KeyR`・`KeyT` は修飾キー（Shift・Ctrl・Alt・Meta）が付いていても、それぞれ RETRY・TITLE
- **ゲームオーバーのボタンの配置と当たり**（純粋な関数。手計算の値）：画面 1024x720 → RETRY の中心 (434, 518.4)、NEW GAME (590, 518.4)、TITLE (512, 578.4)。画面 390x844 → RETRY (117, 607.68)、NEW GAME (273, 607.68)、TITLE (195, 667.68)。離した位置の判定: TITLE の中心から x に ±70・y に ±22 ちょうどは TITLE、±71・±23 は TITLE ではない。RETRY・TITLE のどれの範囲にも入らない位置、NEW GAME の範囲の中は NEW GAME。ボタンの範囲は互いに重ならない（RETRY / NEW GAME の下端 = 0.72H + 22 < TITLE の上端 = 0.72H + 38）。画面の大きさを変えたときは、新しい大きさで同じ関数を呼んだ値になる（390x844 → 844x390 で RETRY (344, 280.8)・NEW GAME (500, 280.8)・TITLE (422, 340.8)。このとき TITLE の下端 340.8 + 22 = 362.8 < 390 で、画面に収まる）。置き直した後の離しは新しい配置で判定する（844x390 で (422, 340.8) の離しは TITLE、同じ位置が置き直し前の 390x844 の配置では TITLE の範囲の外）。置き直しの前後で、ボタンの大きさ（140 × 44）と互いの隙間は変わらない。回転後も 320 px 以上なら収まる（320x568 → 568x320 で TITLE の下端 = 0.72 × 320 + 60 + 22 = 312.4 < 320）。押し始めの規則: `DeathDelay` の間に押し始めた指は、`resize` の後に TITLE の上で離しても何もしない。ボタンが出た後に押し始めて `resize` をまたいだ指は、離した位置を新しい配置で判定する。`DeathDelay` の間の `resize` ではボタンは出ず、出るときの大きさで置かれる。STAGE のジャンプで取り消した後の `resize` で、ボタンは戻らない

- **段階つきのキーの判定**（純粋な関数。手計算）：1 段目: `KeyR`（`repeat` false）→ RETRY、`KeyT` → TITLE、`Space`・`ShiftLeft`・`KeyX` → 2 段目へ、`repeat` が true のものはすべて何もしない。2 段目: `KeyR` → RETRY、`KeyT` → TITLE、他のキー → NEW GAME、`repeat` true → 何もしない。2 段目に入ってから 299 ms の入力は何もしない（R・T を含む）、ちょうど 300 ms は受け付ける。
- **2 段目への遷移**（`StageFlow` の拡張で確認）：1 段目で R・T 以外のキーまたは押して離す操作が届くと 2 段目になり、同じフレームに 2 つ届いても遷移は 1 回。1 段目から R で RETRY、T で TITLE（2 段目を経ない）。`dying` の間（`DeathDelay`）の入力は何もしない。2 段目に入る前に押し始めた指の離しは、2 段目で何もしない（遷移のきっかけの指を含む）。2 段目に入ってから押し始めた指は、離した位置で RETRY / TITLE / NEW GAME になる。STAGE のジャンプは 1 段目・2 段目のどちらでも受け付け、暗幕・墓石・ボタン・「†」を取り消す。`dying` の間（`DeathDelay` 内）に押し始めた指を 1 段目で離しても、2 段目に進まない。`GraveInputLock` の間（例: 2 段目に入って 200 ms で押し始め、350 ms で離す）に押し始めた指の離しは、何もしない。キャンセルされたタッチ（`wasCanceled`）の離しは、1 段目でも 2 段目へ進まない。
- **墓石の絵**（純粋な関数。手計算。各行は右を空白で 24 文字に埋める）：ステージ 20・`bomb-without-flag`・ハイスコア 19・新記録ありの変形 A は 13 行で、順に `    ________________`、`   /                \`、`  /       REST       \`、` /         IN         \`、`/        PEACE         \`、`|                      |`、`|       Stage 20       |`、`|     killed by a      |`、`|         mine         |`、`|  Score:19  High:19   |`、`|     New record!      |`、`|______________________|`、`_)/\_//(\/(/\)/\//\/|_)_`。新記録なしは `New record!` の行が無く 12 行。`false-flag` は 8・9 行目が `|     stepped on a     |`・`|      false flag      |`。変形 B（ステージ 5・ハイスコア 4・新記録あり）は 10 行で、`    ________________`、`   /                \`、`  /      R.I.P.      \`、` /      Stage 5       \`、`/     killed by a      \`、`|         mine         |`、`|   Score:4  High:4    |`、`|     New record!      |`、`|______________________|`、`_)/\_//(\/(/\)/\//\/|_)_`。変形 C（`false-flag`・ステージ 100・スコア 99・ハイスコア 99・新記録なし）は 5 行で、`  ____________________`、` /  R.I.P. Stage 100  \`、`|stepped on false flag |`、`|  Score:99  High:99   |`、`|______________________|`（3 行目は 21 文字で、左 0・右 1 の空白）。`center` は左の空白を切り捨てて、残りを右に置く。内側の幅を超える文字列は、切らずにそのまま置く。
- **新記録と文言の部品**（純粋な関数。手計算）：新記録: スコア 5・死亡前のハイスコア 4 → 入れる、スコア 4・ハイスコア 4 → 入れない、スコア 0・ハイスコア 0 → 入れない。保存の書き込みが失敗しても、スコア > 死亡前のハイスコアなら入れる。スコアの行: ステージ 5・ハイスコア 9 → `Score:4  High:9`。結果 `bomb-without-flag` → `mine`、`false-flag` → `false flag`（死因 2）。
- **墓石の配置と変形**（純粋な関数。手計算）：下端 = H × 0.72 − 22 − 12。画面 1024x720 → 下端 484.4、390x844 → 573.68、375x550 → 362、667x310 → 189.2、568x320 → 196.4。中心 x = W / 2。変形（新記録なし）: 使える高さ 216 → A、215 → B、162 → B、161 → C、90 → C、89 → C（収まらなくても C）。（新記録あり）: 234 → A、233 → B、180 → B、179 → C、108 → C。HUD の帯の下端が凡例の行ありで 72 のとき、1024x720 は使える高さ = 484.4 − (72 + 8) = 404.4 → A。667x310 は 189.2 − 80 = 109.2 → C（新記録ありの 108 ≤ 109.2 で収まる）。568x320（回転後）は 196.4 − 80 = 116.4 → C。帯が 92 の 375x550 は 362 − 100 = 262 → A（新記録ありの 234 ≤ 262）。画面の大きさ・帯の下端を変えたときは、新しい値で同じ関数を呼んだ値になる。幅: 絵は 24 文字なので、1 文字の幅 8.4 px の注入値で絵の幅 201.6 px、裏の矩形 217.6 px（左右 8 px ずつ）、矩形の中心 x = W / 2、矩形の下端 = 絵の下端。`Score:12345  High:12345`（23 文字）では、その行が 25 文字（`|` + 23 + `|`）になり、絵の幅は 25 文字（210 px）、全行が 25 文字に埋まる。
- **「†」の位置**：移動で死んだとき（`bomb-without-flag`・`false-flag`）は踏んだマス、コード操作で死んだとき（`bomb-without-flag`）は自分のマスに「†」が置かれ、「@」は出ない。RETRY・NEW GAME・TITLE・STAGE のジャンプの後に残らない。
