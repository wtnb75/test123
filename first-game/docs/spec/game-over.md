# ゲームオーバーの表示

`docs/spec.md` の「画面・Scene 構成」の一部。`Game` で死亡したときの表示（全爆弾の開示・色分け）と、RETRY / NEW GAME / TITLE のボタンと入力を、独立して書いたもの。`docs/spec.md` と合わせて 1 つの spec である。

## 概要

死亡すると全爆弾を開示して色分けし、`DeathDelay` 後に RETRY / NEW GAME / TITLE のボタンを出す。死んだステージをやり直す（RETRY）・新しいゲームを始める（NEW GAME）・`Title` へ戻る（TITLE）の 3 つの出口がある。

## 操作仕様

ゲームオーバーの画面の入力（R / T / 他のキー、ボタンの離し、`resize`）は、下の「画面・Scene構成」の「ゲームオーバーの表示」に書く。

## 画面・Scene構成

### ゲームオーバーの表示

- ゲームオーバーの表示: 全爆弾の開示。論理的に確定できた爆弾（橙）・安全マス（緑）・誤ったフラグ（紫）の色分け。`DeathDelay` 後に「RETRY [R]」「NEW GAME」ボタンと、その 1 段下に「TITLE [T]」ボタン（`DeathDelay` の間は、「STAGE」を除くキー・ポインタの入力を受け付けない。「TITLE」は、ゲームオーバーの画面だけにある）
  - R キー・「RETRY」ボタンの上で離す: 死んだステージ番号を、新しく生成した盤面でやり直す（同じ盤面ではなく、乱数で作り直す）。
  - T キー・「TITLE」ボタンの上で離す: `Title` へ戻る（`Game` の状態を捨てて `Title` を始める。`Title` はデモを最初から流し、開始の門も新しい（[spec/title.md](title.md)）。そこで Start すると、`Game` は開始ステージ（`docs/spec.md` の「開始ステージの決め方」）から始まる。ハイスコアのセッション最大は残り、保存された値・開始ステージはこの遷移で書き換えない）。
  - それ以外のキー、「RETRY」「TITLE」の外のどこかで離す（NEW GAME ボタンの上を含む）: 新しいゲーム（`Game` を作り直し、開始ステージ（`docs/spec.md` の「開始ステージの決め方」）から）
  - 再開・遷移の要求（RETRY・NEW GAME・TITLE）は、最初の 1 回だけを受け付ける（同じフレームに 2 つ以上届いても、先に処理された 1 つだけが効く）
  - T キーは、プレイ中・`DeathDelay`・`ClearDelay` の間は何も起こさない。ボタンの範囲は、画面の座標（ポインターの位置）で、境界を含み、どのマウスボタンの離しでもよい。ボタンの位置は、画面の大きさ（幅・高さ）から「ボタン（RETRY / NEW GAME）」「ボタン（TITLE）」の式で決める。ボタンが出ている間に画面の大きさが変わった（`resize`。端末の回転・ウィンドウの変更）ときは、そのたびに、新しい大きさで 3 つのボタンの絵と範囲を置き直す（押し始めの記録は変えない。離したときは、離した時点の配置で判定する。リサイズより前に押し始めた指でも、ボタンが出てからの押し始めなら、離した位置で決まる。ボタンが出る前に押し始めた指は、`resize` があっても離しは何もしない）。ボタンが出る前（`DeathDelay` の間）に変わったときは、ボタンを出さず、出るときの大きさで置く。ボタンが出ていない間（`DeathDelay` の前、RETRY / NEW GAME / TITLE・STAGE のジャンプで取り消された後、`Game` を離れた後）の `resize` は、ボタンを作らず・出さず、何も起こさない。幅・高さとも 320 px 以上の画面で、3 つのボタンは画面に収まる。ボタンは仮想パッド・FLAG の絵より手前に描き、ゲームオーバーの画面ではパッドは押し始めを受け付けない（小さい画面でボタンがパッドの絵に重なってもよい）
- 死亡したとき、仮想パッドの押下の状態とリピートを解除する（RETRY の後に、指を置いていないのに動かない）。押しっぱなしのキーの自動リピート（`repeat`）は、RETRY / NEW GAME / TITLE のきっかけにならない（押し直したキーだけがきっかけ。`KeyR` は修飾キーが付いていても RETRY、`KeyT` は修飾キーが付いていても TITLE、それ以外のキー（修飾キーだけを含む）は NEW GAME）

## ルール

なし（死亡条件・スコア・ハイスコアの保存は `docs/spec.md` の「ルール」「スコア」のとおり）。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `DeathDelay` | 600 ms | 死亡してから RETRY / NEW GAME / TITLE のボタンを出すまで |
| ボタン（RETRY / NEW GAME） | 140 × 44 px・隙間 16 px・画面の高さの 0.72 の位置 | ゲームオーバーの表示。RETRY の中心 x = W / 2 − 78、NEW GAME の中心 x = W / 2 + 78、中心 y = H × 0.72（W・H は画面の幅・高さ） |
| ボタン（TITLE） | 140 × 44 px・RETRY / NEW GAME の行の 16 px 下 | 中心 x = W / 2、中心 y = H × 0.72 + 60（= 行の中心 + 44 + 16）。ボタンの範囲は中心から幅 ±70、高さ ±22（境界を含む） |

## テスト観点

- **キーの判定**：ゲームオーバー後のキーは、`repeat` が true のとき RETRY / NEW GAME / TITLE のきっかけにならない。`repeat` が false の `KeyR` は RETRY、`KeyT` は TITLE、他のキーは NEW GAME（修飾キー単独の `ShiftLeft` も NEW GAME）。判定は `KeyboardEvent.code` で、`KeyR`・`KeyT` は修飾キー（Shift・Ctrl・Alt・Meta）が付いていても、それぞれ RETRY・TITLE
- **ゲームオーバーのボタンの配置と当たり**（純粋な関数。手計算の値）：画面 1024x720 → RETRY の中心 (434, 518.4)、NEW GAME (590, 518.4)、TITLE (512, 578.4)。画面 390x844 → RETRY (117, 607.68)、NEW GAME (273, 607.68)、TITLE (195, 667.68)。離した位置の判定: TITLE の中心から x に ±70・y に ±22 ちょうどは TITLE、±71・±23 は TITLE ではない。RETRY・TITLE のどれの範囲にも入らない位置、NEW GAME の範囲の中は NEW GAME。ボタンの範囲は互いに重ならない（RETRY / NEW GAME の下端 = 0.72H + 22 < TITLE の上端 = 0.72H + 38）。画面の大きさを変えたときは、新しい大きさで同じ関数を呼んだ値になる（390x844 → 844x390 で RETRY (344, 280.8)・NEW GAME (500, 280.8)・TITLE (422, 340.8)。このとき TITLE の下端 340.8 + 22 = 362.8 < 390 で、画面に収まる）。置き直した後の離しは新しい配置で判定する（844x390 で (422, 340.8) の離しは TITLE、同じ位置が置き直し前の 390x844 の配置では TITLE の範囲の外）。置き直しの前後で、ボタンの大きさ（140 × 44）と互いの隙間は変わらない。回転後も 320 px 以上なら収まる（320x568 → 568x320 で TITLE の下端 = 0.72 × 320 + 60 + 22 = 312.4 < 320）。押し始めの規則: `DeathDelay` の間に押し始めた指は、`resize` の後に TITLE の上で離しても何もしない。ボタンが出た後に押し始めて `resize` をまたいだ指は、離した位置を新しい配置で判定する。`DeathDelay` の間の `resize` ではボタンは出ず、出るときの大きさで置かれる。STAGE のジャンプで取り消した後の `resize` で、ボタンは戻らない
