# Minefield Rogue

踏むな、読み切れ! 推理で抜ける地雷原ローグライク!!

![screenshot](screenshot.png)

## どんなゲーム?

- 数字ヒントを読んで地雷位置を推理
- 8方向移動で、上り階段（▲）から下り階段（▼）を目指す。1 つのフロアは 5 つの部屋の木（スタートの部屋 A に扉が 2 つ、そこから枝分かれ）で、壁の扉（+）の向きへ進むと通路を自動で歩いて、つながる部屋に渡ります。下り階段は先の無い部屋の 1 つにだけあり、ほかの先の無い部屋には何もありません。途中の部屋は先へ進む扉を持ち、部屋は行き来できます（通路の長さは部屋の位置で変わります）。木にない近道（輪。0〜2 本）が、2 つの部屋をまっすぐにつなぐことがあります
- 合ってるフラグなら地雷マスも通過できる
- ミスったら即ゲームオーバー。緊張感高め

## 特徴

- 全ステージが推理だけで解けるように生成
- 運任せの当て推量を前提にしない設計
- 1 マスの大きさは画面とステージで決まります（スマホは最大 44 px、PC は最大 52 px。収まらない大きい盤面は 30 px でスクロール）。画面に収まる部屋は、HUD とボタンを除いた領域の中央に表示されます
- 進むほど盤面サイズと難易度が上昇。スタートの部屋 A から通路を 2 つ以上たどった奥の部屋は、手前の部屋より少し大きく難しくなります
- 死亡するとゲームオーバー。まず全爆弾が表示され（死んだマスに「†」）、タップ・クリック・R と T 以外のキーで墓石画面（死んだステージ・死因・スコアとハイスコア・新記録）に進みます。RETRY（R。全爆弾の表示の時点からでも押せます）は同じステージ番号の新しい盤面で、NEW GAME はステージ 1 から（開発用のサーバーでは保存した開始ステージから）、TITLE（T）はタイトル画面へ戻ります。墓石の絵は、画面が大きいほど大きく（最大 3 倍）表示されます（小さい画面は今までの大きさ）

## 操作方法

- 開始: 起動すると Title 画面が出ます（ボットが推理してステージ 1〜3 を進めるデモが流れます）。「Start」をタップ / クリックするか、Enter / Space で始まります
- スマホ: 隣のマスをタップで移動（開いているマスを遠くタップすると、開いたマスを通ってそこまで自動で歩きます。歩いている間にタップすると止まります）、左下の仮想パッドで移動（タップでコード操作）、右下の FLAG ボタンでフラグモード（隣の未開示マスを長押しするとフラグを立てられます。Title の「パッド」で、パッドと FLAG を隠せます）、その上の MAP ボタンでフロアの全体図（2 秒で消えます。PC は M キー）、（開発用: `npm run dev` のときだけ、右上の STAGE ボタンで開始ステージ（1〜100）を選択。公開版には出ません。URL の `?stage=` は公開版でも使えますが、ページを開いて最初のゲームにだけ効きます）
- 移動: 矢印キー / テンキー 1-9（5除く）/ QWEA + XZDC / hjklyubn（h 左・j 下・k 上・l 右・y 左上・u 右上・b 左下・n 右下。キーの位置で決まるので、AZERTY などでは文字の位置が違う）
- 走る: Shift + 移動キー。開いているマスを 1 歩ずつ進み、壁・まだ開いていないマス・下り階段（▼）の手前で止まります。扉のマスには入って止まり、上り階段（▲）と下り階段（▼）の隣（斜めを含む）でも止まります。走っている間にキーを押すと止まります
- フラグ: f を押してから方向キー（隣接マスへ設置・解除。Esc で取り消し）
- コード操作: S またはテンキー 5
  - 条件がそろうと自動展開や自動フラグ補助が動く
- フロアの全体図: M キー（または MAP ボタン）。入った部屋・歩いた通路・まだ通っていない扉（「？」）が出て、2 秒で自動的に消えます。出ている間も操作できます

## ルール

- 爆弾をフラグなしで踏むと即死
- 非爆弾にフラグを立てて踏んでも即死
- 数字と矛盾しないルート作りがカギ

## こんな人向け

- マインスイーパーの論理推理が好きな人
- 緊張感のある1ミス即終了ゲームが好きな人
- 反射より判断を楽しみたい人

## 開発メモ

- 開発サーバー: npm run dev
- ビルド: npm run build
- テスト: npm run test
