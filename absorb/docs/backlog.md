# absorb 拡張候補（backlog）

`game-extend` で候補に挙がり、まだ採用していないアイデア。spec ではない。

- `leech`（ストック泥棒）: 自機に近づき、フィールド内にいる間ストックを吸い取る敵。溜め込むほど狙われるので「いつ撃つか」の判断が深まる。`splitter` を先に採用したため見送り
- `armored`（装甲の敵）: 正面の盾で、正面から来た解放弾をはじく敵。回り込むように撃つ位置取りを求める。`splitter` を先に採用したため見送り
- `carrier`（運び屋）: 小型機をばらまく母艦。放っておくと場の敵が増える。`splitter` を先に採用したため見送り
