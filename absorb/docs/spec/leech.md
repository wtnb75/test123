# ストック泥棒 `leech`

## 概要

自機のまわりを回りながら、吸い取りの範囲（半径 `LEECH_DRAIN_RADIUS`。吸収フィールドより広い）の中にいる間ストックを吸い取っていく敵 `leech`。近いほど速く吸い取るので、ストックを溜め込むほど奪われる危険が増え、「今撃つか、もう少し溜めるか」に損得が生まれる。範囲に入った遠いところから弱く吸い始め、近づくほど強くなる様子は、紐・流れる粒・吸収フィールドの色で見える。弾は撃たない。倒せば 400 点、離れれば吸われない。コアループ（吸う → 溜める → 撃つ）の「溜める」を深める。

## 操作仕様（追加・変更分）

なし（既存の移動と解放だけで戦う）。

## 画面・Scene構成（追加・変更分）

新しい Scene はない。leech は `Game` Scene のプレイ領域に、ほかの敵と同じ「敵」の層に描く。HUD のストックゲージと `GameOver` 画面の内訳に、下記の表示が加わる。

### 見た目

- **本体**: 紫系の色の、当たり半径 `LEECH_RADIUS` に合わせた図形。既存の敵（`grunt` / `shooter` / `heavy` / `rammer` / `splitter` / `carrier`）とボスのどれとも、色か形で見分けられること。ふだんの色（本体色）は 1 色で、予告などで色を変える状態はない
- **紐**: 吸い取りが働いている間（下記「吸い取り」の対象になっている leech ごと）、その leech の中心と自機の中心を結ぶ線を、本体色で描く。線の太さは吸い取りの強さで変える: 太さ = `LEECH_TETHER_MIN_WIDTH` + (`LEECH_TETHER_MAX_WIDTH` − `LEECH_TETHER_MIN_WIDTH`) × (そのフレームのその leech の吸い取り速度 ÷ `LEECH_DRAIN_MAX`)。不透明度は `LEECH_TETHER_ALPHA`。距離 d が `LEECH_DRAIN_RADIUS` 以下の leech は、ストックの有無にかかわらず描く（d = `LEECH_DRAIN_RADIUS` ちょうどでも、太さ `LEECH_TETHER_MIN_WIDTH` で描く）。吸い取りの範囲の外にいる leech、`ready` と `ending` の間は描かない
- **ストックの粒**: 吸い取りでストックが取られているあいだ、自機から leech へ向かって、紐の上を小さな粒が流れる。「吸われている向きと強さ」を見せるための描画だけで、ルール・入力には影響しない
  - **出る条件**: `playing` の間、距離 d が `LEECH_DRAIN_RADIUS` 未満の leech のうち、そのフレームの時点でストックが 1 以上あるときだけ出す（ストック 0 のときは出さない。紐は上のとおり描く）。判定に使うストックは、そのフレームの吸収と自動解放を終えた後、吸い取りの前の値とする（吸い取りでストックが 0 になったフレームにも、その値が 1 以上なら粒を出す）。更新の後のフェーズが `playing` のフレームだけ粒を出す（接触でライフが 0 になって `ending` に替わるフレームは、新しい粒を出さず、持ち分も 0 に戻す。[演出・UI](effects.md) の吸収演出と同じ）
  - **出す頻度**: leech ごとに「粒の持ち分」を持つ。毎フレーム、持ち分に（その leech の吸い取り速度 × `LEECH_PARTICLE_PER_STOCK` × そのフレームの経過時間）を足し、持ち分が 1 以上になった回数 m だけ粒を出して持ち分から m を引く（端数は次のフレームへ持ち越す。1 フレームに出る粒は 1 つの leech あたり最大 `LEECH_PARTICLE_MAX_PER_FRAME` = 2 まで。超えた分は捨てて、持ち分は「持ち分 − 実際に出した個数」の小数部分に戻す。例: 経過時間が大きくて持ち分が 5.3 になったら 2 個出し、持ち分は 0.3 に戻る。持ち分が 2.0 ちょうどなら 2 個出して 0）。出す条件を満たさないフレームは持ち分を 0 に戻す。吸い取り速度が速い（近い）ほど粒が密になり、`LEECH_DRAIN_RADIUS` の縁では粒が出ない
  - **動き**: 粒は出たフレームを t = 0 として、`LEECH_PARTICLE_DURATION` かけて自機の中心から leech の中心まで直線的に進み、ちょうどその時間で消える。位置は毎フレーム、そのときの自機の中心と leech の中心から決める（動いても紐の上を流れる）。途中で leech が壊れる・`ending` に入る・粒を出した leech が範囲の外へ出ても、再生中の粒は最後まで描く（leech が壊れたときは、壊れる直前の位置を終点にして続ける）。時間の規約は [演出・UI](effects.md) の「時間の規約」と同じ（途中で一時停止すると止まる）
  - **見た目**: 半径 `LEECH_PARTICLE_RADIUS` の円。色は本体色より明るい 1 色（実装裁量）。紐の色・太さとは別に、紐より目立つこと。不透明度は 1
  - 同時に存在する粒の数の上限は `LEECH_PARTICLE_MAX`（超えるときは古いものから消す）。リスタートのときは何も残さない
- **吸収フィールドの色**: 自機側の吸収フィールド（塗りと縁。ストック量に応じた塗りの濃さはそのまま）の色を、吸い取りの強さに応じて本体色へ寄せる。そのフレームの全 leech の吸い取り速度の合計を R として、フィールドの色 = ふだんのフィールドの色と本体色を、割合 min(1, R ÷ `LEECH_DRAIN_MAX`) × `LEECH_FIELD_TINT_MAX` で混ぜた色（R = 0 ならふだんの色）。混ぜるのは RGB の各成分の直線補間。R はストックが 0 のときも計算に入れる（「吸われている」のではなく「吸う力がかかっている」を見せる）。更新の後のフェーズが `playing` のフレームだけ混ぜる（`ready`、`ending`、接触でライフが 0 になって `ending` に替わるフレームは R = 0 とみなす）。混ぜるのは、`playing` の間の自機側の吸収フィールドの塗りと縁だけ（carrier の戦利品の強化中は、縁には混ぜず塗りだけに混ぜる。[carrier の戦利品](powerup.md)）。縁の太さ・不透明度は変えない。ほかの演出がフィールドの色を参照する場合（解放・吸収の演出の輪、吸い込みの粒の終了色、`ready` のチャージなど）は、ふだんの色のまま。吸収フィールドの範囲が見えること（docs/spec.md）は、色が変わっても満たす
- **描画順**: 紐は敵の層の最後（撃破の破片・分裂の輪・carrier より手前）、解放弾の層より奥に描く。ストックの粒は紐の直後（紐より手前、解放弾の層より奥）に描く。自機の層は紐と粒より手前なので、紐と粒の自機側の端は自機と吸収フィールドに隠れてよい。吸収フィールドの色の変化は、自機の層の中の既存の描画順のまま（塗りと縁の色が変わるだけ）
- **HUD のストックゲージの合図**: 吸い取りでストックが実際に減ったフレームに、ストックゲージ（HUD 右の「残数／上限」の表示。形は実装裁量）の色を赤（#ff5252）にし、`LEECH_HUD_FLASH` の間続ける。ふだんの色・形は変えない。減ったフレームが続けば、そのたびに数え直す（同時に 1 つ）
  - 時間の規約は [演出・UI](effects.md) の「時間の規約」と同じ（減ったフレームは t = 0 で赤、以降は毎フレームの経過時間で t を進め、ちょうど `LEECH_HUD_FLASH` で元の色に戻る）。描画だけで、ルール・入力には影響しない
  - ストックが 0 で何も減らなかったフレームは、合図を出さない・数え直さない
  - `ending` に入っても、再生中の合図は最後まで描く（`ending` の間は新しい吸い取りがないので、新しい合図は出ない）。リスタートのときは何も残さない
  - 解放ボタン（タッチ端末）の数字は、合図の対象にしない
- **撃破演出**: 既存の撃破演出のとおり（[演出・UI](effects.md)「演出・UI（撃破）」。破片の色は本体色そのまま。同時撃破の表示も既存どおりで、leech も 1 体として数える）
- 出現・体当たりで壊れるとき・専用の演出はない

### 状態遷移

leech 1 体（出現してから撃破・体当たりで壊れるまで）に、フェーズはない。出現した瞬間から壊れるまで、毎フレーム「周回の目標点」へ向かって動き続ける（下記「動き」）。画面外へ出て消えることはない。

## ルール

### 能力

| 種類 | HP | 弾パターン | 撃破スコア | 当たり半径 |
|------|-----|-----------|-----------|-----------|
| `leech` | `LEECH_HP` = 4 | 撃たない | `LEECH_SCORE` = 400（100/HP） | `LEECH_RADIUS` = 14px |

### 出現

- leech は `rammer` と同じく専用の枠で出現し、難易度スケールの表の出現比率・出現間隔とは関係しない。ボスの有無・carrier の有無にも関係しない
- 1 体目の予定時刻は `playing` の経過時間 `LEECH_FIRST_AT`。2 体目以降の予定時刻は、前の leech が出現した時刻 + `LEECH_INTERVAL`
- 予定時刻に達した時点で、画面にいる leech（壊れていないもの）が `LEECH_MAX` 体未満なら、その瞬間に 1 体出現する。`LEECH_MAX` 体いれば、`LEECH_MAX` 体未満になった最初のフレームに出現する（予定時刻は遅れた出現の時刻から数え直す。遅れた分をまとめて出すことはない）。1 回に出るのは 1 体
- leech は同時 `MAX_ENEMIES` 体の上限にも、`MAX_RAMMERS` の上限にも数えない。`heavy` の「追跡中」の数や包囲の持ち場の計算にも加わらない。leech が `LEECH_MAX` 体いても、通常の敵と `rammer` の出現は変わらない
- leech は `playing` の間だけ出現する（`ready`・`ending` では出現しない）
- **判定のタイミング**: 出現の判定は、既存の敵・ボスの出現と同じく `playing` の更新の最初の出現処理で、そのフレームの経過時間を足す前の経過時間を使って行う。出現したフレームから leech は動く（出現処理の後、そのフレームの敵の移動で動く）
- **出現位置**: 出てくる辺は [敵の種類と動き](enemies.md) の「出現位置（上・左・右）」と同じ比率で乱数により選ぶ。位置は次のとおり（中心が、画面の外側に `LEECH_RADIUS` だけ離れた位置）
  - 上: x は画面上端のランダムな位置（左右 `EDGE_MARGIN` の余白を除く）、y = −`LEECH_RADIUS`
  - 左: x = −`LEECH_RADIUS`、y は画面高さの 15〜45%（ランダム）
  - 右: x = 画面幅 + `LEECH_RADIUS`、y は左と同じ範囲
- 出現した瞬間に、周回の向き（時計回り・反時計回り）を乱数で半々に選ぶ。その leech は壊れるまでその向きで回る

### 動き

- 出現した時刻から数えた経過時間を s とする（出現したフレームの s は 0。以後のフレームで、そのフレームの経過時間を足す）
- **周回の目標点** P: 自機の中心から見て、角度 θ の方向に `LEECH_ORBIT_RADIUS` だけ離れた点。θ = θ0 ± `LEECH_ORBIT_SPEED` × s（向きが時計回りなら +、反時計回りなら −。θ0 は出現した瞬間の自機から見た leech の方向。y は下向きに増える座標で、角度は x 軸から y 軸へ向かう向きを正とする）
- 毎フレーム、leech は P へ向かって最大 `LEECH_SPEED` で進む。P までの距離が `LEECH_SPEED` × そのフレームの経過時間以下なら、P ちょうどに着いて止まる（行き過ぎない）。P は毎フレーム、その時点の自機の位置と s から計算し直す
- **内側へは入らない**: 動く前に自機から `LEECH_ORBIT_RADIUS` 以上離れていた leech が、動いたあとに `LEECH_ORBIT_RADIUS` より近くなる位置になるとき（P が自機の向こう側にあって、まっすぐ向かうと自機のすぐそばを横切る場合）は、自機から見た方向は動いた位置のままで、距離をちょうど `LEECH_ORBIT_RADIUS` にする（円の縁に沿って P へ回り込む）。動く前から `LEECH_ORBIT_RADIUS` より内側にいる leech（自機が近づいた場合）には、この補正をしない
- 自機が `PLAYER_SPEED`（320px/秒）で離れると leech は追いつけず（`LEECH_SPEED` = 100px/秒）、距離が開いて吸い取りの範囲の外に出られる。自機が止まれば、leech は追いついて周回に入る（周回の接線方向の速さ = `LEECH_ORBIT_RADIUS` × `LEECH_ORBIT_SPEED`（ラジアン）≈ 94px/秒 は `LEECH_SPEED` 以下なので、止まった自機のまわりを回り続けられる）
- 周回の半径 `LEECH_ORBIT_RADIUS`（60px）は、自機の当たり半径 `PLAYER_RADIUS` と `LEECH_RADIUS` の和（24px）より大きいので、近づく途中も周回中も、leech の側から体当たりになることはない（自機が leech へ近づいて重なったときだけ接触する）
- `ending` の間も leech は動き続ける（新しく出現せず、吸い取りは止まる）
- リスタート（`Game` の作り直し）で、leech・吸い取りの持ち分・次の出現予定は初期状態に戻る。一時停止の間は、経過時間 s・出現の時計・持ち分のどれも進まない（[一時停止](pause.md)）

### 吸い取り

- `playing` の間、leech の中心と自機の中心の距離 d が `LEECH_DRAIN_RADIUS`（150px。吸収フィールドの `FIELD_RADIUS` = 90px より広い）以下の leech は、ストックを吸い取る。その leech の吸い取り速度（個/秒）は `LEECH_DRAIN_MAX` × (1 − d ÷ `LEECH_DRAIN_RADIUS`)（d = 0 で最大、d = `LEECH_DRAIN_RADIUS` ちょうどで 0、それより遠いと吸い取らない）。吸収フィールドの外（d が `FIELD_RADIUS` より大きい）でも吸い取る。弱く吸い始める遠さと、近づくほど強くなる段階を分けて見せるための広さ
  - 例（初期値）: d = 150px で 0 個/秒、d = 120px で 3.6 × (1 − 120/150) = 0.72 個/秒、d = 90px（吸収フィールドの縁）で 1.44 個/秒、d = 60px（周回の距離）で 3.6 × (1 − 60/150) = 2.16 個/秒、d = 30px で 2.88 個/秒、d = 0 で 3.6 個/秒
- 画面にいる全 leech の吸い取り速度を合計し、そのフレームの経過時間を掛けた量を「吸い取りの持ち分」に足す（持ち分は 0 以上の実数。`World` が 1 つ持つ）。持ち分の整数部分 n（浮動小数の誤差を許す。`DRAIN_EPS` = 1e-6 として、持ち分 + `DRAIN_EPS` の切り捨て）だけストックを減らし、持ち分から n を引く。ストックが n より少ないときは 0 になるまで減らす。減らした後もストックが 1 以上あれば、端数は次のフレームへ持ち越す
  - 例（初期値、60fps、1 体、d = 60px で動かない）: 1 フレームの持ち分は 2.16 × (1/60) = 0.036。28 フレーム目で持ち分が 1.008（27 フレーム目は 0.972）に達しストックが 1 減る。以後 28 フレームごとに 1 減る（持ち越した端数 0.008 を含む）
- 減った分のストックは戻らない（leech に貯めるものではない。倒しても返らない）。解放弾・自動解放・救済ストックには影響しない
- **1 フレームの中の順序**: 吸収（敵弾の吸収、途中で 50 に達したら自動解放）、吸い取り、接触判定（救済ストックの +10）の順に処理する。吸収で自動解放が起きたフレームは、解放後のストックから吸い取る
- 無敵中（被弾後の `PLAYER_INVULNERABLE`）も吸い取る。`ready` と `ending` の間は吸い取らない（持ち分も増えない）
- ストックが 0 のときは減らさない。上の処理のあとストックが 0 になっていたら（もともと 0 だった場合と、この吸い取りで 0 になった場合のどちらも）、持ち分を 0 に戻す（端数も捨てる）。0 のあいだに溜まった持ち分が、後で吸収したストックを余計に減らすことはない
- 吸い取りの対象は、距離 d だけで決まる。中心が画面内の leech に限らない（周回の目標点が画面の外にかかるとき、画面外にいる leech も吸う）。ただし解放弾の標的にできるのは、既存どおり画面内にいる leech だけ

### 解放弾との関係

- leech は既存の敵と同じく、標的の割り振り・付け替えの対象になる（中心が画面内にあるときだけ。不足数も既存どおり）
- 解放弾が当たると HP が 1 減り、HP 0 で撃破されて撃破スコアが入る。同時撃破ボーナスでは 1 体として数える
- 解放弾は自機に近い敵から割り振られるので、周回中の leech には（自機のそばにいるため）優先して弾が向かう

### 体当たり（接触）

- 既存の敵と同じ: 自機に接触するとライフ −1・無敵・ストック +`HIT_STOCK_BONUS`、接触した leech は壊れて消える（スコアは入らず、同時撃破にも数えない）。1 回の接触判定で壊れるのは 1 体だけ、ボスが優先、無敵中は接触判定をしない、という既存ルールも変えない

### スコアの内訳

- leech を 1 体以上倒したときは、GameOver 画面の内訳に「LEECH」の行を置く（解放弾で倒した leech の数と、撃破スコアの合計）。行の位置は「CARRIER」の次、「BOSS」の前。色・書式は docs/spec.md「GameOver 画面（スコアの内訳）」のとおり（名前の色は本体色）
- 内訳の行は最大 9 行（敵の行 8 種類 + ボーナス）になり、`GAMEOVER_INPUT_LOCK` は 9 × `GAMEOVER_ROW_INTERVAL` + `GAMEOVER_ROW_FADE` = 1.28 秒になる（docs/spec.md の GameOver 画面）

### Title のデモとの関係

- `Demo` の走り（`DEMO_RUN_SECONDS` = 40 秒）は、`LEECH_FIRST_AT`（40 秒）と同時に黒い幕が閉じ始めるので、デモの走りで leech が見えることはない（幕の下の 0.5 秒の間に出ても、そのまま作り直される。ボットは leech を「敵」として避けるだけで、ボットのロジックは変えない）

## テスト観点

- 出現: 経過 `LEECH_FIRST_AT` ちょうどで出る（直前には出ない）、次は前の出現 + `LEECH_INTERVAL` ちょうど、`LEECH_MAX` 体いる間は出ず 1 体壊れた最初のフレームに出て予定がそこから数え直される、1 回に出るのは 1 体、`ready`・`ending` では出ない、ボスがいても carrier がいても出る、出てくる辺が上・左・右の比率（縦長 50/25/25、横長・正方形 70/15/15）に従う（乱数を注入して境界を確認）、出現位置（上: x が `EDGE_MARGIN`〜画面幅 − `EDGE_MARGIN`・y = −`LEECH_RADIUS`、左右: x = −`LEECH_RADIUS` または 画面幅 + `LEECH_RADIUS`・y が画面高さの 15〜45%）、周回の向きが乱数で半々に分かれる、出現したフレームから動く
- 上限との独立: leech がいても通常の敵が `MAX_ENEMIES` 体まで・`rammer` が `MAX_RAMMERS` 体まで出る、leech は `MAX_ENEMIES`・`MAX_RAMMERS` に数えない、`heavy` の持ち場の計算に leech が入らない
- 動き: 周回の目標点 P（θ0 ± 90°/秒 × s、自機から 60px）へ最大 100px/秒で進む、P に着いたら止まる（行き過ぎない）、自機が動くと P も動く、自機が 320px/秒で離れると距離が開く、自機が止まると追いついて周回に入る、止まった自機へ遠くから近づいても（出現の辺・向きを変えた多数のシードで）一度も自機に重ならず距離が `LEECH_ORBIT_RADIUS` を割らない（P が向こう側にある場合は円の縁に沿って回り込む。補正の境界: 動く前に ちょうど `LEECH_ORBIT_RADIUS` にいる leech も補正の対象で、`LEECH_ORBIT_RADIUS` より内側にいる leech は補正されない）、時計回り・反時計回りで θ の増減が逆、`ending` の間も動く
- 吸い取り: d = 150px ちょうどで 0、d = 120px で 0.72 個/秒、d = 90px で 1.44 個/秒（吸収フィールドの縁の外でも吸う）、d = 60px で 2.16 個/秒、d = 30px で 2.88 個/秒、d = 0 で 3.6 個/秒、150px を超えると 0、60fps・d = 60px・1 体で 28 フレーム目に 1 減る（27 フレーム目までは減らない。浮動小数の誤差を許す）、2 体なら合算する、端数が次のフレームへ持ち越される、ストックが 0 のときは減らず持ち分が 0 に戻る（0 のあいだに溜まった持ち分で、後に吸収したストックを余計に減らさない。ストック 1 のとき持ち分 0.5 から 1 減って 0 になったら、持ち分も 0 に戻る）、無敵中も吸う、`ready`・`ending` では吸わず持ち分も増えない、1 フレームの順序（自動解放が起きたフレームは解放後のストックから吸う）、減った分が戻らない（leech を倒してもストックは増えない）
