# absorb

避けるな、吸え! 敵弾を溜めて、まとめて撃ち返すシューティング。

## どんなゲーム?

- 自機は画面のどこへでも動ける(上ほど敵にぶつかりやすいので注意)
- 自機のまわりの吸収フィールドが、敵弾を自動で吸い込んでストックする
- 解放ボタンで、溜めた弾を一斉に撃ち返す。弾は近い敵から順に、倒すのに必要な数ずつ分かれて追いかける
- ストックが満タン(50)になると自動で解放される
- 敵弾には当たらない。当たると痛いのは **敵の体当たり** だけ
- 強い敵ほど 1 発あたりのスコアが高い。溜めて `heavy` をまとめて落とすのが稼ぎどころ

## 操作方法

| 操作 | キー |
|------|------|
| 移動 | 矢印キー または WASD |
| 解放 | X または Enter |
| リスタート | ゲームオーバー画面で R またはクリック |

## 敵

| 敵 | 見た目 | HP | スコア | 動き |
|----|--------|----|--------|------|
| grunt | 緑の三角 | 2 | 100 | ときどき震えてから、自機めがけて蛇行しながら急降下する |
| shooter | オレンジの四角 | 4 | 400 | 3 方向に撃ちつつ、ときどき画面の中ほどまで降りて横切る |
| heavy | 紫の大きな円 | 8 | 1600 | 全方位に撃ちながら、ゆっくり降りてくる。下まで逃げられるとスコアなし |
| rammer | 赤い矢印 | 3 | 300 | 赤く点滅したあと、自機めがけて突進してくる |

## ルール

- ライフは 3。敵に体当たりされると 1 減り、1.5 秒間は無敵
- ライフが 0 になるとゲームオーバー
- 1 回の解放で 2 体以上倒すと同時撃破ボーナス(2 体で ×1.5、3 体で ×2.0 …)
- 時間がたつほど敵の種類・数・弾速が増えていく

仕様の詳細は [docs/spec.md](docs/spec.md) を参照。
