# 古語ドロップ (KogoDrop)

落として覚える古語単語ゲーム。高校受験対策向けの古語・現代語・英語を同時に学べる落ちゲー。

## ゲームの目的

上から落ちてくる単語タイルを、画面下部に並ぶ意味スロット（4列）へ正しく振り分ける。  
全問終了後に正答率を確認し、間違えた単語を復習できる。
結果画面（または復習画面）の「間違えた語を再挑戦」で、間違えた語だけを同じ設定でもう一度落として確かめられる（1 周で終わる。まだ間違えた語が残れば、結果画面からもう一度再挑戦できる）。

## ルール

- 落下タイルに表示された単語を、対応する意味のスロットへ落とす
- 4 つのスロットのうち正解は 1 つ。ほかの 3 つは、正解と同じ品詞の語の意味から選ばれやすい（同じ品詞の語が足りないときだけ、ほかの品詞の語で補う）
- 正解: 正答数 +1
- 不正解: 不正答数 +1（ゲームは続行）
- 規定出題数に到達したらリザルト画面へ
- ゲームオーバーなし（時間制限なし）
- 語ごとの正解・不正解の回数は、この端末のブラウザに保存されます（`localStorage`。ほかのデータや点数は保存しません）。タイトル画面の「苦手な語を多めに出す」がオンのとき（初期状態）、通常の出題では、間違えやすい語ほど選ばれやすくなります（いつも間違える語は、間違えない語より選ばれやすさが 5 倍。ただし 1 回の出題で同じ語が出るのは 1 回までで、必ず出るわけではありません）。オフにすると、記録があっても今までどおりの出題です。「苦手な語の記録を消す」を 2 回タップ（3 秒以内）すると、記録が消えます（オンとオフの設定は残ります）。保存が使えない環境でも、そのまま遊べます。

### 言語モード

| モード | タイル | スロット |
|--------|--------|---------|
| 古語→現代語 | 古語（例: あはれ） | 現代語訳の短縮形 |
| 古語→英語 | 古語 | 英語訳の短縮形 |
| 英語→古語 | 英語訳の短縮形 | 古語 |

### 難易度

| 難易度 | 出題プール |
|--------|-----------|
| やさしい | basic 語（約60語） |
| ふつう | basic + standard（約120語） |
| むずかしい | 全レベル（約160語） |

## 操作方法

### タッチ操作
- タイルをタッチしてホールド → 左右にドラッグ → 離してスロットへ投入

### キーボード操作
- `←` / `→`: タイルを左右のスロットへ移動
- `Space` / `Enter`: 現在位置のスロットへ投入
- `P`: 一時停止（未実装 / 非MVP）

## 開発

```bash
npm install
npm run dev       # 開発サーバー起動 (port 8080)
npm run build     # 本番ビルド
npm run test      # テスト実行
npm run test:coverage  # カバレッジ付きテスト
npm run lint      # ESLint
```

### 開発用フラグ

`.env.development` に以下を記述すると `verified: false` の単語も出題プールに含まれる:

```
VITE_DEV_IGNORE_VERIFIED=true
```
