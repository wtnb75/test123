# 復習画面（Review Scene）

## 概要

Result Scene の「間違えた単語を復習する」ボタンから開く、不正解単語の一覧画面。出題順に、古語・現代語訳・英語訳・例文を並べて、もう一度読めるようにする。仕様の本体は [docs/spec.md](../spec.md) の「画面・Scene 構成」と「画面イメージ」にあり、この文書はそこから Review Scene の部分を移したもの。

## 操作仕様

- 一覧はスクロールで全件を見られる（DOM オーバーレイ。下の補足を参照）
- 下部のボタン: 「間違えた語を再挑戦」（不正解が 1 問以上のとき。[再挑戦ラウンド](retry-missed.md)）、「もう一度」、「タイトルへ」

## 画面・Scene 構成

```text
+------------------------------------------------------+
|                  復習 — 間違えた単語                  |
|                                                      |
|   1. おぼつかなし［形容詞・ク活用］                  |
|      → 不安だ・はっきりしない                         |
|      → uneasy; vague; unreliable                    |
|      例）「返り事もおぼつかなくて、日ごろ過ぎぬ。」    |
|          （返事もはっきりせず、何日も過ぎた。）        |
|          ※「おぼつかなく」= 連用形                   |
|                                                      |
|   2. いみじ［形容詞・シク活用］                      |
|      → 非常に・ひどい・すばらしい                     |
|      → very; terribly; wonderful                    |
|      例）「いみじう美しき人の…」                      |
|          （非常に美しい人が…）                        |
|          ※「いみじう」= 連用形・ウ音便               |
|                                                      |
|   3. をかし［形容詞・シク活用］                      |
|      → 趣がある・おもしろい                           |
|      → charming; interesting; witty                 |
|      例）「春はあけぼの。…紫だちたる雲の…」           |
|          （春は夜明け。…紫がかった雲が…）             |
|          ※出典: 枕草子                               |
|                                                      |
|   （スクロールで全件表示）                            |
|                                                      |
|   [ 間違えた語を再挑戦 (3語) ]                        |
|   [ もう一度 ]          [ タイトルへ ]                |
+------------------------------------------------------+
```

補足:
- 不正解単語は出題順に並べる
- 各エントリは「古語［品詞・活用種別］」と `meaning`（フル表記）と `englishMeaning` を表示する
- その単語を `highlights.word` に含む例文を最大1件表示する（複数ある場合は先頭1件）
- 例文がある場合、該当 `highlight` の `note` を「※「form」= note」の形式で表示する
- 例文の `source` がある場合は「※出典: 〇〇」を追加表示する
- 例文が存在しない単語は意味・英語訳・品詞のみ表示する
- スクロール可能なリスト形式にする（単語数が多くなる場合を考慮）
- スクロールは DOM オーバーレイで実装する（Phaser キャンバスの上に HTML `<div>` をかぶせ、CSS `overflow-y: auto` でスクロール）
- Review Scene 開始時に DOM 要素を生成し、Scene 終了時（タイトルへ戻るボタン押下時）に削除する

## ルール

- 一覧の並びは出題順。不正解の語は、同じ語を複数回間違えた場合も重複して並ぶ（[docs/spec.md](../spec.md) の「不正解リスト収集」）
- 例文の引き当ては `docs/spec.md` の「例文引き当て」の規則に従う（`verified: false` の例文は出さない）

## パラメータ表

なし（表示の大きさ・位置は実装裁量。下の「実装裁量」を参照）。

## テスト観点

- 例文引き当て（`docs/spec.md` の「テスト観点」の「例文引き当て」を参照）
- 不正解が 0 問のとき、一覧と「間違えた語を再挑戦」を出さない（[docs/spec.md](../spec.md) の完了条件）

## 完了条件

- 不正解単語の一覧（古語・現代語訳・英語訳・例文）が出題順に表示される
- 全問正解の場合は復習ボタンが表示されない（Result 側の条件）
- 一覧の全件がスクロールで見られ、タイトルへ戻ると DOM 要素が消える

## 実装裁量

- 一覧の文字の大きさ・行間・色・スクロールバーの見た目
- DOM オーバーレイの生成と破棄の具体的な方法（Scene の開始・終了に合わせる、という規則は上の補足のとおり）
