# cjump

拡大する円を避けるワンボタン・ジャンプゲーム。

## 遊び方

- キャラクターは決まったルートを自動的に進み続けます。
- 画面のランダムな場所から円が発生し、時間とともに輪(縁)が広がっていきます。
- 円の縁がキャラクターの位置に重なるタイミングでジャンプして回避してください。
- 円の内側・外側は安全です。危険なのは輪(縁)そのものだけです。

## 操作方法

- スペースキー、または画面のクリック/タップでジャンプします。
- ジャンプ中は移動が止まり、着地すると同時に移動を再開します（連続ジャンプ・二段ジャンプはできません）。

## ルール

- ルートの終点まで、円の縁に一度も触れずに到達すればステージクリアです。
- 円の縁に触れると即ゲームオーバーです。
- 全10ステージ。ステージをクリアすると次のステージが解放されます（この解放状況はブラウザを閉じる・リロードすると失われます）。

## 開発

```bash
pnpm install
pnpm --filter cjump dev            # 開発サーバー
pnpm --filter cjump lint           # ESLint
pnpm --filter cjump test           # Vitest
pnpm --filter cjump test:coverage  # カバレッジ (90%以上)
pnpm --filter cjump build          # 静的サイトのビルド
```

詳細な仕様は [`docs/spec.md`](docs/spec.md) を参照してください。
