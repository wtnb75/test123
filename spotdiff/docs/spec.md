# SpotDiff（仮称）

## コンセプト

図形で描いた左右2枚の絵から、違う箇所を制限時間内にクリックして見つける短時間パズル。絵と差分はシード付き乱数で毎回自動生成し、全5ステージ。

## コアループ

違うと思う箇所をクリック／タップする。当たりなら発見済みになり、外れなら残り時間が減る。全差分を見つけたらステージクリア、時間が尽きたらゲームオーバー。

## 操作仕様

クリック／タップのみ（マウスとタッチで同じ）。左右どちらのパネルを押してもよい。ゲームオーバー／全クリア後のクリックで最初からやり直す。

## プレイテストで固まったこと

- 良い: ステージがサクサク進むテンポ。前半は難易度が上がっていく実感がある。残す。
- 後半が当てやすい問題: 差分が増えると「外れの場所」が減り、当てずっぽうでも当たる。対策として図形数をステージごとに増やし、差分の割合を 25%→19% に下げた（図形数 12→36）。
- 縦持ち対応: ウィンドウの縦横比で縦横レイアウトを切り替える（縦は2枚を上下に並べる）。
- 図形が重なる絵柄を許可。ただし中心間距離に下限を置き、差分がどの図形のものか分かるようにする。
- 背景を足して画面を映えさせる。パネルの装飾は左右同一で差分の対象にしない。
- 図形が重なる絵柄でも、差分同士の判定円は重ならないように選ぶ。丸で囲った範囲に別の差分が入ると「1回の丸で2個」になり直感に反するため。
