# 遊び方の説明（Help）

## 概要

`Title` の "HOW TO PLAY" ボタンから開く説明画面 `Help` を足す。`Title` のデモが見せていない点（誤クリックで 5 秒減る・5 ステージで 1 セット・時間切れはセットの先頭から・画面を離れると止まる）を、短い文字 6 行と、違いの 6 種類の小さな図で伝える。初めての人が、ルールを知らないまま遊び始めて損をしないようにする（遊びの中身は変わらない。演出・UI のみ）。

## 操作仕様

- `Title` の "HOW TO PLAY" ボタンの矩形の中の入力で `Help` を開く（ボタンの位置・遷移の規則は [../spec.md](../spec.md) の「Title」）。
- `Help` では、開いてから `helpInputLockMs`（300 ms）が過ぎたあと、画面のどこをクリック／タップしても `Title` へ戻る。それより前の入力は無視する（ボタンを押した余波で即座に閉じないため。無視した入力は覚えない）。経過時間は `Help` の `create` を 0 として `update` の delta で数え、経過 ≧ `helpInputLockMs` で受け付ける。戻る遷移は最初の 1 回だけを受け付ける（同じフレームに複数の入力が届いても 1 回）。
- 入力はクリック／タップ（`pointerdown`）のみ。キーボード・ホバー・ドラッグ・長押しは使わない。
- 戻った `Title` は、`Title` に入るたびの規則どおり、新しいデモの絵で始まる（日付の表示は戻ったときに取り直す）。

## 画面・Scene構成

Scene は `Help` 1 つ（Phaser の Graphics とテキストだけで描く。画像・音声は使わない）。向きの切り替え（縦・横・横長）は他の Scene と同じ規則で、`Help` ではリサイズのたびに新しいレイアウトで描き直す。入力ロックの経過時間は描き直しても引き継ぐ。`Help` では一時停止しない。

**背景**: `Title` と同じ背景（`drawBackdrop` と `MENU_HUE`）。

**表示するもの**（上から順に。座標はキャンバス座標）

1. 見出し "HOW TO PLAY"（水平中央、y は文字の中心）。
2. 説明の 6 行（左揃え、左上を基準に置く。長い行は `bodyWrap` で折り返す）。文言は英語で、次のとおり（この順）:
   1. `Tap where the two pictures differ.`
   2. `A wrong tap costs 5 seconds.`
   3. `Find every difference to clear a stage.`
   4. `5 stages make 1 set.`
   5. `Time runs out: the set restarts.`
   6. `Leave the screen: the game pauses.`

   2 行目の "5" は `missPenalty` の値、4 行目の "5" は `stageCount` の値と同じ（値を変えたら文言も合わせる）。
3. 違いの図: 6 つのセル（行の順に COLOR・MOVE・SIZE・GONE・EXTRA・SHAPE）。1 セットは「左の絵」「右の絵」の 2 つの正方形（スウォッチ）を隣り合わせに置き、その下に種類の名前（水平中央）を出す。
4. "TAP TO CLOSE"（水平中央、y は文字の中心、36px）。`Title` の "TAP TO START" と同じ点滅（下の「演出」）。

**配置**（キャンバス座標。説明の `top` は 1 行目の文字の上端）

| 要素 | 縦（768x1664） | 横（1024x768） | 横長（1664x768） |
|---|---|---|---|
| 見出し（文字・y） | 56px・y=110 | 48px・y=50 | 56px・y=50 |
| 説明（文字・左端 x・折り返し幅 `bodyWrap`） | 32px・x=40・688 | 28px・x=40・460 | 32px・x=60・800 |
| 説明の i 行目（0 始まり）の上端 y | 200 + 88·i | 110 + 72·i | 110 + 64·i |
| 図のセルの並び（列 x 行） | 2 x 3 | 2 x 3 | 3 x 2 |
| 図の列の中心 x | 192・576 | 650・870 | 1000・1240・1480 |
| 図の行の上端 y（スウォッチの上端） | 790・994・1198 | 130・280・430 | 130・330 |
| スウォッチの一辺 `S`・2 枚の隙間 | 120・24 | 80・16 | 96・16 |
| 種類の名前（文字・y の中心） | 32px・行の上端 + 150 | 24px・行の上端 + 102 | 32px・行の上端 + 126 |
| "TAP TO CLOSE"（y） | 1540 | 700 | 700 |

- セルの中心 x を `cx` とすると、左のスウォッチは x = `cx - gap/2 - S` 〜 `cx - gap/2`、右のスウォッチは x = `cx + gap/2` 〜 `cx + gap/2 + S`（縦の 1 列目: 60〜180 と 204〜324、2 列目: 444〜564 と 588〜708）。スウォッチの y は行の上端から `S` の高さ。
- セルの並びは行優先（縦・横の 1 行目は COLOR・MOVE、2 行目は SIZE・GONE、3 行目は EXTRA・SHAPE。横長の 1 行目は COLOR・MOVE・SIZE、2 行目は GONE・EXTRA・SHAPE）。
- すべての要素はキャンバスに収まり、互いに重ならない（縦: 説明の最後の行の下端 ≦ 716 < 図の上端 790、図の下端 ≦ 1366 < 1540。横: 説明の右端 ≦ 500 < 図の左端 562、説明の下端 ≦ 536 < 700。横長: 説明の右端 ≦ 860 < 図の左端 896、説明の下端 ≦ 468 < 700）。縦と横長の文字（見出し・説明・種類の名前・"TAP TO CLOSE"）はキャンバス上で 32px 以上。横の文字は 24px 以上（800x600 以上の 4:3 の画面で 18 CSS px 以上）。縦の説明は、折り返しても 2 行までに収まる（行の間隔 88 ≧ 2 行分。スクリーンショットで確認する）。縦キャンバス（768 幅）は固定の論理サイズなので、縮小率が 0.5 を下回る画面（375x550 など）では、`Game` の文字と同じく実寸が小さくなってよい（既存の方針）。

**図の見本**（固定の見本で、乱数は使わない。座標と大きさはスウォッチの一辺 `S` に対する割合で、左上を原点とする）

- スウォッチの背景: 淡色の正方形（色相 215・彩度 0.3・明度 0.9）。
- 全スウォッチ共通の「そのまま」の図形（左右同一）: 四角、中心 (0.84, 0.84)、半径 0.08、色相 40。
- 主な図形（色相 205・彩度 0.7・明度 0.5。例外は表のとおり）:

| 種類 | 左の絵 | 右の絵 |
|---|---|---|
| COLOR | 円、中心 (0.5, 0.5)、半径 0.2 | 同じ円で色相だけ 330 |
| MOVE | 円、中心 (0.38, 0.5)、半径 0.2 | 同じ円で中心 (0.62, 0.5) |
| SIZE | 円、中心 (0.5, 0.5)、半径 0.2 | 同じ円で半径 0.32 |
| GONE | 円、中心 (0.5, 0.5)、半径 0.2 | 主な図形なし（共通の四角だけ） |
| EXTRA | 主な図形なし（共通の四角だけ） | 円、中心 (0.5, 0.5)、半径 0.2 |
| SHAPE | 円、中心 (0.5, 0.5)、半径 0.2 | 三角、中心 (0.5, 0.5)、半径 0.2 |

図形は `Game` と同じ描画（`drawShape` 相当。外接の正方形 `2*半径` に収まる）で描く。主な図形と共通の四角は重ならない（SIZE の右の円と四角の最短距離は円の半径より大きい）。

**演出**

- "TAP TO CLOSE": 透明度 `promptAlpha`（`Title` の "TAP TO START" と同じ式。t は `Help` が始まってからの経過 ms）。入力ロック中も動かす。
- それ以外の演出はない（フェードインなし）。入力ロックの時間は `update` の経過時間（delta）で数える（`delayedCall` は使わない）。

## ルール

遊びのルール・スコア・シードには関係しない（`Help` は何も保存せず、`Title` に戻るだけ）。文言は「ルール」の現在の値（誤クリック 5 秒・5 ステージ・時間切れはセットの先頭から・ページ非表示で一時停止）を表している。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `helpInputLockMs` | 300 | `Help` を開いてから入力を無視する時間(ms)。`resumeInputLockMs` と同じ長さ |
| `helpButton` | 縦 (384, 1612)・360x88 / 横 (840, 700)・240x60 / 横長 (1464, 690)・320x110 | "HOW TO PLAY" ボタンの中心・大きさ（キャンバス座標。文字は 32 / 28 / 40px）。正本は [../spec.md](../spec.md) 「Title」の配置の表で、ここは参照用 |
| `bodyWrap` | 縦 688 / 横 460 / 横長 800 | 説明の折り返し幅 |
| 配置の値 | 上の「配置」の表 | 見出し・説明・図・"TAP TO CLOSE" の位置と文字の大きさ |
| `swatch` / `swatchGap` | 縦 120・24 / 横 80・16 / 横長 96・16 | スウォッチの一辺と、2 枚の隙間 |

## テスト観点

- **ボタンの判定**（レイアウトごとの純粋関数。入力はキャンバス座標）: 縦のボタンは x=204〜564・y=1568〜1656。中心 (384, 1612) は内、境界の角 (204, 1568) と (564, 1656) は内（縁は含む）、(203, 1612)・(565, 1612)・(384, 1567)・(384, 1657) は外。横は x=720〜960・y=670〜730、横長は x=1304〜1624・y=635〜745（どれも縁を含み、1px 外は外）。ボタンの矩形は、各レイアウトでキャンバスに収まり、`Title` の他の要素（文字・パネル・"TAP TO START"）と重ならない。ボタンの高さ × 縮小率が、縦 390x844（0.508）で 44 以上（88 × 0.508 ≒ 44.7）、横長 844x390（0.508）と 667x310（0.404）で 44 以上（110 × 0.404 ≒ 44.4）、横 800x600（0.78）で 44 以上（60 × 0.78 ≒ 46.9）。
- **Title の遷移**: ボタンの中の入力は `Help` へ、外の入力（デモの絵の上を含む）は `Game`（今日の日付・セット番号 1）へ。同じフレームに 2 つの入力（ボタンの中と外）が届いても遷移は 1 回で、先に処理した方だけ。遷移した後は時計を進めてもデモは進まない。`Help` を開いても `Game` の日付・セット番号には影響しない。
- **入力ロックと戻り**（時間は引数で渡す）: `Help` が始まってから 299 ms の入力は無視、300 ms の入力で `Title` に戻る。ロック中の入力は後で効かない（299 ms に押して、300 ms に何もしなくても戻らない）。戻る遷移は 1 回だけ（同じフレームの 2 回目は無視）。リサイズ（向きの変化）でロックの経過時間は変わらない。
- **配置**（縦・横・横長）: 上の表の座標どおりに、見出し・説明 6 行・図の 6 セル・"TAP TO CLOSE" が置かれる。すべてキャンバスに収まり、互いに重ならない。セルの順序は行優先で、横長だけ 3 x 2。例: 縦の 5 番目のセル（EXTRA）は 3 行目の 1 列目で、スウォッチは x=60〜180・204〜324、y=1198〜1318。横長の 4 番目のセル（GONE）は 2 行目の 1 列目で、スウォッチは x=896〜992・1008〜1104、y=330〜426。縦と横長の文字は 32px 以上。
- **文言**: 見出しは "HOW TO PLAY"、種類名は COLOR・MOVE・SIZE・GONE・EXTRA・SHAPE、促し文は "TAP TO CLOSE"。説明は上の 6 行がこの順・この文字列で出る。2 行目の数字は `missPenalty`、4 行目の数字は `stageCount` と一致する。
- **図の見本**: 6 種類それぞれで、左右の絵の差が表のとおり（COLOR は色相だけ、MOVE は中心の x だけ、SIZE は半径だけ、GONE は右に主な図形がない、EXTRA は左に主な図形がない、SHAPE は種類だけ）。差のない部分（背景・共通の四角）は左右で同一。図形がスウォッチの内側（0〜1）に収まる（SIZE の右の円は 0.18〜0.82、MOVE の右の円は x=0.42〜0.82）。乱数を使わない（何度生成しても同じ）。
- **回帰条件（遊び方の説明の追加で変えないもの）**: `Game`・`Result` のルール、誤クリックの罰（5 秒）、持ち時間・図形数・差分数、スコア、`(日付, セット番号, ステージ)` のシードの決め方、一時停止、演出・UI（`Game`・`Result` のもの）、`Title` のデモの仕組み・手順・タイミング・配置（ボタン以外の要素の位置）、日付の表示、"TAP TO START" の点滅、`Title` から `Game` へ「今日の日付・セット番号 1」で開始すること、保存しないこと。既存のテストが（Scene を 4 つにする変更を除いて）そのまま通る。`Help` は `localStorage`・`sessionStorage`・`IndexedDB` を使わない（コードの検索で確認する）。

## 完了条件

- `Title` の縦（390x844）・横（1024x768）・横長（844x390）のスクリーンショットで、"HOW TO PLAY" ボタンが他の要素と重ならずに表示され、文字が読める。ボタンを押すと `Help` が開く。ボタンの外（デモの絵の上を含む）をタップすると、従来どおり `Game` が始まる。
- `Help` の縦・横・横長のスクリーンショットで、見出し・6 行の説明・6 つの図・"TAP TO CLOSE" が切れずに重ならずに表示され、図の左右の違いが見分けられる（縦と横長の文字は 32px 以上）。開いて 300 ms 以降のタップで `Title` に戻り、新しいデモが始まる。向きを変えても（縦・横・横長のどの間でも）`Help` が崩れない。
- `Help` を足しても、`Game`・`Result` のルール、誤クリックの罰、持ち時間・図形数・差分数、スコア、シード、一時停止、演出・UI、`Title` のデモ、`Title` の日付の表示と "TAP TO START" の点滅、`Title` から `Game` への開始（今日の日付・セット番号 1）、保存しないことが変わっていない（上の回帰条件のテストと、既存のテストが通る）。
- `README.md` に、`Title` の "HOW TO PLAY" から遊び方の説明を見られることが書かれている。
- 共有ビルド（`task build`）でも `Title` から `Help` が開く。

## 実装裁量

- ボタンの色・縁・文字色、`Help` の説明・図の文字色、スウォッチの縁取りの有無（背景との識別ができ、文字は背景と十分なコントラストを持つこと）。
- 説明の行間（表の「上端 y」を守る範囲）、折り返しの実装手段、フォント（`UI_FONT`）。
- `Help` のオブジェクトの作り方（再利用して `update` で生成しないこと）。入力ロックの数え方の実装（`update` の delta で数えること）。開発ビルド専用の QA 用スナップショット（`window.__qa`。本番には含めない）。
- 図の描画で、既存の図形描画を使い回す部品の分け方。
- ボタンの当たり判定を、Phaser の入力オブジェクトで行うか、矩形の判定関数で行うか（遷移の規則・最初の 1 回だけ・縁を含むことを満たす範囲）。
