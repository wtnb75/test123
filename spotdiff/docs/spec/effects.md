## 画面・Scene構成

### 演出・UI

プレイヤーの操作や出来事への反応と、読みやすさのための表示。**どの演出も入力を止めない**（仕様が入力を無視する状態を除く）。描画は Phaser の Graphics とテキストだけで行い、画像・音声は使わない。オブジェクトは作り直さず再利用し、`update` で生成しない。時間はすべて「出来事のフレームを t=0 として、ちょうど D で消える」に統一し、`update` の経過時間で数える（`delayedCall` は使わない）。

**共通ルール**

- **一時停止**: `paused` に入る時、×と「-5」はその場で消す。赤丸の広がりとメッセージのポップは最終値（拡大率 1.0）に確定する（再開後に続きはやらない）。状態で決まる表示（残り時間の警告色、時間切れの黄色い開示、初回ヒント）は再開後も条件を満たす限り続く。残り時間の警告の拡縮は、`paused` の間は時間 t を止め、再開後にその続きから進める。
- **Scene 再開・遷移**: 演出の状態は Scene と一緒に捨て、次の Scene に持ち越さない。新しいステージが始まる時は、残っている×・「-5」・広がりをすべて消す。
- **レイアウトの変更**（縦・横・横長のどれの間でも）: 演出は新しいレイアウトで描き直し、経過時間は引き継ぐ。×と「-5」は「パネル番号（上下／左右のどちらか）とパネル内座標」で保持し、描画のたびに現在のレイアウトのパネル位置と表示倍率から画面位置を求め直す。
- **画面外**: ×はパネル内のタップにしか出ないので収める必要はない。「-5」は、上昇前の中心の x だけを `[40, キャンバス幅-40]` に収める（縦の拡大したパネルの端をタップしても文字が切れないように。y は収めない。上昇しても画面外に出ない位置にしかタップできない）。
- **文字の大きさ**: 縦レイアウトと横長レイアウトでは、HUD・メッセージ行・Title・Result・一時停止画面・「-5」の文字は、キャンバス上で 32px 以上にする（縦は幅 390 CSS px、横長は 844x390 のスマホで 16 CSS px 以上に見える）。HUD は、32px のときの幅に `1 + lowTimePulse` を掛けても縦キャンバス幅 768 以下になるフォントを選ぶ（文字が等幅のフォントは避ける。横長のキャンバスは幅 1664 なので収まる）。
- **押しやすさ**: 縦レイアウトの 390x844 の画面（`Scale.FIT` で幅に合う）で、最小の判定円（直径 `2*(shapeSizeMin + hitMargin)` = 68px）が 44 CSS px 以上になる（表示倍率 1.75 × 縮小 約 0.51 で約 60 CSS px）。横長レイアウトの 844x390 の画面（`Scale.FIT` で幅と高さがほぼ同率に合う。縮小 約 0.507）でも同じく 44 CSS px 以上になる（表示倍率 1.6 × 約 0.507 で約 55 CSS px）。文字（16 CSS px 以上）と判定円（44 CSS px 以上）の条件は、横長では 844x390 以上の画面で守る（これより小さい画面では、縮小に応じて小さくなってよい）。

**Game**

| 演出 | きっかけ・内容 | 時間 | 描画順・競合 |
|---|---|---|---|
| 誤クリックの×と「-5」 | 誤クリック（パネル内で外れた入力）のたびに、タップ位置へ赤い × を出す（線幅 5px、一辺 `missMarkSize`。どちらもキャンバス上の px で、表示倍率では拡大しない）。同時に「-5」（常に `-` + `missPenalty`。残り時間が足りず実際の減算が少ない時もこの表示）を同じ位置に出し、`missPopupRise` px 上へ動かしながら消す | ×は `missMarkMs` で透明度が 1→0（直線）。「-5」は `missPopupMs` で透明度 1→0、上昇は 0→`missPopupRise`（直線） | ×は赤丸の上・HUD の下、「-5」は HUD の上・一時停止画面の下。同時に出せる数は `missMarkMax` 個ずつで、超えたら最も古いものを再利用する。同一フレームの誤クリックはそれぞれ独立に出す。誤クリックで時間切れになった場合も同じフレームで出し、`over` の間も時間どおり進める |
| 当たりの赤丸の広がり | 当たり（発見）のたびに、その差分の赤丸（両パネル同時）の半径だけを中心から広げて出す（線幅 4px は固定）。時間切れの黄色い開示は広げず、すぐ全体を出す | `hitPopMs` で半径の拡大率が `hitPopFrom`（0.6）→1.0（イーズアウト: `from + (1-from)*(1-(1-p)^3)`、p は 0〜1 の進み具合）。透明度は常に 1 | 最後の差分の当たりでも広がる（`clear`／`won` 中も進める）。他の赤丸には影響しない |
| 時間切れの開示の色 | `over` で未発見の差分の判定円を、発見済みの赤と区別して黄色（`revealMarkColor`）で描く | `over` の間ずっと（状態で決まる） | 発見済みの赤丸はそのまま赤 |
| 残り時間の警告 | `displaySeconds` が `lowTimeSec`（10）以下の間、HUD の文字色を赤系（`lowTimeColor`）にする。`play` の間は、さらに HUD を拡縮する（拡大率 `1 + lowTimePulse*(1-cos(2π*t/lowTimePulseMs))/2`、t は警告に入ってからの経過ms。範囲 1.0〜`1+lowTimePulse`） | 色: 状態で決まる（`clear`／`won`／`over` でも ≤10 なら赤のまま）。拡縮: `play` のみ、周期 `lowTimePulseMs`。t=0 は、`play` 中に `displaySeconds` が `lowTimeSec` 以下になった（初めて、または誤クリックで一気に下がった）フレームで、そこから数える。`clear`／`won`／`over` に入ったら拡大率は即 1.0 に戻る。拡縮は HUD の中心を基準にする | 新しいステージで残り時間が `lowTimeSec` を超えれば元の色・拡大率 1 に戻る。HUD の幅に収める縮小と掛け合わせ、拡縮で一時的に幅を超えてもキャンバス幅内に収まる程度（`lowTimePulse` ≦ 0.12）。色だけでなく動きでも知らせる |
| 初回ヒント | ステージ1・セット番号1・`play`・発見数 0 の間、メッセージ行に "Tap where the pictures differ" を出す。最初の当たりで消える（誤クリックでは消えない） | 状態で決まる | メッセージ行を使う。`clear`／`won`／`over` のメッセージが出る時は、そちらが優先（ヒントが出ている間に発見数 0 のまま時間切れになったら、その瞬間に "TIME UP" に置き換わる）。ヒントの文字は縦・横長でも 32px 以上 |
| メッセージのポップ | "CLEAR!"・"ALL CLEAR!"・"TIME UP" が出る瞬間（メッセージが出たフレームが t=0）に、文字を拡縮する | `msgPopMs`。拡大率は 0→0.6D で `msgPopFrom`（0.8）→`msgPopPeak`（1.15）、0.6D→D で `msgPopPeak`→1.0（それぞれ直線）。D 以降は 1.0 | 初回ヒントのメッセージにはかけない |

**Title のデモ**

| 演出 | きっかけ・内容 | 時間 | 描画順・競合 |
|---|---|---|---|
| タップの輪 | ボットがタップするたびに、1 枚目のパネルのタップ位置に白い輪（線幅 `demoRingWidth` = 4px。キャンバス上の px で、表示倍率では拡大しない）を出し、半径を `demoRingFrom` から `demoRingTo`（キャンバス上の px）へ（直線で）広げながら透明度を 1→0（直線）にする | `demoRingMs`（t = 0 はタップのフレーム） | 赤丸の上・文字の下。タップの間隔（`demoTapMs`）は `demoRingMs` より長いので、輪どうしは重ならない。次のステージへの切り替えと作り直しの開始で、残っている輪は消す |
| 当たりの赤丸の広がり | タップで差分が発見済みになるたびに、`Game` と同じ広がり（両パネルに同時。「Game」の表を参照） | `hitPopMs` | 輪と同じフレームに始まる。作り直しの透明化の間は、絵と一緒に透明になる |
| 作り直しの透明化 | ステージを見せ終えたあと、絵（パネルの背景・図形・赤丸・輪）が透明になり、新しい絵が現れる | 透明になるのに `demoFadeMs`、現れるのに `demoFadeMs`（透明度は直線） | 文字（ゲーム名・説明・日付・TAP TO START）には掛けない。透明化の間はタップせず、再生中の赤丸の広がりは最終値に確定する |

**Title・Result**

- 「TAP TO START」「TAP FOR NEXT SET」「TAP TO RETRY」: 透明度を `promptPulseMin + (1 - promptPulseMin) * (1 + cos(2π * t / promptPulseMs)) / 2` で往復させる（t は Scene が始まってからの経過ms。t=0 で 1.0、`promptPulseMs/2` で `promptPulseMin`、`promptPulseMs` で 1.0）。`Result` では入力ロック中も動かす。
- Result の見出し・SET・STAGE・TIME・促し文: 表示した瞬間から `resultFadeMs` で透明度が 0→1（直線）。促し文の透明度は、このフェード係数と上の点滅の値の積。入力ロック（`resultInputLockMs`）には影響しない。
