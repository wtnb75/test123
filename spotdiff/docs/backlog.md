# spotdiff 拡張候補（backlog）

公開済みの spotdiff に次に足せる要素の候補。上ほど優先（先頭が次の候補）。spec ではない。採用するときは `game-extend` で 1 件を選んで詰め、`game-spec` で spec に書く。

- 規模: S = 小さな追加（既存の仕組みの範囲） / M = 新しい種類・仕組みを 1 つ / L = 複数の仕組みにまたがる（`game-extend` で 1 PR 分に切り出してから採用）
- 「自動プレイ」の数字の条件: 日付 20300000〜20300299 の 300 セット（セット番号 1、各 5 ステージ）の中央値・割合。ゲームのロジックだけを動かした数字で、人が見て見つけやすいかは分からない。差分の種類の割合は、増加を足したあとの 6 種類で、シード 1〜300 の各 5 ステージを測った（色 18%・消失 17%・移動 14%・増加 17%・大きさ 16%・形 17%。四捨五入なので合計は 100% にならない）
- どの候補も、差分を選ぶルール（いまは 6 種類を等確率）を変える。採用するときは、ステージごとにどの種類を出すか（早いステージは易しい種類だけ、など）も `game-extend` で決める

### 明るさの差分（色覚への配慮を含む）（`tone-diff`）

- 狙い: 色の差分は色相のずれだけで、後半は 30° まで小さくなる。赤と緑のように見分けにくい色の組み合わせでは、見えない違いになりうる。明るさ・彩度だけが変わる違いも無い。根拠: spec 「差分の内容」（色: 色相を `hueShift[s]` 度ずらす）とパラメータ表（120 / 80 / 55 / 40 / 30°）、図形の色の範囲（彩度 0.55〜0.9・明度 0.4〜0.6）。実際に見分けにくい人のデータはまだない
- 何を足すか: 色の差分で明るさも同時に変えて、色だけに頼らずに違いが分かるようにする。あわせて、色相は同じで明るさ（または彩度）だけが変わる差分を足す。
- コアループへの効き方: 広げる — 色覚の違いで差分が「見えない」ことがなくなり、色相の違いより気づきにくい、静かな差分が加わる。
- 種別: gameplay
- 規模: M
- 出どころ: spec 分析
- メモ: 採用前に、色覚シミュレーションで見え方を確認し、見えにくくなる色差分の割合を測る。明るさだけの差分は気づきにくいので、ステージ後半に限る・変化量の初期値は小さすぎないようにする。難しさに強く効くため、足したあとは `game-balance` で見る。大きければ、色の差分の修正を先に出す。

### 回転の差分（`rotate`）

- 狙い: 図形に角度の概念がなく、三角も頂点が上向きだけ。向きが変わる違いがない。根拠: spec 「絵の描画」（図形は頂点が上の二等辺三角形、四角は軸に平行）
- 何を足すか: 図形に角度を持たせ、右の絵で一定の角度だけ回転している差分
- コアループへの効き方: 広げる — 「同じ位置・同じ形・同じ色に見えて向きが違う」という見分けが加わる
- 種別: gameplay
- 規模: M
- 出どころ: ユーザー / spec 分析
- メモ: 円は回しても変わらないので、対象は四角・三角（`more-shapes` の図形があればそれも）。回した後も外接の正方形に収まる範囲（回転で四隅が飛び出さない大きさの扱い）を決める

### 背景の差分（`background-diff`）

- 狙い: 全差分が図形に結びついていて、背景の装飾の円は差分にならない。図形の外を見る必要がない。根拠: spec 非MVP範囲（背景の差分）と「背景」の規則（装飾は左右同一で、差分にしない）
- 何を足すか: 背景の装飾の円が、右の絵で消える・動く・大きさが変わる差分
- コアループへの効き方: 広げる — 探す範囲が図形の外の背景にも広がる
- 種別: gameplay
- 規模: M
- 出どころ: spec 分析
- メモ: 装飾の円はパネルの端で切れて描かれる（矩形でクリップする）ので、判定円の扱いと端のときの見え方を決める。spec の非MVP範囲から「背景の差分」を外すことになる

### リングの図形を足す（`ring-shape`）

- 狙い: 図形が塗りつぶしだけで、見た目の違いが「形」と「色」に限られる。根拠: spec 「図形の描画」（塗りつぶしだけで描く。縁取り・模様なし）。`more-shapes` で形を 6 種類にしたとき、リング（中抜きの円）は、塗り方の差分まで増えるので見送った
- 何を足すか: 縁取りだけのリング（中抜きの円）を足す。ステージが進むと混ざる。
- コアループへの効き方: 広げる — 塗り方（塗り／縁取り）が、形・色とは別の見分けの軸になる。
- 種別: gameplay
- 規模: S〜M
- 出どころ: ユーザー / spec 分析
- メモ: 「塗り方が変わる」差分を作るかは `game-extend` で決める。図形ごとに外接の正方形（一辺 `2*size`）に収める規則は守る。

### ベストスコアを保存し、トップページに出す（`best-score`）

- 狙い: スコア（クリア時の残り秒の合計）があるのに、保存されない。リスタートしても比べる記録が無く、トップページのカードにも何も出ない。根拠: `spec`「勝利・失敗・スコア」、「永続化: なし」、非MVP範囲（ハイスコアの永続化）
- 何を足すか: セットごとのスコアの最高値を `shared/best-store` の約束（キー `spotdiff.best`、値 `{score, label}`）で保存し、`Result` に新記録を出す。トップページのカードに `label` が出る。
- コアループへの効き方: 広げる — 「前回の残り時間を超える」目標が、ゲームの外にも見える。ルール・時間・スコアの付け方は変えない。
- 種別: presentation-only
- 規模: S
- 出どころ: ユーザー（ハイスコアが無い公開中のゲームの洗い出し）
- メモ: 「永続化: なし」の記述と非MVP範囲を、spec で書き換える（`game-spec`）。セット（日替わりなど）ごとにスコアの条件が違うなら、どれを代表にするかを `game-extend` で決める（代表は 1 件、モード別は `best-store-modes` の領域）。保存の失敗でもゲームが止まらないこと（`BestStore` が担う）。

### 模様のある図形を足す（`patterned-shapes`）

- 狙い: 図形に模様が無く、絵の見た目の幅が狭い。根拠: spec 「図形の描画」。`more-shapes` で形を 6 種類にしたとき、縞・水玉の模様は、塗り方の差分まで増えるので見送った
- 何を足すか: 縞・水玉などの模様のある図形を足す。ステージが進むと混ざる。
- コアループへの効き方: 広げる — 絵の見た目がさらに多彩になる。
- 種別: gameplay
- 規模: M
- 出どころ: ユーザー / spec 分析
- メモ: `ring-shape` の後。模様のある図形を足すと、「塗り方が変わる」差分（模様の有無・縞の向き）が自然に生まれるので、差分の種類の割合（6 種類・各 8〜25%）と判定円をどう扱うかを `game-extend` で決める。

### 戻ったときに操作してから再開する（`pause-resume`）

- 狙い: `HIDDEN` では幕を出してタップで再開するが、`BLUR`（PC のフォーカス外れ）では止まらず、残り時間が進む。根拠: ユーザーの声（復帰時に突然再開されるゲームがある。フォーカス外れとスマホで動作を揃えたい）、`spotdiff/src/game/scenes/Game.ts`（`HIDDEN` / `VISIBLE` だけ拾う）、`spotdiff/src/game/logic/run.ts`（`hide` / `show` / `resume`。復帰後 `resumeInputLockMs` の間はタップを受けない）
- 何を足すか: ページが見えなくなった（`HIDDEN`）かウィンドウがフォーカスを失った（`BLUR`）とき、ゲームの時間を止めて幕を出す。戻っても勝手には再開せず、タップかキーを押したときに、止まった続きから再開する。再開に使った操作は、それだけで終わる（打つ・動くなどのゲームの操作にはならない）。停止のきっかけに `BLUR` を足す。幕・復帰直後の入力ロック・再開のタップの扱いは、いまの仕様を変えない。
- コアループへの効き方: 広げない — 復帰時の不意の失点・失敗を防ぐ。コアループそのものは変えない。
- 種別: gameplay
- 規模: S
- 出どころ: ユーザー
- メモ: ルート `docs/backlog.md` の `shared-pause`（共通部品）の後。共通部品に載せて作る。`BLUR` で止めたあと、ページは見えているので、`show()` のロック開始のタイミング（`VISIBLE` に頼らない）を spec で決める。spec は `absorb/docs/spec/pause.md` と同じ形（`docs/spec/pause.md`）に分ける。
