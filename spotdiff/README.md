# spotdiff

図形で描いた2枚の絵から、違う箇所を制限時間内に見つける間違い探しです。

## 遊び方

- 左右（縦持ちのスマホでは上下）に並んだ2枚の絵を見比べて、違う箇所を探します。
- 違いは「色」「位置」「大きさ」「消えている」「増えている（右の絵にだけ図形がある）」「形（円・四角・三角が別の形に変わる）」の6種類です。
- 全5ステージで1セットです。ステージが進むほど、図形が増え、違いは小さく・多くなります。
- セットの絵は、日付とセット番号で決まります。同じ日の同じセット番号なら、何度遊んでも同じ絵です。

## 操作方法

- クリック／タップだけで遊びます（マウスでもタッチでも同じ）。
- 違うと思う場所を、どちらの絵の上でも押してください。見つかると、両方の絵に赤い丸が付きます。
- 違いのない場所を押すと、残り時間が5秒減って画面が揺れます。
- ブラウザのタブを切り替えたり、スマホの画面を消したり別のアプリを開いたりすると、時間が止まります。戻ったら一時停止画面をタップして再開します。

## ルール

- 各ステージの違いをすべて見つけるとステージクリアです。
- 持ち時間はステージごとに 60 / 55 / 50 / 45 / 40 秒です。時間が 0 になるとゲームオーバーで、同じセットを最初のステージからやり直します。
- 5ステージすべてをクリアするとセットクリアです。次のセット（別の絵）へ進めます。
- 結果画面の「TIME」は、各ステージをクリアした時の残り秒の合計です（セットごとに数え直します）。
- 記録は保存しません。ページを開き直すと、その日のセット1から始まります。

## 開発

```bash
pnpm install
pnpm --filter spotdiff dev            # 開発サーバー
pnpm --filter spotdiff lint           # ESLint
pnpm --filter spotdiff test           # Vitest
pnpm --filter spotdiff test:coverage  # カバレッジ (90%以上)
pnpm --filter spotdiff build          # 静的サイトのビルド
```

詳細な仕様は [`docs/spec.md`](docs/spec.md) を参照してください。
