# mazetd (Maze TD)

壁と砲台で迷路を作って守るタワーディフェンス。敵の道のりを長くして、砲台で撃ち落とそう。

## どんなゲーム?

- 何もない盤面(9 × 12 マス)の上から下へ、敵が **S** から **G** に向かって歩いてくる
- 敵はいつも S から G までの **最短経路** を通る。壁や砲台を置いて道を曲げれば、敵の道のりが長くなる
- **壁**(5 コイン)は安いけれど攻撃しない。**砲台**(25 コイン)は高いけれど、壁の代わりにもなり、射程(2 マス)に入った敵を自動で撃つ
- 「迷路を長くする(壁)か、火力を増やす(砲台)か」のコインの配分が腕の見せどころ
- 建設フェーズでは、敵が通る予定の経路が黄色い点で表示される。置くたびに更新されるので、道の伸び方を見ながら組み立てられる
- 「砲台」を選んでいる間は、置いた砲台の射程が半透明の円で表示される

## 操作方法

タップ(クリック)だけで遊べます。スマートフォンでも PC でも同じ操作です。

| 操作 | 方法 |
|------|------|
| 道具を選ぶ | 画面下の「壁」「砲台」「売却」ボタンをタップ |
| 置く | 「壁」か「砲台」を選んで、盤面の空いているマスをタップ |
| 売る | 「売却」を選んで、壁か砲台のマスをタップ(費用の半分が戻る。端数は切り捨て) |
| ウェーブ開始 | 「開始」ボタンをタップ |
| リスタート | 結果画面をタップ |

- 置いたり売ったりできるのは、ウェーブとウェーブの間(建設フェーズ)だけ
- S と G には置けない。S から G への道を完全にふさぐ置き方もできない

## ルール

- 全 10 ウェーブ。最後のウェーブをしのげばクリア
- ライフは 10。G にたどり着いた敵 1 体につき 1 減り、0 になるとゲームオーバー
- 初期コインは 60。敵を倒すと +2、ウェーブを終えると +10
- ウェーブが進むごとに、敵の数と HP が増えていく
- スコア = 倒した数 × 10 + (クリアしたときだけ)残りライフ × 50

仕様の詳細は [docs/spec.md](docs/spec.md) を参照。

npm run test
