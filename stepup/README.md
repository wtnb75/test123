# stepup（空中足場のぼり）

自動で上へ進む画面を、ジャンプと、空中で自分で作る足場で登っていくアクションゲームです。上から降ってくる弾をよけながら、高さ 200 m のゴールに乗ればステージ 1 クリアです。

## 遊び方

- 画面は一定の速さで上へ進みます。下に取り残されたら失敗です。
- ボタンは 1 つです。足が地面（足場）についているときはジャンプ、空中にいるときは足元に足場ができます。
- 足場は同時に 2 枚まで（3 枚目を作ると一番古いものが消える）で、3 秒で消えます。地面でジャンプした直後の 0.3 秒は、足場を作れません。
- 上から弾が降ってきます。落ちる位置には、弾の向きを指す三角の予告が先に出ます。弾に当たると失敗です。高く登るほど、弾が速く・多く、斜めの弾も増えます。
- 高さ 200 m のゴール（緑の足場）に乗るとクリアです。
- 到達した高さの自己ベストは、このブラウザに保存されます。Title に「自己ベスト 137 m」（クリアしたら「200 m クリア」）と出て、記録を更新したプレイの Result に「NEW BEST!」が出ます。

## 操作方法

| 操作 | スマホ（タッチ） | PC（マウス） | キーボード |
|---|---|---|---|
| 左右に動く | 画面のどこでも左右にスワイプ（指を止めて押さえている間も動き続ける） | ドラッグ | ← → |
| ジャンプ / 足場 | 画面をタップ。スワイプ中は、2 本目の指でタップ | クリック | Space または ↑ |

画面を縦にして遊んでください（横向きの小さい画面では「画面を縦に」の案内が出ます）。

## 開発

```sh
pnpm install
npm run dev      # 開発サーバー
npm run lint
npm run test
npm run test:coverage
npm run build    # dist/ に静的サイトを出力
```
