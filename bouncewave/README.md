# bouncewave（打ち返しインベーダー）

敵の玉を打ち返して、自分の玉にしろ！ パドルで戦うインベーダー。

## どんなゲーム?

- 画面の上に並んだ敵の編隊が、赤い玉（ひし形）を撃ってくる
- パドルで受けると、玉は水色の丸（自分の玉）に変わって跳ね返る
- 自分の玉は壁や敵で跳ね返り続ける。敵に当たると倒せる
- 編隊は左右の壁で折り返すたびに少しずつ降りてくる。敵が減るほど編隊は速くなる
- 敵を全滅させると次のウェーブ。ウェーブが進むほど撃つ間隔が短く、敵の段が増える
- 赤い玉が画面の下に落ちるとライフが 1 減る。ライフ 3 がなくなるとゲームオーバー
- 編隊がパドルの上の赤い点線まで降りてくると、ライフが残っていてもゲームオーバー（倒さずにいると約 1 分で届く。倒すほど編隊は速くなるので、全滅させてウェーブを終わらせよう）
- 自分の玉は取り逃しても消えるだけ。受け直すほど攻撃が続く

## スコア

- 敵 1 体につき 10 × ウェーブ番号
- 自己ベスト（スコアと到達ウェーブ）はブラウザに保存される

## 操作方法

### スマートフォン / タブレット

- パドル: 画面のどこでも、指の左右の位置にパドルが付いてくる
- ボタン: START / もう一度 / タイトルへ をタップ
- 横向きで画面が小さいときは「画面を縦にしてください」と出る。縦にすると続きから遊べる

### PC

- パドル: マウスを左右に動かす、または ← →
- 開始・もう一度: Enter / Space
- タイトルへ（結果画面）: Esc
