# 予測線

## 概要

パドルに最も早く届く玉を、いまのパドル位置で受けたらどこへ跳ね返るかを、細い点線で見せる。パドルを動かして、受ける位置（跳ね返る角度）を狙って決められるようになり、コアループの「どこで受けるか」の判断が見て分かる。表示だけで、ルール・得点・数値は変えない。

## 操作仕様

追加・変更なし（パドルの操作・跳ね返りの角度はそのまま。予測線は表示だけで、操作には使わない）。

## 画面・Scene 構成

Game だけが変わる。Title のデモ（`spec/title-demo.md`）・Result は変えない（デモに予測線は出さない）。

### 予測線（Game）

- 見た目: 細い白系の点線（太さ `AIM_LINE_WIDTH`、点の長さ `AIM_DASH`、すき間 `AIM_GAP`、不透明度 `AIM_LINE_ALPHA`）。折れ線は、パドルで受けた玉が置かれる位置（パドルの上）から始まり、壁で跳ね返る所で折れ、止める位置（「ルール」）で終わる。点の並びは、始点から数えた道のりで決める（始点は点で始まり、点の長さ `AIM_DASH` → すき間 `AIM_GAP` を繰り返す。毎フレーム始点から数え直すので、パドルを動かすと点の並びも始点に付いて動く）。折れ目をまたいで続く（折れ目で途切れても、すき間の長さがずれない）
- 出す条件: `playing` で、予測の対象の玉があり、その玉を「いまのパドル位置」で受けられるとき（「ルール」）。`waveClear`・`ending`・対象が無い・受けられないときは出さない。パドルを動かすと線が動く（毎フレーム、`Run` の更新のあとに、そのフレームのパドル位置で計算し直す）
- 描画の順（奥から）: 背景 → 場の枠 → 危険ライン → **予測線** → 編隊 → パドル → …（それ以降は変えない）。予測線は玉・敵より奥なので、玉や敵が重なる所では隠れる
- スマホ縦で読めること: 点線は補助の表示なので文字の大きさの基準（AGENTS.md 4.6）の対象外。小さい画面で細くなっても、点線が見えること（太さは論理 px で、SE の縦（縮小率 約 0.69）で実寸 1 px 台）
- 画面の揺れ（ライフが減ったとき）では、予測線も一緒に揺れる（カメラの揺れ）
- 「縦にしてください」の案内が出ている間は Game の進行が止まり、線は前フレームのまま案内に隠れる。戻ったときは次のフレームで描き直される

## ルール

### 予測線の対象と形

- 対象の玉: 下向き（vy > 0）に動いていて、まだパドルの上面に届いていない玉（中心の y < 接触の y = パドルの中心の y − `PADDLE_HEIGHT` / 2 − `BALL_RADIUS`）のうち、接触の y まで下がるのに要する時間 `(接触の y − 玉の y) ÷ vy` が最も短い玉。敵の玉・自分の玉とも対象になる。同じ時間なら id の小さい玉。該当する玉が無ければ予測線は出さない
- 届く x: 対象の玉の x を、その時間のあいだ vx で進め、左右の壁（玉の中心の x の範囲 [`FIELD_LEFT` + `BALL_RADIUS`, `FIELD_RIGHT` − `BALL_RADIUS`]）で折り返した位置（折り返しを何回挟んでもよい）。この x を使う。ほかの玉・編隊の動きは考えない（いまの位置で止めて計算する）
- 受けられるか: 届く x とパドルの中心 x の差が `PADDLE_WIDTH` / 2 + `BALL_RADIUS` 以下（ちょうどなら受ける。ゲームの受ける判定と同じ）なら受けられる。受けられないなら予測線は出さない
- 跳ね返りの向き: ゲームの受け方と同じ。`offset` = （届く x − パドルの中心 x）÷（`PADDLE_WIDTH` / 2）を [−1, 1] に収め、真上から `offset × PADDLE_MAX_ANGLE` 傾けた向き（vx ∝ sin、vy ∝ −cos）。始点は（届く x, 接触の y）
- 折れ線: 始点から、自分の玉と同じ規則（左右の壁・上の壁で跳ね返る。壁の内側の面は玉の半径を引いた範囲）で進め、次のいずれかで止める。(1) 玉の円が編隊の敵の矩形に初めて接した（重なりの深さが 0 を超える直前の）位置 — 敵は、いまの位置で止めて考える（編隊の動きは予測しない）。(2) 壁で跳ね返った回数が `AIM_MAX_BOUNCES` を超えた位置（左右・上のどの壁も 1 回と数える。`AIM_MAX_BOUNCES` + 1 回目の跳ね返りの点で止め、そこを終点にする）。(3) 下向きになって接触の y に戻った位置（敵に当たらず戻ってくる場合）。折れ線は、始点・壁で跳ね返った点・止めた点を並べたもの
- この予測は表示のためだけで、ゲームの状態（玉・敵・スコア・乱数）には触れない
- Title のデモの run には予測線を出さない（`Game` だけが描く）

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `AIM_MAX_BOUNCES` | 4 | 予測線が壁で跳ね返る回数の上限 |
| `AIM_LINE_WIDTH` | 2 | 予測線の太さ（論理 px） |
| `AIM_DASH` / `AIM_GAP` | 8 / 8 | 予測線の点の長さとすき間（論理 px） |
| `AIM_LINE_ALPHA` | 0.55 | 予測線の不透明度 |

## テスト観点

- 予測の対象の玉 `pickAimBall`: 敵の玉（y 400、vy 240。時間 (675 − 400) ÷ 240 ≈ 1.146）と自分の玉（y 500、vy 460。≈ 0.380）が下向き（論理の高さ 792、パドルの中心の y 692、接触の y 675）→ 自分の玉。上向きの玉は対象にならない。接触の y に届いている・超えている玉は対象にならない。同じ時間なら id の小さい玉。玉が無ければ無し
- 届く x `arrivalX`: x 500・vx 120・時間 0.5 → 560 が右の限界 523 を超えるので 486（523 − 37）。x 20・vx −100・時間 0.5 → −30 が左の限界 17 を下回るので 64（17 + 47）。x 300・vx 333・時間 2 → 966 → 折り返しを繰り返して 80（周期 1012 の 949 → 1012 − 949 = 63、17 + 63）。壁を 2 回以上挟む長い時間でも範囲内に収まる
- 受けられるか: 差がちょうど `PADDLE_WIDTH` / 2 + `BALL_RADIUS` = 64 → 受ける。64.01 → 受けない（線は出ない）
- 予測の折れ線 `aimPath`: 論理の高さ 792・ウェーブ 1・編隊が出たままの位置で、パドルの中心 x = 305、x = 305・vy > 0・vx = 0 の玉 → `offset` = 0 で真上。始点（305, 675）。最初の敵（4 列目の一番下の段。下端 248）に円が接する位置 y ≈ 257（= 248 + 9）で止まる（±1 px）。パドルの中心 x = 270・玉の x = 325（`offset` = 1）なら右へ 60° の線で、右の壁（x = 523）で折れ、左の壁（x = 17）で折れてから、左下の敵に接して止まる（折れ点の y は 560.68 と 268.53、終点は約 (58, 244.86)）。`offset` = −1（玉の x = 215）は左右が逆。敵がいなければ、真上（パドルの中心 x = 玉の x）は上の壁（y = 73）で折れ、接触の y に戻って止まる。敵に当たらずに壁で `AIM_MAX_BOUNCES` 回を超えたら、その（5 回目の）点で止まる（パドルの中心 x = 270・玉の x = 325・敵なしなら、折れ点は (523, 560.68)・(17, 268.53)・(355.6, 73)・(523, 169.7) の次の 5 回目が (17, 461.8)）
- 敵との接し方: 敵の側面から玉の半径以内（深さが 0 を超える）に入る線は止まり、ちょうど半径の外側（0.01 外）の線は通り抜けて先へ進む。隣の敵との間のすき間（14 px）は玉（直径 18 px）より狭いので通れない
- 予測は状態を変えない: `aimPath` を呼んだ前後で、`Run` の玉・敵・スコア・ライフ・乱数の状態が同じ（純粋）。呼ぶたびに前の線を空にして作り直す
- 回帰（変えないもの）: 予測線を足しても、得点・ライフ・編隊・玉・段・乱数の引き方はこの拡張の前と同じ（`Run` の状態遷移を変えない）。Title のデモの結果が変わらない
- 単体テストの対象外: 点線の描画、画面の揺れとの重なり。QA で確かめる

## 完了条件

- `npm run lint` エラー 0 件、`npm run test` 全通過、`npm run test:coverage` 90% 以上、`npm run build` 成功（共有ビルドでも起動する）
- 予測線が、パドルに最も早く届く玉の跳ね返り先を、壁で折れながら最初の敵まで出し、パドルを動かすと動く。受けられない・対象の玉が無いときは出ない（ブラウザで確認。SE の縦・スマホ縦・PC で、点線が見える）
- 変えないもの（回帰条件）:
  - パドルの操作と、受けた玉の速さ・向き（`offset` で決まる）
  - 玉の速さ・跳ね返り・当たりの大きさ、敵の玉
  - 編隊の動き・折り返しと危険ラインの規則、撃つ間隔
  - ライフ、段（受け直し）の仕組みと色、得点の式、自己ベストの保存
  - Title とデモ（デモに予測線は出ない。デモの結果は変わらない）。Result の表示
  - 演出（倒したときの白い四角は白のまま、「+N」の見た目）
- 表示だけの拡張なので、自動プレイで測るものは無い（`Run` の状態遷移を変えないことを、テストで確かめる）
