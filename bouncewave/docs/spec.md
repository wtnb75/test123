# 打ち返しインベーダー（bouncewave）

## コンセプト

画面の上に並ぶ敵の編隊が撃ってくる玉を、パドルで打ち返して自分の玉にし、敵を倒す。全滅させると次のウェーブ。

## コアループ

1. 落ちてくる敵の玉（赤いひし形）を見る
2. パドルで受ける。当たる位置で跳ね返る角度が変わる（中央は真上、端ほど斜め）
3. 受けた玉は自分の玉（水色の丸）になり、左右と上の壁、敵で跳ね返って、また落ちてくる
4. 敵の玉と自分の玉を同時にさばく

- 敵は自分の玉が 1 回当たると倒れる。玉はその敵で跳ね返る
- 敵の玉が画面の下端に届くとライフ -1（0 で終わり）。自分の玉は取り逃しても消えるだけ
- 敵の玉は敵をすり抜ける。玉どうしは当たらない
- 撃つのは、各列で一番下にいる敵のうち 1 体（ランダム）
- 敵を全滅させると、少し間をおいて次のウェーブの編隊が出る。そのとき画面に残った敵の玉は消え、自分の玉は残る
- スコア: 敵 1 体につき 10 × ウェーブ数

## 操作仕様

- タッチ・マウス: パドルが指（ポインタ）の x 位置に追従する
- キーボード: ←→ でパドルを動かす
- 終わった画面でタップすると、最初からやり直す

## パラメータ表

値は `src/proto/params.ts` と一致させる。論理サイズは 540 × 960（縦）。

| 項目 | 値 |
|---|---|
| パドルの幅 × 高さ | 110 × 16 px |
| パドルの y | 860 |
| パドルのキー移動速度 | 720 px/s |
| パドル端での跳ね返り角（真上から） | 60° |
| 玉の半径 | 9 px |
| 敵の玉の速さ | 240 px/s |
| 敵の玉の向きのばらつき（真下から） | ±20° |
| 自分の玉の速さ | 460 px/s |
| 編隊の列数 | 6 |
| 編隊の段数 | 3 段から、2 ウェーブごとに +1（最大 6） |
| 敵の大きさ / すき間 | 56 × 30 px / 14 px |
| 編隊の上端 y | 130 |
| 編隊の横移動の速さ | 50 px/s（端で折り返す） |
| 撃つ間隔 | 1.6 s × 0.88^(ウェーブ-1)、下限 0.45 s |
| ライフ | 3 |
| 1 体のスコア | 10 × ウェーブ |
| ウェーブ間の間 | 1.0 s |

## プレイテストで固まったこと

スマホ実機で 1 回遊んで確認した（2026-10-25）。

- コアループ（受けて打ち返す → 自分の玉が跳ね続ける → 敵の玉と自分の玉を同時にさばく）は、このままでよい。手触りは良好
- 操作: パドルが指の x 位置に追従する方式で、スマホ実機で問題なし
- 玉の見分け（敵の玉は赤いひし形、自分の玉は水色の丸）で分かる
- ルールは上の「コアループ」の箇条書きのとおりで、変更なし
- 課題（実装時のバランス調整で扱う。プロトタイプでは直さない）:
  - 敵の動きが単調（編隊が左右に動くだけ）
  - 難しさが低めで、上がり方も緩い
- プロトタイプに無く、完全版で要るもの: Title、自己ベストの保存と表示、結果画面。また、論理サイズを 540 × 960 に固定しているため、スマホの縦画面では上下に黒い帯が出る（AGENTS.md 4.6）
