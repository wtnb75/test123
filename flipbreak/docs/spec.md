# flipbreak 仕様（spec-lite）

## ゲーム名

フリップブレイク（`flipbreak`）

## コンセプト

縦長のピンボール台の上に並んだブロックを、フリッパーで玉を打ち上げて崩す。バンパーで跳ね返る軌道を読み、全部崩すと面クリア。玉を落とすと残機が 1 減り、3 回でゲームオーバー。

## コアループ

1. 右端のレーンでプランジャーを溜めて離し、玉を発射する
2. 玉が壁・バンパー・ブロックで跳ね返る
3. 落ちてくる玉をフリッパーのタイミングで打ち上げる
4. ブロックを全部崩せば面クリア、玉が下に抜ければ残機 -1

## 操作仕様

| 入力 | 操作 |
|---|---|
| キーボード | ← / Z = 左フリッパー、→ / `/` = 右フリッパー、↓ / Space を押し続けて溜め、離して発射、R = 玉をレーンに戻す（プロトのみ） |
| タッチ | 画面の左半分を押している間 = 左フリッパー、右半分 = 右フリッパー。玉がレーンにある間は、画面のどこかを押し続けて溜め、離して発射 |

## プレイテストで固まったこと

スマホ（トンネル経由）で遊んで、上のパラメータ表の値のまま確定した。数値の変更は無し。

- 台の構造: 画面は縦長（360 × 640）で、右端 30px がプランジャーのレーン、残りが台。レーンの上端は斜めの壁で台側へ曲がる。台の下には左右の斜面（ガイド）と左右のフリッパーがあり、フリッパーの間の隙間（約 40px）から玉が落ちる。
- 斜面とフリッパーの接ぎ目: 斜面の線は、フリッパー（太さ半径 7）の上面と同じ高さに揃える。揃えないと、フリッパーの根元に段差ができ、低速の玉が乗り上げられずに止まる（プレイテストで起きた不具合。修正済みで、実機でも止まらなくなったことを確認済み）。
- 玉が詰まらないこと: フリッパーを下げた状態の玉は、斜面からフリッパーへ転がって必ず下に抜ける（段差で止まらない）。
- フリッパーを上げたままにすると、上がったフリッパーと斜面の谷に玉が挟まることがある。離せば転がり出るので、仕様として許容する。
- プランジャー: 弱い溜め（目安 0.6 以下）では玉が台に届かずレーンに戻り、溜めが強いほど高く上がる。レーンに戻った玉は、また発射できる（レーン内で止まっていれば発射可）。満タンでは玉は台の上部まで届く。
- 操作: 玉がレーンにある間、タッチは画面のどこを押しても溜める。台に出たあとは、画面の左半分・右半分を押している間だけフリッパーが上がる。
- フリッパーは押している間だけ上がり、離すと戻る。上がっているフリッパーは玉に回転の勢いを与える（動く面の速度を反射に足す）。
- バンパーは当たると玉を弾き、最低 480 px/s で跳ね返す。当たるたびに 10 点。
- ブロックは 1 回当たると崩れ、玉は跳ね返る（反発 1）。1 個 100 点。
- 玉が台の下（画面の下端の外）に抜けたら残機 -1。レーンに戻して次の発射を待つ。残機 0 でゲームオーバー。
- ブロックを全部崩すと「STAGE n CLEAR」を 1 秒出して次の面へ。最後の面を崩すと「ALL CLEAR」。

## 見送ったこと

- フリッパーを上げ続けても玉が谷に挟まらないようにする工夫: 離せば転がり出るので、ピンボールとして普通の挙動と判断した（プレイテストでユーザーに確認して許容）。
- 玉が詰まったときの救済（R キーで玉をレーンに戻す）: プロトだけの機能。本実装でどうするかは `game-spec` で決める（詰まりを無くしたうえで、救済が要るかを判断する）。
- スリングショット、スペシャルブロック（マルチボールなど）、動くブロックや硬いブロック、面の自動生成・エディタ、ランキング: コンセプトの段階で非MVPと決めた。プロトでは扱っていない。
