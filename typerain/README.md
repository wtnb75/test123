# typerain（TYPE RAIN）

降ってくる英単語を、キーボードで打って消せ！ 床に着いたらライフが減る。

## どんなゲーム?

- 画面の上から英単語（3〜8 文字）が降ってくる。打ち切ると単語が消えて得点が入る
- 最初の 1 文字を打つと、その文字で始まる一番下の単語にロックオンする（白くなり、打った部分が黄色になる）。打ち切るか床に着くまで、ロックオンは外れない
- 違う文字を打つと「ミス」。コンボが切れて、画面が少し揺れる（ライフは減らない）
- 単語が床に着くとライフが 1 減る（最初は 3 つ）。ライフが 0 になったら終わり
- 時間がたつほど、単語が速く、多く、長くなる

## スコア

- 得点 = 文字数 × 10 × コンボ倍率（1 + コンボ × 0.1。上限 3 倍）
- 打ち切るとコンボが 1 増える。ミスをするか、単語が床に着くとコンボは 0 に戻る
- 自己ベストはブラウザに保存される

## 操作方法

### スマートフォン

- START をタップすると、スマホのキーボードが出る。英字を打って単語を消す
- キーボードを閉じてしまったときは、画面をタップするとまた出る
- 画面は、キーボードが出ても盤面が隠れないように、残りの領域に合わせて縦が縮む
- 横向きでキーボードが出て画面が小さくなると「画面を縦にしてください」と出る。縦にすると続きから遊べる

### PC

- 物理キーボードで英字を打つ（大文字・小文字は区別しない）
- 開始・もう一度: Enter
