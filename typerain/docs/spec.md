# TYPE RAIN（仮称）

## コンセプト

上から英単語が降ってくる。OS キーボードで打ち切ると消え、床に着くとライフが減る。ライフ 3 つが尽きるまでのスコアを競う、スマホ向けのオーソドックスなタイピングゲーム。

## コアループ

降りてくる単語を見る → 先頭の文字から打つ（その文字で始まる一番下の単語に自動ロックオン） → 打ち切って消す → 次の単語を選ぶ。

## 操作仕様

- スマホ: 画面をタップすると隠し input にフォーカスして OS キーボードが出る。打った文字を判定する
- PC: 物理キーボードで直接打つ（タップ / Enter でフォーカス）
- ロックオン中に違う文字を打つと「ミス」（無視。コンボが切れる）
- 開始・リトライは画面タップか Enter

## パラメータ表

`src/proto/params.ts` と一致させる。

| 項目 | 初期値 |
|---|---|
| 論理サイズ | 幅 360 固定。高さは表示領域（キーボードが出たら残りの領域）の縦横比に合わせて 240〜640 で変える（初期 480）。左右の余白を作らず、文字は縮めない |
| 遊べない高さ | 論理サイズの高さが 240 を下回る（横画面でキーボードが出た等）と、「画面を縦にしてください」を全面に出し、ゲームは一時停止（落下・出現・入力を止める）。高さが戻れば続きから再開 |
| 床の位置 | 下端から 30 の位置（高さに追従） |
| 落下速度の基準 | 床 y = 450 のときの値。床の高さに比例させ、落ちきるまでの時間は画面の高さによらず一定 |
| 単語の文字数 | 3〜（最大 4 から 20 秒ごとに +1、上限 8） |
| 同時に出る数の上限 | 6 |
| 落下速度 | 36 px/s から毎秒 +0.6、上限 120 |
| 出現間隔 | 2.4 秒から毎秒 -0.02、下限 0.8 秒 |
| ライフ | 3 |
| スコア | 文字数 × 10 × コンボ倍率（1 + コンボ × 0.1、上限 3） |

## プレイテストで固まったこと

実機（スマホ）で遊んで確かめた内容。数値は上の表のまま（プレイ感の調整は入れていない）。

- **入力**: 画面タップで隠し input にフォーカスし、OS キーボードを出す。キーボードは出て、そのまま使える（確認済み）。打った文字は input の値の増分で読み、a-z 以外は無視する。バックスペースは無視
- **ロックオン**: 最初の 1 文字で、その文字で始まる一番下の単語に自動でロックオンする。ロックオン中の違う文字はミス（コンボが切れ、画面が少し揺れる）。単語の先頭文字が重ならないように出す（候補が尽きたら重なってよい）
- **キーボードと画面サイズ（最重要）**:
  - キーボードが出ると表示領域の下半分が隠れ、単純な縮小では「半分を過ぎた単語が見えない」「縮んで読みにくい・左右に余白が出る」となった
  - 解決: 論理サイズの幅を 360 に固定し、高さを表示領域（`visualViewport`）の縦横比に合わせて変える。文字は縮めず、左右の余白も出ない。実機で「いい感じ」と確認済み
  - 落下速度は床の高さに比例させ、落ちきるまでの時間を画面の高さによらず一定にする。高さが変わったとき、落ちている単語の位置も比例して動かす（残り時間を保つ）
  - 横画面でキーボードを出すと高さが足りない（論理サイズの高さが 240 未満）。この場合は無理に遊ばせず、「画面を縦にしてください」を出して一時停止する（ユーザーの判断）
- **画面**: 開始前（タップで開始）、プレイ中、ゲームオーバー（スコアとベスト、タップでリトライ）の 3 つ。Title の作り込みはしない
- **ベスト**: プロトタイプでは保存しない（セッション中のみ）。完全版で `localStorage` に保存するかは `game-spec` が決める
