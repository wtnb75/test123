# fukuwarai (ふくわらい)

福笑い風パーツ配置ゲーム。お題の元絵を覚えて、パーツ（眉・目・鼻・口）をドラッグで並べ、仕上がりが元絵とどれだけ似ているかをスコアで採点する。

## ゲームの目的

記憶を頼りに顔のパーツを正しい位置・向きに配置し、なるべく高いスコアを目指す。

## 遊び方

1. 最初にお題の元絵（完成した顔）が表示されるので覚える
2. 「はじめる」を押すと元絵が隠れ、パーツ配置フェーズに切り替わる（元絵は以後見られない）
3. 画面下部のトレイから、覚えた通りの位置・向きにパーツをドラッグして並べる
4. 「採点する」を押した時点の配置でスコアが決まる
5. 結果画面で、実際に並べた顔・スコア・正解の顔（比較用）を確認する

## 操作方法

- パーツ上の好きな場所をつかんでドラッグする。つかんだ点がポインタに追従し、引っ張る位置・方向に応じて位置と回転が同時に決まる
- **配置エリア**（顔を組み立てる領域）で指/マウスを離すと、その位置・角度でパーツが確定し、以後動かせなくなる
- **トレイ領域**で離すと確定せず、離した場所から何度でもつかみ直せる
- ドラッグ中は、つかんだ点に小さな印（マーカー）が表示される
- パーツの当たり判定は薄い円で常に表示されているので、掴める範囲が分かる
- PC（マウス）・スマホ（タッチ）どちらでも遊べる

## ルール

- 制限時間・ライフはない。元絵は最初に一度だけ表示され、以後は再表示されない
- 「採点する」を押した時点の配置でスコア（0〜100点）が決まる。トレイに残ったパーツもそのまま採点対象になり、低スコアに反映される
- スコアは、プレイヤーの配置と正解の配置をピクセル単位で比較した類似度。何も配置しない場合は0点になるよう基準化されている

## 開発

```bash
pnpm install
pnpm --filter fukuwarai dev            # 開発サーバー
pnpm --filter fukuwarai lint           # ESLint
pnpm --filter fukuwarai test           # Vitest
pnpm --filter fukuwarai test:coverage  # カバレッジ (90%以上)
pnpm --filter fukuwarai build          # 静的サイトのビルド
```

詳細な仕様は [`docs/spec.md`](docs/spec.md) を参照してください。
