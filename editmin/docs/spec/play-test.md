# 作った盤面をその場でプレイする（play-test）

## 概要

編集中の盤面を、そのまま遊べるプレイモードに切り替える。「プレイ」を押した時点で開始マスは開いていて（周囲へ連鎖して開く）、数字を見て地雷の位置を推理し、地雷と思うマスには旗を立てる。作った盤面が実際に遊べるか、判定（難易度・論理解法可否）を自分の手で確かめる。プレイは盤面を書き換えない。作る → 遊ぶ → 直す、の循環を作る。

## 操作仕様

- 「プレイ」ボタン: サイドバーに 1 つ置く。並びは、開始マス指定・コピーの行の下、ズームの行の上の 1 行。編集中は「プレイ」、プレイ中は「編集に戻る」と表示する。
- 開始マスが未指定のとき、「プレイ」は押せない（無効）。その行の直下に 1 行「開始マスを指定するとプレイできます」を出す（11 px 以上。長いときは折り返す）。爆弾が 0 個の盤面でも「プレイ」は押せる（下の「ルール」）。
- プレイ中の盤面での操作は 2 つ: マスの左クリックで、そのマスを開く。マスの右クリックで、そのマスに旗を立てる（旗のマスなら外す）。開いたマスを押しても何もしない（左右とも）。旗の立ったマスは、左クリックでは開かない（旗を外してから開く）。
- プレイ中、フォーカス中のマスで Space・Enter を押しても何もしない（マスを開くのも旗もクリックだけ）。キーボードの操作は追加しない。
- プレイ中の盤面では、右クリックのメニューを出さない（`preventDefault`）。旗の立て外しはプレイ中だけで、編集中の右クリックは今までどおり何もしない。キーボードでは旗を立てない。
- プレイ中は次が効かない: 爆弾の左クリックトグル・キーの Space による爆弾トグル・開始マス指定・サイズの入力と「反映」。
- プレイ中の表示モードのボタンは、文字（今のモード）を変えず、無効表示にする。キー `M` も効かない。表示モードはプレイの見た目に使わない。編集に戻るとプレイ前のモードに戻る。
- プレイ中も使える: ズーム（ボタン・キー・Ctrl+ホイール）、スクロール、判定結果の表示、「盤面テキストをコピー」（編集中と同じ形式で、爆弾の配置をそのままコピーする）。コピーの失敗は、従来どおり「盤面テキストをコピー」の状態表示に出す（プレイの状態行は使わない）。
- プレイの状態は保存しない。リロードすると編集に戻る。

## 画面・Scene 構成

- 盤面表示エリアは編集と同じ。「プレイ」の開始・終了で、マスのボタンを作り直さず、マスの見た目（クラス）だけを切り替える。
- 判定結果表示エリアの最上段に、プレイの状態を 1 行で出す（実寸 14 px 以上。長い文は折り返し、画面の右端で切らない）:
  - 編集中: 出さない（今までどおり）
  - プレイ中: 「プレイ中」
  - 爆死: 「爆死。爆弾を見せています」
  - クリア: 「クリア」
- マスの見た目（プレイ中）:
  - 未開のマス: 通常色。進入禁止マス（開始マス周囲 8 マス）の色は、開く前から、表示モードの規則どおりに出す
  - 開いたマス: 淡色の面。隣接爆弾数を出す（0 は空欄）。数字は、マスの 1 辺が `COMPACT_CELL_PX` 以上のときだけ出す（既存の規則。未満では淡色の面だけ）。進入禁止マスを開いたときも同じ淡色の面にする
  - 開始マス: 「プレイ」を押した時点で開いていて、枠を残す（淡色にはしない）
  - 旗のマス（未開のマスだけ）: 旗「⚑」を出す。旗は、マスの 1 辺が `COMPACT_CELL_PX` 以上のときだけ文字で出す。未満では、文字の代わりに旗のマスを橙色の面で塗る（旗の有無が分かること）。旗のマスは開かない。旗は爆弾かどうかを判定しない（間違った旗もそのまま立つ）
  - 爆死・クリアのあとは、すべての爆弾を濃い面で見せる。「B」は、マスの 1 辺が `COMPACT_CELL_PX` 以上のときだけ出す（未満では濃い面だけ）。爆死したマスも同じ規則
  - 爆死のあと、未開の安全なマスは未開のまま（数字は出さない。旗が立っていれば旗のまま）。旗の立っていた爆弾は、爆弾として見せる（「B」・濃い面。旗より爆弾を優先する）
- 数字が見えない倍率（1 辺が `COMPACT_CELL_PX` 未満）でもプレイはできる。ヘルプ文に「数字はマスが 20 px 以上のときに出ます」と書く。

## ルール

- 開始マスは、「プレイ」を押した時点で開いている（プレイの始まりの状態）。開始マスには爆弾が無い（既存の開始マス安全性）ので、その数字は 0 で、開いた瞬間に周囲へ連鎖する。プレイの始まりの時点で、連鎖で開いたマスもすでに開いている。
- 数字 0 のマスを開くと、8 近傍の未開のマスも開く。開いたマスの数字が 0 なら、さらにその 8 近傍を開く（連鎖）。数字が 1 以上のマスでは止まる。連鎖で爆弾は開かない。連鎖は旗のマスも開かない（旗を外して自分で開く）。
- 爆弾のマスを開くと爆死。プレイは終わり、以後の開く操作は無視する。
- 爆弾以外のすべてのマスが開いたら、クリア。プレイは終わる（旗の有無・正しさは関係しない）。爆弾が 0 個の盤面では、「プレイ」を押した時点（開始マスが開いた時点）でクリアになる。
- 「編集に戻る」でプレイを終え、編集の状態に戻る。盤面（サイズ・開始マス・爆弾の配置・判定結果）は変わらない。
- 再挑戦: プレイ中・終了後は、まず「編集に戻る」を押し、それから「プレイ」を押す。開いたマス・旗・爆死・クリアの状態は消え、開始マスだけ（と、その連鎖）が開いた状態から始まる。
- 判定（難易度・論理解法可否）はプレイの結果に関係しない（プレイは判定の値を使わない）。判定の表示は、プレイ中も今までどおり見える。
- 座標の書き方は、(行, 列)、0 始まり。

## パラメータ表

新しい数値は無い。マスの大きさの規則は既存の `COMPACT_CELL_PX`（20 px）を使う。旗の橙色の面（縮小時）の具体色は実装裁量（通常色・淡色・進入禁止の色と区別できること）。

## テスト観点

純粋関数（`play.ts`、Phaser と DOM に依存しない）の単体テスト。戻り値は `{ ok: true, state }` または `{ ok: false, reason }` とし、`reason` は `'NO_START' | 'ENDED' | 'FLAGGED'` のいずれか（名前は実装裁量）。
- 開始マス未指定のとき、プレイを始められない（`NO_START`）
- 開始マス指定後に始められ、始まりの状態で開始マスとその連鎖がすでに開いている。手で数えた例: 5 × 5 の盤面で爆弾が (4,4) の 1 つだけのとき、始まりの状態で、爆弾以外の 24 マスがすべて開き、そのままクリアになる
- 数字 1 以上のマスは連鎖を止める。手で数えた例: 2 行 × 5 列の盤面で、爆弾が (0,2) と (1,2) の 2 つ、開始マスが (0,4) のとき、始まりの状態で開いているのは (0,4)・(0,3)・(1,3)・(1,4) の 4 マス（(0,3) と (1,3) の数字は 2 で止まる。列 0〜1 は開かない）
- 爆弾が 0 個の盤面では、始まりの状態でクリアになる
- 旗: 未開のマスに旗を立て、もう一度で外せる。開いたマスには旗を立てられず（状態は変わらない）、終了後（爆死・クリア）は旗を立て外しできない（`ENDED`）。旗のマスを開こうとすると、状態は変わらず `FLAGGED` が返る。旗はクリア判定に関係しない（爆弾以外のマスに旗が立っていても、外してすべて開けばクリアになる。旗の立った爆弾は、旗のあいだは開かないので爆死しない）
- 爆死・クリアのあと、旗の立っていた爆弾は爆弾として見える（`revealedMine`）。旗の立った安全な未開のマスは、旗のまま見える
- 爆弾を開くと爆死になり、以後の開く操作は `ENDED` で無視される
- 連鎖は旗のマスを開かない（旗を外して開くまで、そのマスは未開のまま。クリアにもならない）
- 爆弾以外のすべてを開くとクリアになる（残り 1 マスのとき、そのマスを開いてクリアになる境界値も含む）。旗が爆弾以外のマスに立っていても、外して開けばクリアになる
- 連鎖は爆弾を開かない
- 開いたマスを開き直しても、盤面は変わらない
- 「編集に戻る」で盤面（爆弾・開始マス・サイズ）が変わらない
- 編集に戻ってから「プレイ」を押すと、開いた状態と旗が消えて、始まりの状態（開始マスと連鎖だけ開いている）から始まる
- 入力の盤面を破壊的に変更しない

DOM（ブラウザ）の確認は QA で行う（単体テストの対象外）: 開始マス未指定で「プレイ」が無効、プレイの開始・終了でマスのボタンが作り直されない、「プレイ」を押した直後に開始マスと連鎖が開いている、右クリックで旗が立ち外れる（⚑ と、縮小時の橙色の面）、爆死・クリアの見た目、プレイ中に爆弾トグル・表示モード・右クリックのメニューが出ないこと、Space・Enter でマスが開かないこと、数字の大きさの規則。

## 完了条件

- 開始マス未指定では「プレイ」が押せず、理由が出る
- 「プレイ」を押した時点で、開始マスと、数字 0 の連鎖で開く周りが開いている。数字 1 以上で連鎖が止まる。爆弾は開かない
- 爆弾を開くと爆死で終わり、爆弾がすべて濃い面で見える（「B」は 20 px 以上のときだけ）。爆弾以外をすべて開くとクリアで終わる。爆弾 0 個の盤面は「プレイ」を押した時点でクリア
- 右クリックで、未開のマスに旗を立て外しできる。旗のマスは左クリックで開かない。旗は勝敗に関係しない。右クリックのメニューは出ない
- 「編集に戻る」で編集に戻り、盤面（サイズ・開始マス・爆弾・判定結果）は変わらない
- プレイ中は、爆弾のトグル・開始マス指定・サイズ入力・表示モードが効かない。Space・Enter でマスは開かない
- プレイの開始・終了で、マスのボタンは作り直さない（DOM の確認）
- 開いたマスの数字は、マスの 1 辺が `COMPACT_CELL_PX` 以上のときだけ出る（既存の規則と同じ）
- 回帰（既存と同じ）: 隣接爆弾数の計算、開始マスの制約（周囲 8 マス・拒否・自動解除しない）、開始マス指定の操作（UI で選んでからクリック）、爆弾のトグル、開始マス未指定のときは判定が未評価で表示される、`evaluateDifficulty` とそのテスト、サイズ入力の丸め（2〜50）、反映・リサイズで表示倍率が変わらない、「盤面テキストをコピー」の形式、スクロールが盤面表示エリア内だけ、既存のボタン・表示の並び（プレイの行の分だけ下がる。並びの順番は変えない）、ズーム、表示モード（編集中）
- `npm run lint` / `npm run test` / `npm run test:coverage` / `npm run build` が成功する。カバレッジ 90% 以上

## 実装裁量

- 開いたマスの淡色、濃い面の色（既存の色の範囲で、表示モードの濃い面と同じ色でよい）、旗の文字・橙色の具体値、状態行の文言の細部（上の文言を変えない範囲）、「プレイ」ボタンの大きさ・余白（既存のボタンと同じ範囲）、ヘルプ文の言い回し
- `play.ts` のファイル名と関数の形、盤面の状態（開いたマス・爆死・クリア）の持ち方（純粋なデータとして返す）
