# match3（3マッチパズル）

となり合う石を入れかえて、同じ色を 3 つ以上そろえて消そう。連鎖で点数が伸びる、オーソドックスな 3 マッチパズル。

## どんなゲーム?

- 8 × 8 の盤面に、6 色の石が並ぶ。色ごとに形も違う（赤=丸・青=四角・緑=三角・黄=ひし形・紫=六角形・橙=星）ので、色が見分けにくくても形で見分けられる
- となり合う（上下左右の）2 つの石を入れかえて、同じ色を縦か横に 3 つ以上そろえると消える
- 消えた分は上から石が補充される。補充で新しくそろうと連鎖になる
- そろわない入れかえは元に戻り、手数は減らない（色の石を使うときは別。下）
- 4 個以上をそろえると、そろえた場所に「特殊な石」が 1 つ残る（下）
- 手数は 30。手数が 0 になり、最後の連鎖が終わったら終わり
- 動かせる手がなくなったら、石の並びを自動で入れかえる
- 5 秒ほど操作しないと、おすすめの手の 2 つの石がふくらんだりちぢんだりして教えてくれる。おすすめは、盤面の下のほうの手を優先し（下で消すと上が落ちて連鎖しやすい）、同じ高さなら消える数が多い手

## 特殊な石

4 個以上をそろえたとき、そろえた場所に特殊な石が 1 つ残ります。入れかえで動かした石のマスにできます（連鎖でできたときは、そろった並びの真ん中あたり）。特殊な石は、あとで消えるときに効果が出ます。ほかの特殊な石の効果に巻き込まれても出て、同じ消去の中で連鎖して広がります。

| 石 | できるとき | 効果 |
|---|---|---|
| 線の石（白いバーつき） | 一直線に 4 個。横にそろえたら縦のバー、縦にそろえたら横のバー | バーの向きの 1 列（または 1 行）を全部消す |
| 爆発の石（白いリングつき） | L 字・T 字・十字にそろえた | まわりの 3 × 3 を消す |
| 色の石（6 色の円） | 一直線に 5 個以上 | となりの石と入れかえると、その石と同じ色を盤面から全部消す。そろわなくても入れかえでき、手数を 1 つ使う |

- 線の石と爆発の石は、元の色のまま。その色でそろって消えるときに効果が出る
- 特殊な石どうしを入れかえても、特別な組み合わせの効果はない
- 色の石がある間は、いつでも動かせる手があるので、自動の入れかえは起きない

## スコア

- 1 回に消した石 1 個につき 10 点（特殊な石の効果で消えた石も数える）
- 1 回に 4 個以上を同時に消すと、3 個を超えた分の 1 個ごとに +20 点
- 連鎖 n 段目の得点は n 倍（2 連鎖目は 2 倍、3 連鎖目は 3 倍…）
- 得点は、消えた場所に `+点数` で出る（連鎖は `CHAIN xn`、4 個以上は `BONUS` つき）
- 自己ベストはブラウザに保存される

## 操作方法

### スマートフォン / タブレット

- 入れかえ: 石をタップして選び、となりの石をタップ。または、石をとなりの方向へなぞる（スワイプ）
- ボタン: START / もう一度 / タイトルへ をタップ（押した場所で離したときに働く）
- 横向きで画面が小さいときは「画面を縦にしてください」と出る。縦にすると続きから遊べる

### PC

- 入れかえ: クリック 2 回、またはなぞる（ドラッグ）
- キーボード: ← → ↑ ↓ でカーソルを動かし、Space / Enter で石を選ぶ。選んでいる間は ← → ↑ ↓ でその方向のとなりと入れかえ。Esc で選択を解く
- 開始・もう一度: Enter / Space
