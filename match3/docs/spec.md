# 3マッチパズル（仮称 / `match3`）

## コンセプト

隣り合う 2 つの石を交換して、同じ色を縦か横に 3 つ以上そろえて消す。消えた分は上から補充され、連鎖でスコアが伸びる。決まった手数の中で高スコアを狙う、オーソドックスな 3 マッチパズル。

## コアループ

盤面を見る → 隣と交換する → そろって消える → 落下・補充 → 連鎖、を繰り返す。手数が尽きたら結果を表示し、タップでリトライする。

## 操作仕様

- タップ 2 回: 1 つ目の石をタップして選び、隣の石をタップして交換する。隣でない石をタップしたら、選び直す。
- スワイプ: 石から隣の方向へ指（マウス）を動かすと交換する。
- そろわない交換は元に戻り、手数を消費しない。
- 動作中（交換・消去・落下の間）は入力を無視する。

## パラメータ表

| 名前 | 初期値 | 意味 |
|---|---|---|
| `COLS` / `ROWS` | 8 / 8 | 盤面の列数・行数 |
| `COLORS` | 6 | 石の色数 |
| `MOVES` | 30 | 手数（そろった交換 1 回で 1 消費） |
| `CELL` | 60 | 1 マスの大きさ（px、論理サイズ 540 × 960） |
| `SCORE_PER_GEM` | 10 | 消した石 1 個あたりの基本点 |
| `BONUS_PER_EXTRA_GEM` | 20 | 同時に消した数が 3 を超えた分、1 個ごとの追加点（4 個なら +20、5 個なら +40） |
| `CHAIN_MULTIPLIER` | 連鎖の段数 | n 連鎖目の点は（消した数 × 基本点 + 追加点）× n |
| `SWIPE_RATIO` | 0.4 | スワイプと見なす移動量（CELL に対する比） |
| `SWAP_MS` | 150 | 交換のアニメーション |
| `CLEAR_MS` | 200 | 消去のアニメーション |
| `FALL_MS_PER_CELL` | 90 | 落下 1 マスあたりの時間 |
| `HINT_DELAY_MS` | 5000 | 無操作でヒント（そろう交換の 2 つの石を脈動）を出すまでの時間 |

## プレイテストで固まったこと

- 操作感（タップ 2 回・スワイプ）は良好。変えない。
- 得点は、消えた場所に `+点数`、連鎖のときは `CHAIN xn` を浮かべて見せる。得点ルールを説明する常設テキストは要らない（かえって邪魔）。
- 同時に 4 個以上消したときはボーナス点を入れる。数えるのは 1 回の消去で消えた石の総数（縦横の run が複数でも合算）。表示は `BONUS` を `+点数` の上に出す。
- 詰まりそうなときのために、無操作が `HINT_DELAY_MS` 続いたら、そろう交換を 1 つ選んで 2 つの石を脈動させる。操作を始めたら止まる。

## 見送ったこと

- 4 つ以上そろえてできる特殊な石（同じ色の行・列を消すなど）— 基本形を先に固めるため、ボーナス点で代替した（アイデアの段階で非MVP）。
- 目標付きのステージ — MVP は手数制限のスコア勝負のみ。
- アイテム — 基本形の外。
- ランキング — 自己ベストの保存だけにする。
- 交換のルールの派生（ナナメ隣・桂馬・列スライド）— `docs/ideas.md` の Inbox に既にある 3 案。公開後に、交換のルールを差し替える拡張として足す。MVP では差し替えやすい構造にしておく。
