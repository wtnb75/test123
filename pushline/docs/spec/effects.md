# 演出・UI

## 概要

一列が消える・出現・間引き・失敗の揺れ・手数の警告などの演出と UI の手がかりの一覧、時間の規則、描画順。ルールと数値の意味は変えない。用語・Game の配置・`ending`・`Quit の確認時間` などの共通の定義は `docs/spec.md` にある。

## 操作仕様

なし（操作は `docs/spec.md` の「操作仕様」のまま。）

## 画面・Scene 構成

### 演出・UI

| 手数の警告 | 手数が `警告の手数` 以下のとき（手数が変わるたびに判定） | 「手数 N/…」の文字が赤くなり、等倍と `警告の拡大` 倍の間で拡縮を繰り返す（鼓動のように） | `警告の周期` で 1 往復、手数が `警告の手数` を超えるまで続く | 受け付ける |
| 手数の危険 | 手数が `危険の手数` 以下のとき（手数が変わるたびに判定） | 手数の警告に加えて、拡縮が速くなり（`危険の周期`）、画面の縁が `危険の縁の太さ` の赤い帯で脈打つ（不透明度 0 と `危険の縁の不透明度` の間を、同じ周期で往復） | `危険の周期` で 1 往復、手数が `危険の手数` を超えるまで続く | 受け付ける |

- 時間の規則: きっかけのフレームを t = 0 とし、各演出は独立に再生する。新しいきっかけは既存の演出を止めず、重ねて再生する。
- 一列が消えたときの演出の順序（一列を消した押しを t = 0 とする。`次の演出の開始` = `ライン消しの予告光` + `ライン消し演出` = 370 ms）:

  | 時刻 | 動き |
  |---|---|
  | 0〜`ライン消しの予告光`（150 ms） | 消える一列が白く光る。ほかのブロック（間引かれるブロック、置き直される押せないブロックの元のマスを含む）は、そのままの見た目 |
  | 150〜370 ms | 消える一列が縮む（`ライン消し演出`） |
  | 370 ms（`次の演出の開始`） | 出現、間引き、置き直しの縮小が同時に始まる |
  | 370 + `出現演出の開始遅れ`（480 ms） | 置き直しの広がりが始まる（置き直しがあるときだけ） |

  出現は 590 ms、置き直しの広がりは 700 ms に終わる（`出現演出` = 220 ms）。間引きは 370 + 980 = 1350 ms に終わる。一列が消えた押しの前に始まった演出には影響しない。
- 盤面の本体は、押した瞬間（t = 0）に更新済みの状態になる。光る・縮む・まだ始まらない出現・間引き前のブロック・置き直しの元のマスは見た目だけで、入力の判定には影響しない（空きマスは、歩ける・押し込める。出現するマスや置き直しの新しいマスは、広がる前でも、ブロックがあるものとして扱う）。
- 演出の途中で入力を受けたら、出現と置き直し（縮小と広がり）を、まだ始まっていないものも再生中のものも含めて、その場で完成した状態にする（出現するブロックは等倍で現れ、置き直しの元のマスのブロックは消え、新しいマスに等倍で現れる。`次の演出の開始` ちょうどの入力も同じ）。出現するブロックは消える一列のマスにも現れうる。その場合は、完成させた新しいブロックを、光る・縮む旧ブロックの上に描く（出現が上）。光る・縮む・間引きは、決まった時刻のまま再生を続ける（間引きがまだ始まっていなければ、`次の演出の開始` に始まる）。入力を止めたり遅らせたりはしない。対象の入力は、盤面に対する操作を試みた入力で、歩き・押す・1 マス移動（動けない場合を含む）と、タップの失敗の揺れが出る入力である。何も起こさない入力（履歴が空のときの Undo、自分のマスのタップ、盤面の外のタップ、「Quit」の 1 回目のタップ、`ending` の間の入力）では完成させない。「戻す」（履歴が空でないとき）は対象にする。タップ移動の歩きの 2 マス目以降は、新たな入力ではないので対象にしない。一列を消した押しがもう一度起きたときは、その入力で前の一列の分を完成させたうえで、新しい一列の順序を t = 0 から始める。
- Title のデモは、プレイヤーの入力で完成させない。デモでは、出現と置き直しの広がりが終わるまで、次の一手を動かさない（[Title とデモ](title-demo.md) の「デモ」の節）。
- 描画順（下から）: 盤面のマス → 間引きの演出（灰色のブロック）→ キャラクター → ライン消し・出現・置き直しの演出用のブロック → 失敗の赤い枠・歩きの輪（ブロックとキャラクターより手前）→ HUD・操作ボタン・「+N」 → 画面の縁の赤い帯 → 画面のフェード（最前面）。間引きの灰色のブロックが残っている間も、そのマスは空きマスとして扱い、キャラクターは歩ける（見た目だけ）。同じマスに間引きの演出と出現の演出が重なる場合は、出現が上に描かれる。
- Title の描画順（下から）: デモの盤面（上の Game と同じ順で、盤面のマス → 間引き → キャラクター → ライン消し・出現・置き直し）→ ゲーム名・Start ボタン → 画面のフェード（最前面）。ゲーム名と Start ボタンは盤面と重ならない位置にあるので、互いに隠れない。切り替えの透明化は、盤面（マス・ブロック・キャラクター）だけにかかり、ゲーム名と Start ボタンにはかからない。
- デモは、Game と同じ見た目の盤面・ブロック・キャラクターと、ライン消し・出現・間引き・押せないブロックの置き直しの演出を使う。デモ専用の見た目の演出は、切り替えの透明化だけである。
- 盤面の本体（マスとブロックの状態）は、演出の完了を待たずに更新済みの状態で扱う。演出は見た目だけで、入力判定には影響しない。
- 押せないブロックの置き直しの規則: 一度の生成で置き直した押せないブロックの数だけ、縮小と広がりの組を再生する（置き直しが行われても、採用された候補に置き直しがなければ何も出さない。同じ一列の消去で補充されたばかりの押せないブロックが置き直されたときは、縮小は出さず、新しいマスに補充の出現として広がるだけ）。縮小のマスと広がりのマスは、ほかのライン消し・出現・間引きの演出と同じ層に描き、同じマスで重なる場合は、出現・広がりが上に描かれる（同じマスに、置き直しの縮小と、新しい押せるブロックの出現が重なるときも同じ）。置き直しの縮小・広がりは、`ending` の間は最後まで再生し、Result への遷移・「Quit」・向きの変更では、ほかの演出と同じく破棄してよい。盤面の本体は、置き直し後の位置に更新済みで、キャラクターは新しいマスの押せないブロックを通れない（演出の完了を待たない）。
- 演出の再生中に手数が尽きた場合、始まった演出は `ending` の間は最後まで再生する。Result へ遷移した時点で、残りの演出は破棄する。「Quit」でタイトル画面へ戻るときは、演出を待たずに破棄する。
- 手数の警告と危険は、手数の値だけで決まる状態の演出である。ライン消しによる回復や戻すで手数が基準を超えれば止まり、再び基準以下になれば始まる。`ending` の間も続き、Result への遷移で破棄する。向きが変わったときは、配置し直したうえで、その状態のまま続ける（点滅の位相は合わせなくてよい）。縁の赤い脈打ちは、HUD とボタンより手前に描き、入力を妨げない。
- 画面全体のフラッシュは使わない（盤面が全部作り直されたように見えるため）。Scene が始まるときの黒からのフェードは、ここでいうフラッシュではない。
- 光るブロックの白い重ねは、ライン消しの演出用のブロックと同じ層に描く（キャラクターより手前、失敗の赤い枠・歩きの輪より奥）。間引き前（`次の演出の開始` まで）に見えている押せるブロックは間引きの演出の層に、置き直しの縮み前の元のマスの押せないブロックは置き直しの縮小と同じ層に、通常の見た目で描く。入力で完成させた出現・置き直しのブロックは、その一列のライン消し・出現・間引きの演出が終わるまで、演出の層で光る・縮む旧ブロックと間引きのブロックの上に描く。
- ブロックや文字は盤面とキャンバスの外にはみ出さない。

## ルール

なし（演出は見た目だけで、入力判定には影響しない。「演出・UI」の規則を参照）。

## テスト観点

- 押せないブロックの置き直しの演出の入力（一手の結果 `MoveResult` の契約として、ロジックのテストで確認する）: 置き直しの記録の 1 組ごとに、元のマスで縮小し、新しいマスで広がる（広がりは、新しいマスが「新しく現れたブロック」の一覧に FIXED として入ることで再生される）。記録が空なら、置き直しの演出は何も出ない。補充されたばかりの押せないブロックを置き直したときは、記録に入らず、元のマスは「新しく現れたブロック」の一覧にも入らない（新しいマスだけに現れる）。初期盤面の生成は記録を使わない。縮小と広がりの長さ・開始時刻（`次の演出の開始` = 370 ms で縮小が始まる、480 ms で広がりが始まる、590 ms で縮小が終わる、700 ms で広がりが終わる）は、既存のライン消し・出現と同じ長さを使うことを、QA の連続撮影で確認する
- 一列が消えたときの演出の順序（演出の時刻を求める関数を時刻と演出の種類で確認する。一列を消した押しを t = 0 とする）:
  - 消える一列: t = 0 で白の不透明度 0・大きさ等倍、t = 75 ms で 0.4、t = 150 ms で 0.8（`予告光の最大不透明度`）・大きさ等倍のまま。t = 150 ms から縮み始め、t = 370 ms で 0.2 倍・透明（`ライン消し演出` の終わり）。149 ms では縮んでいない
  - 出現: t = 369 ms では 0 倍（空きマスの見た目）、t = 370 ms で 0 倍から始まり、t = 480 ms で中間、t = 590 ms で等倍
  - 間引き: t = 369 ms まで押せるブロックの通常の見た目、t = 370 ms から灰色の点滅、t = 1350 ms で消える
  - 置き直し: 元のマスは t = 369 ms まで通常の見た目、t = 370 ms から縮み始め、t = 590 ms で消える。新しいマスは t = 480 ms まで見えず、t = 480 ms から広がり始め、t = 700 ms で等倍
  - 演出の途中の入力で完成させる: t = 100 ms に盤面を操作する入力があると、出現のマスは等倍で現れ、置き直しの元のマスは消え、新しいマスは等倍で現れる。光る・縮むは、そのまま t = 150 ms・370 ms の時刻で進む。間引きは t = 370 ms に始まる。t = 500 ms にあっても、出現・置き直しは完成し、間引きは t = 370 ms から始まった進み具合のまま続く
  - t = 400 ms の入力（置き直しの縮みが進行中で、広がりはまだ）: 置き直しの元のマスは消え、新しいマスは等倍で現れる。出現も等倍になる
  - 完成させない入力: 履歴が空のときの Undo、自分のマスのタップ、盤面の外のタップ、「Quit」の 1 回目のタップ、`ending` の間のすべての入力では、出現と置き直しは完成せず、演出の時刻のまま進む。履歴がある Undo、失敗の揺れが出るタップ、動けない移動入力、歩き・押す・1 マス移動では完成する。歩きの 2 マス目以降では完成の処理を繰り返さない
  - 連続して一列が消えるとき: 前の一列の出現が終わる前に次の一列を消す押しをしても、その押しで前の分が完成し、新しい一列の順序が t = 0 から始まる
  - 回帰: 盤面の本体（マス・キャラクターの位置・手数・スコア・履歴）は、演出の順序の導入前と同じ。同じ乱数シードと同じ入力で、一列が消えた直後の盤面の本体が変わらない。光る間（0〜150 ms）に消える一列のマスへ歩いて入れる（空きマスとして扱う）
  - `ending`（一列を消した後に歩いて手数が尽きた場合）: 演出の途中で `ending` に入っても、まだ始まっていない出現・間引き・置き直しも決まった時刻に始まり、`終了待ち` の間は時刻のまま再生を続け、Result への遷移で破棄する（入力は無視されるので完成はしない）
  - 破棄: 「Quit」・向きの変更・Result への遷移で演出が破棄されても、盤面の本体の状態（出現したブロックは等倍、置き直しは新しいマス、間引かれたブロックは無し）がそのまま見える。破棄された演出が残らない
- 一列を消したときの手数の回復表示の値 N は、実際に増えた手数である（手数 20 → 消去 → 33 なら 14、手数 35 → 消去 → 40 なら 6、上限の 40 で押した場合も、増えた分だけ）
- 手数の警告の段階の判定: 手数 11 以上は「なし」、10〜6 は「警告」、5〜1 は「危険」、0 は「危険」（`警告の手数` と `危険の手数` の境界ちょうどを含む）

## 完了条件

- 縁の赤い帯と重なっても、手数の表示が読める（QA のスクリーンショットで確認する）。
- 手数が 10 以下で、手数の表示が赤く脈打つ。5 以下で、脈打ちが速くなり、画面の縁も赤く脈打つ。ライン消しなどで手数が増えて基準を超えると止まる（QA のスクリーンショット連続撮影で確認する）。
- 一列を消す・ブロックが出る・間引かれる演出が、互いに見分けられる。画面全体のフラッシュがない（QA のスクリーンショット連続撮影で確認する）。
- 押せないブロックが置き直されるとき、元のマスで縮み、新しいマスで広がるのが見える。置き直しのないとき（初期盤面・デモの盤面の作り直しを含む）は、何も出ない。ゲームの進行（入力・手数・盤面）には影響しない（QA のスクリーンショット連続撮影で確認する。置き直しが起きにくいので、乱数または評価を固定した確認用の盤面で再現する）。

- 一列を消す押しで、消える一列が白く光ってから縮み、その終わり（370 ms）から、新しいブロックの出現・間引き・置き直しが始まる。光る間と縮む間は（入力で完成させる前は）、新しいブロックがまだ見えず、間引かれるブロックと置き直される押せないブロックの元のマスは通常の見た目のまま（QA のスクリーンショット連続撮影で、0・100・200・300・400・500・700 ms で確認する）。
- 演出の途中で盤面を操作する入力をすると、出現と置き直しがその場で完成する。見えていないブロックに阻まれて動けない、という食い違いが見えない（QA で、一列を消した直後の押しと、Undo・失敗のタップで確認する）。入力は止まらず、遅れない。
- 画面全体のフラッシュがない。光るのは消える一列のブロックだけである（QA のスクリーンショット連続撮影で確認する）。
- 回帰: ルール・スコア・手数の回復・盤面の生成と難しさ・押せないブロックの置き直しの規則・入力の応答・`終了待ち`・Result への遷移での破棄・「Quit」での破棄・向きの変更での破棄は、演出の順序の導入前と同じである（既存の単体テストが変更なしで通る）。

## 実装裁量

- 光の白の色味と、光の不透明度の上がり方の細部（t = 150 ms で `予告光の最大不透明度` に達し、t = 0 で 0 であること）。縮む間に白をどう薄めるか（ブロックの透明化とともに消えること）。
- 演出の時刻を求める関数のモジュール構成（ロジックの単体テストで確認できること）。
- 歩きの目印（輪）・失敗の赤い枠・「+N」・「Quit?」の色、輪の線の太さ・開始と終了の大きさ、「+N」のフォントの大きさ。0.3 秒未満の細かい動き。
- 失敗の揺れ以外の、細かいフィードバック（押したときの小さな動き等）。0.3 秒未満のものに限る。
