# Title とデモ

## 概要

Title 画面の配置と、盤面で流す自動プレイ（デモ）の仕様。ルール・操作・盤面生成は変えず、見せ方だけを持つ。用語・Game の配置・`ending`・「初期盤面」・「一列が消えた後に起こること」などの共通の定義は `docs/spec.md` にある。

## 操作仕様

Title の入力（Start・Space / Enter だけを受け付ける）は、「画面・Scene 構成」の「Title」「デモ」に書く。

## 画面・Scene 構成

### Title

- ゲーム名「pushline」、「Start」ボタン、デモの盤面を置く。遊び方の説明文は置かない。HUD・Undo・Quit は出さない。Start ボタンは、ゆっくり拡大縮小を繰り返す（`Start の脈打ち` を参照）。
- ボタンは高さ 80 px 以上、幅 200 px 以上とする（タッチで押しやすい大きさ）。
- デモの盤面は、Game と同じ位置・同じ大きさ（5 × 6、1 マス 80 px）で、暗くせずに置く。ゲーム名と Start ボタンは盤面と重ならない位置に置く。

| 要素 | 縦画面（中心 x = 240） | 横画面（中心 x = 480） |
|---|---|---|
| デモの盤面 | 左上 (40, 110)、全体 400 × 480（Game と同じ） | 左上 (280, 60)、全体 400 × 480（Game と同じ） |
| ゲーム名 | 盤面の上。y 約 60 | 盤面の左の余白。中心 (140, 300) |
| 「Start」ボタン | 盤面の下。y 約 690 | 盤面の右の余白。中心 (820, 300) |

#### デモ

Title を表示している間、盤面で自動プレイを流す。盤面のルール・盤面の生成は Game と同じものを使い、演出はライン消し・出現・間引きだけを Game と同じ見た目で出す（それ以外の演出は出さない）。プレイヤーの入力では動かない。

- デモの盤面・キャラクター・ライン数は、Game や Result の状態とは別のデモ専用のものである。デモは Game とは別の乱数を使う。Title に入るたびに、初期盤面（「初期盤面」の手順 1〜4）から始め、ライン数は 0 である。盤面を作り直すたびに、同じく初期盤面から始め、ライン数を 0 に戻し、直前に消した行・列の記録も消す。Game に入ったとき、デモの状態は何も引き継がない。
- 進め方（ソルバー誘導）: 今の盤面で、盤面の生成の難しさの判定に使う最短手数の探索（幅優先）により、一列を消す最短の手順を求める。その手順を 1 手ずつ、`デモの1手間隔` ごとに進める。1 手は 1 マスの移動（押す場合を含む）で、タップ移動の歩きは使わない。手順の途中でも、盤面は Game と同じ規則で更新する。1 フレームに進める手は最大 1 手とする（長いフレームのあとでも、手を連続して進めない）。
- 手数はデモでは数えず、表示もしない（手数切れで終わらない）。ライン数は数える。一列が消えるたびに（`デモの1局のライン数` 本目も含めて）、「一列が消えた後に起こること」と同じ順で、押せないブロックの補充と盤面の生成を行う。目標の最短手数と押せないブロックの目標数は、デモのライン数で決まる。
- 手順は、各待ち（下の `waiting`）の開始時に求める。計算を複数フレームに分けてよい。その間も、Start などの入力は通常どおり受け付ける（計算を待たない）。

デモの内部フェーズ:

| フェーズ | 内容 | 遷移 |
|---|---|---|
| `waiting` | 局の開始（Title に入った時、または新しい盤面が現れきった時）、または一列が消えた押しから、`デモの間` の待ち。手順はこの待ちの開始時に求める（ライン数が `デモの1局のライン数` のときは求めない） | 待ちが終わったとき（手順の計算が終わっていなければ、終わった時）、手順があれば `stepping` へ入り、1 手目をその時に動かす。手順がない（探索のノード数が `探索のノード上限` を超えた場合と、盤面に消せる一列がない場合を含む）、またはライン数が `デモの1局のライン数` なら `fading-out` へ |
| `stepping` | 手順の 2 手目以降を、前の手から `デモの1手間隔` ごとに進める | 手順の最後の手（一列を消す押し）を動かしたとき `waiting` へ（ライン数 +1、補充と生成を行う） |
| `fading-out` | 再生中の演出を破棄し、盤面（マス・ブロック・キャラクター）が `デモの切り替え` かけて透明になる。手は進めない | 経過したら、盤面を新しい初期盤面（出現の演出なし）に差し替え、`fading-in` へ |
| `fading-in` | 新しい初期盤面が `デモの切り替え` かけて現れる。手は進めない | 経過したら `waiting`（ライン数は 0） |

- 時刻の例: 局の開始を t = 0 として、手順が 3 手のとき、1 手目は t = 500 ms、2 手目は 720 ms、3 手目（一列が消える）は 940 ms、次の局面の 1 手目は 1440 ms。手順がない盤面では、t = 500 ms に `fading-out`、800 ms に `fading-in`、1100 ms に `waiting`、1600 ms に次の手順の 1 手目（手順があれば）。
- 入力: Start ボタンのタップ、Space / Enter だけを受け付け、Game へ進む。どのフェーズ（手の進行・手順の計算・切り替え）でも、入力と同じフレームのうちに Game への遷移を始める。盤面のタップ・スワイプ、矢印キー・WASD・Z・Backspace・R は無視する（失敗の揺れも歩きの目印も出さない）。
- Game へ進んだ時点で、デモの進行は止める（同じフレームに届いた残りの 1 手は動かさない）。再生中の演出と、デモのタイマー・tween は破棄する。
- 向きが変わったときは、配置し直すだけで、デモの盤面・キャラクター・ライン数・フェーズ・手順の進み具合と、次の手または次のフェーズまでの残り時間は変わらない（リセットも延長もしない）。再生中の演出は破棄してよい。`fading-out` / `fading-in` の最中は、フェーズの進み具合に合う不透明度で盤面を描き直す（`fading-out` の途中なら旧盤面をその進み具合の不透明度で、`fading-in` の途中なら新盤面をその進み具合の不透明度で）。

## ルール

なし（デモの進め方は「画面・Scene 構成」の「デモ」に書く。盤面のルールは `docs/spec.md` と同じ）。

## パラメータ表

| 項目 | 初期値 | 意味 |
|---|---|---|
| Start の脈打ち | 1200 ms | Start ボタンの拡縮 1 往復の長さ |
| Start の脈打ちの拡大 | 1.05 倍 | Start ボタンが最も大きくなるときの倍率 |
| デモの1手間隔 | 220 ms | デモでソルバーの手順を進める間隔（タップ移動の `歩きの 1 マス時間` より遅く、見て追える速さ） |
| デモの間 | 500 ms | `waiting` の長さ。局の開始や盤面の作り直しの後、最初の 1 手まで。一列が消えた後、次の 1 手まで（最後の一列の後は、切り替えの開始まで。手順がないときも切り替えの開始まで） |
| デモの1局のライン数 | 4 | この数の一列を消したら、デモの盤面を作り直す（難しさの目標が上がりすぎないようにする。スコア 0〜3 の目標の最短手数は 6 → 6 → 7 → 7） |
| デモの切り替え | 300 ms | 盤面が透明になるまでと、新しい盤面が現れきるまで、それぞれの長さ |

## テスト観点

- Title のデモ（時計と乱数を注入して確認する。多数の乱数シードで繰り返す）
  - 局の開始: 初期盤面（キャラクターが (2, 5)、押せないブロック 3 個、完成済みの行・列なし）から始まり、ライン数は 0。フェーズは `waiting`
  - 手順: 求めた手順を最後まで進めると、一列が消えてライン数が 1 増える。手順の各手は、Game と同じ規則で動ける手である（動けない手がない）
  - 時間の規則（局の開始を t = 0 として、手順が 3 手の盤面で確認する）: 1 手目は t = 500 ms（`デモの間`）、2 手目は t = 720 ms、3 手目は t = 940 ms。499 ms では動かない。一列が消えた手が t = 940 ms のとき、次の手順の 1 手目は t = 1440 ms（1439 ms では動かない）
  - 1 フレームに進む手は最大 1 手: 時計を一度に 2000 ms 進めても、動く手は 1 手だけである
  - 局の区切り: ライン数が 3 のときは盤面を作り直さない。`デモの1局のライン数`（4）本目が消えた押しの後にも、補充と盤面の生成が行われ（出現の演出が出る）、その押しから 500 ms 後に `fading-out` が始まる。499 ms では始まらない。手順の計算は行わない
  - 切り替え: `fading-out`（300 ms）の間と `fading-in`（300 ms）の間は手を進めない。`fading-in` が終わってから `デモの間` 後に最初の 1 手が動く。新しい盤面は初期盤面と同じ条件（出現の演出なし、ライン数 0、直前に消した行・列の記録なし）を満たす
  - 手順が見つからないとき（探索が `探索のノード上限` を超えた場合と、消せる一列がない盤面を、手順を返さないソルバーを注入して再現する）: 待ちの開始から 500 ms 後に `fading-out` が始まる（行き詰まらない）。そこから 300 ms 後に `fading-in`、さらに 300 ms 後に `waiting`
  - 手順の計算が複数フレームにまたがるとき（計算の完了を遅らせるソルバーを注入して再現する）: 1 手目は、待ちの終わりと計算の完了のうち遅いほうの時刻に動く。計算中も、Start などの入力は受け付けられる
  - 手数が尽きない: デモの手数は数えず、100 手進めても局が手数切れで終わらない（`デモの1局のライン数` 本で必ず切り替わる）
  - 独立: デモを進めても、Game の初期盤面・乱数・戻す履歴・スコアに影響しない（同じ乱数シードの Game の最初の盤面が、デモを先に動かしていても変わらない）。デモの盤面生成は、Game とは別の乱数を使う
  - 入力: Start のタップ・Space・Enter では Game へ進み、盤面のタップ・スワイプ・矢印キー・WASD・Z・Backspace・R では何も起こらない（デモの盤面も変わらない）。`waiting`・`stepping`・`fading-out`・`fading-in`・手順の計算中のどの最中でも、Start / Space / Enter は同じフレームのうちに Game への遷移を始める
  - Game へ進んだ同じフレームに次の手の時刻が来ていても、その手は動かさない
  - 向きが変わっても、デモの盤面・キャラクター・ライン数・フェーズ・手順の進み具合と、次の手または次のフェーズまでの残り時間は変わらない。`fading-out` の途中（150 ms 経過）で向きが変わっても、残り 150 ms で `fading-in` へ進み、`fading-in` の途中でも同様に残り時間を保つ
  - 回帰（Title の表示まわり）: Title の配置データのうち、Start の脈打ち（`Start の脈打ち` 1200 ms・`Start の脈打ちの拡大` 1.05）と画面のフェード（`画面のフェード` 150 ms）の値が、デモの導入前と同じである。デモのコードがブラウザのストレージ API を呼ばない（コードの検索で確認する）

## 完了条件

- Title の盤面の位置が、縦画面では左上 (40, 110)、横画面では左上 (280, 60) で、Game と同じである。ゲーム名と Start ボタンは盤面と重ならず、どちらの向きでもキャンバスの内側に収まる。Start ボタンは高さ 80 px 以上、幅 200 px 以上である（配置データの検査と、QA のスクリーンショットで確認する）。
- Title の盤面でデモが動く。一列が消える・ブロックが出る・間引かれる演出が Game と同じ見た目で出る。HUD・Undo・Quit は出ない。局が `デモの1局のライン数` 本ごとに作り直される。Title に入った直後から、Start と Space / Enter でいつでも Game へ進める（QA のスクリーンショット連続撮影で確認する）。
- デモの間、盤面のタップ・スワイプ・キーに反応しない（失敗の揺れも出ない）。Start と Space / Enter は、デモの手の進行・手順の計算・切り替えのどの最中でも、入力と同じフレームのうちに Game への遷移を始める（デモの処理を待たない。テストで確認する）。
- Title の Start ボタンの脈打ち（`Start の脈打ち`・`Start の脈打ちの拡大`）と、Scene 開始のフェード（`画面のフェード`）は、デモがあっても変わらず動く（QA のスクリーンショット連続撮影で確認する）。
- デモは、ブラウザのストレージ（localStorage・sessionStorage・IndexedDB）を使わない。セッションをまたいで保存するものはない（コードの検索で確認する）。
- 縦画面と横画面を切り替えても、デモは続き、盤面が飛ばない（QA で、切り替えの前後のスクリーンショットで確認する）。

## 実装裁量

- デモの手順の求め方の細部（盤面の生成の最短手数の探索を再利用してよい。同じ長さの最短手順が複数あるときの選び方）。手順を求める計算を、1 フレームで終えるか、複数フレームに分けるか（Title の入力応答を妨げないこと）。
- 切り替えの透明化のイージング、局の開始時の盤面の出し方（初期盤面は出現の演出なしで、盤面全体が現れる）。
