# 盤面の生成

## 概要

一列が消えるたびに新しい押せるブロックを出す手順と、消せる保証、難しさの目標。ルール・操作・見た目は変えない。用語・押せないブロックの補充・初期盤面などの共通の定義は `docs/spec.md` にある。

## 操作仕様

なし（操作は `docs/spec.md` の「操作仕様」のまま。）

## 画面・Scene 構成

なし（`docs/spec.md` の「画面・Scene 構成」のまま。）

## ルール

### 盤面の生成（新しい押せるブロックの出現）

保証すべき性質（実装はこの手順と同等の性質を満たせばよい）:

- 順方向に遊べば、必ず一列を消せる（歩いて押す手順が存在する）。
- キャラクターのマスにはブロックを置かない。
- 生成直後の盤面に、完成済みの行・列は存在しない。
- 直前に消した行・列を、次の「消す対象」にしない。
- 出現する盤面の実際の最短手数（今の位置から最初の一列が消えるまでの最小手数）が、`目標の最短手数` 以上であることを目指す。満たせなければ、見つかった中で最も難しい候補を使う。

手順（1 回の試行）:

1. 盤面を複製する。押せるブロックが `残しておく押せるブロックの数` を超えていれば、ランダムに選んで超過分を取り除く（取り除いたものは「間引き」として演出する）。以降の手順は、この間引き後の盤面に対して行う。
2. 消す対象の一列を、直前の消去で消したすべての行・列と、キャラクターのいる行・列を除いて、ランダムに選ぶ。その一列のうち、空きの 1 マスを `c` とする（空きがなければ試行を破棄する）。
3. 一列に垂直な方向 `d`（行なら上下、列なら左右）をランダムに選ぶ。`feeder = c − d`、`start = c − 2d` とする。どちらも盤面の内側で、`feeder` が押せないブロックでなく、`start` が空きマスであること。満たさなければ試行を破棄する。
4. ダミーの押せるブロックを `ダミーのブロック数` 個、空きマスにランダムに置く（一列の各マス・`feeder`・`start`・キャラクターのマスを除く）。
5. 一列の `c` 以外の空きマスと、`feeder`（空きなら）に、押せるブロックを置く。この時点で完成済みの行・列があれば試行を破棄する。
6. 「逆再生」を `目標の最短手数 + 逆再生の追加ステップ数` ステップ行う。仮想のキャラクターを `start` に置き、各ステップで方向 `e` をランダムに選ぶ。
   - 後ろ（仮想キャラクターの位置 − `e`）が盤面の内側の空きマスでなければ、そのステップは失敗とし、別の方向を選び直す（選び直しは、試行全体で `ステップ数 × 6` 回まで。この回数を使い切ってもステップが終わらなければ、その試行を破棄する）。
   - 前（仮想キャラクターの位置 + `e`）に、この試行の中で置いた押せるブロック（手順 4 のダミー・手順 5 で置いたブロック・すでに引き寄せたブロック）があり、仮想キャラクターが本物のキャラクターのマスにおらず、確率 `押しの取り消し確率` に当たれば、そのブロックを仮想キャラクターのいるマスへ引き寄せる（押しの取り消し）。前の盤面から残っていた押せるブロックは引き寄せない（動かない障害物として扱う）。
   - 仮想キャラクターを後ろへ動かす。
   - 各ステップの後に完成済みの行・列があれば、試行を破棄する。
7. 次をすべて満たさなければ試行を破棄する: 押しの取り消しが `押しの取り消しの最低回数` 回以上、本物のキャラクターのマスが空き、本物のキャラクターから仮想キャラクターの最終位置へ空きマスだけで歩いて行ける。
8. 難しさの判定: 結果の盤面で、探索（幅優先）により `目標の最短手数 − 1` 手以内に一列が消えるか調べる。見つからなければ（ノード数が `探索のノード上限` を超えた場合を含む）、この候補を採用して終了する。見つかれば、見つかった手数が最大の候補を覚えておく。
9. 試行は最大 `生成の最大試行回数` 回、かつ `生成の時間上限` の範囲で行う（時間上限を超えたら、その時点で試行を打ち切る）。採用されなかったときは、覚えておいた最も難しい候補を使う。
10. 候補が 1 つもなければ、「1 回の押しで一列が消える」単純な配置を使う。手順 1〜3 で、消す対象の一列・`c`・`d` の組をすべて列挙し、それぞれについて「一列の `c` 以外の空きマスと `feeder`（空きなら）に押せるブロックを置く」配置を作る。完成済みの行・列ができず、本物のキャラクターから `start` へ空きマスだけで歩いて行けるものだけを残し、その中からランダムに 1 つを使う（ダミーも逆再生もなし）。
11. それも 1 つもなければ、押せるブロックは追加しない。この場合、盤面に消せる一列がないことがある（まれ）。直前に一列を消した直後なので「戻す」の履歴は空で、出口は「Quit」（または手数切れ）だけである。
12. 手順 1 の間引きは、手順 10・11 でも必ず行う（1 回の生成につき 1 回）。間引かれたブロックは、手順 9〜11 のどれが使われても、間引きの演出で消える。

### 消せる保証が及ぶ範囲

- 「必ず消せる」は、盤面を生成した時点の保証である。その後にプレイヤー自身が押したブロックを隅などに押し込み、消せなくなることはありうる（意図した仕様）。そのときの出口は「Undo」と「Quit」である。
- 手順 11（何も追加しない）は、手順 1〜10 のどれでも作れなかったときだけの最後の手段である。通常のプレイでは起こらないことを、テストで確認する（テスト観点）。

### 難しさの目標

- `目標の最短手数 = min(目標の最短手数の上限, 目標の最短手数の初期値 + floor(ライン数 / 目標が 1 増えるライン数))`。
- 盤面の生成は、ゲーム開始時（スコア 0）と、一列が消えるたびに行う。

## パラメータ表

| 項目 | 初期値 | 意味 |
|---|---|---|
| 目標の最短手数の初期値 | 6 | スコア 0 のときの目標 |
| 目標が 1 増えるライン数 | 2 | 2 ライン消すごとに目標が 1 増える |
| 目標の最短手数の上限 | 10 | プレイが進んだ（盤面が混んだ）状態では、10 手以上の盤面は作れないことがある。そのときは最も難しい候補を使う |
| 逆再生の追加ステップ数 | 8 | 逆再生のステップ数 = 目標の最短手数 + 8 |
| 押しの取り消しの最低回数 | 4 | 逆再生で最低限必要な押しの取り消し |
| 押しの取り消し確率 | 0.85 | 逆再生で、引き寄せられるブロックがあるときに取り消す確率 |
| 生成の最大試行回数 | 300 | 盤面の生成の候補を作り直す上限 |
| 生成の時間上限 | 100 ms | 盤面の生成 1 回の上限。超えたらその時点の最良の候補で打ち切る（手順 9） |
| 探索のノード上限 | 60000 | 難しさの判定で、探索する状態数の上限 |
| ダミーのブロック数 | 2 | 解に関係しない押せるブロックを出現ごとに置く数 |
| 残しておく押せるブロックの数 | 2 | 出現のたびに、前の盤面の押せるブロックをここまで間引く |

## テスト観点

- 盤面の生成（多数の乱数シードで繰り返す。独立した探索を「正解」として使う）
  - 生成した盤面で、探索により一列を消す手順が見つかる
  - キャラクターのマスにブロックがない
  - 完成済みの行・列がない
  - 手順 2 で、直前の消去で消した行・列とキャラクターのいる行・列が、消す対象として選ばれない（乱数を注入して全候補を列挙して確認する）
  - 前の盤面から残った押せるブロックの数が、`残しておく押せるブロックの数` 以下になる（新しく置いたブロックは含めない）
  - 乱数シード 100 通りで、探索で測った最短手数が目標の最短手数以上になる割合: スコア 0 と 4 では 50% 以上、スコア 8（目標 10）では 1 件以上（実装後に実測し、満たせない場合は閾値を見直す）
  - 目標の最短手数の計算: スコア 0 → 6、1 → 6、2 → 7、8 → 10、10 → 10（上限）
  - 押せないブロックの目標数の計算: スコア 0 → 3、1 → 3、2 → 4、8 → 7（上限）、10 → 7
  - 一列を消すとき、補充と生成には、更新後のスコアが使われる（スコア 1 から 2 になる消去で、押せないブロックの目標数が 3 から 4 になる）
  - 手順 10・11 が使われた場合も、間引きが行われる
  - 履歴の上限は注入できること（テストでは小さい値を注入して確認する）
  - どの候補も目標を満たさないとき、見つかった中で最短手数が最も大きい候補を使う
  - 生成の時間上限を超えたとき、その時点の最良の候補で打ち切る（時計を注入して再現する）
  - 手順 11（何も追加しない）に至る割合: 乱数シード 200 通り × 10 ラウンドの連続プレイ（各ラウンドは探索で見つけた最短手順で一列を消す）で 0 件であること
  - 同じ連続プレイで、一列を消した直後の盤面のうち、押せないブロックの数が目標数に届かないものの割合が 5% 以下であること（届かないのは置ける場所がないときだけ。回数と割合を数え、ラウンドが実際に行われたことも確認する）
  - 初期盤面: キャラクターが (2, 5)、押せないブロックが 3 個、完成済みの行・列がなく、押せるブロックから一列を消せる

## 完了条件

- 一列が消えるたびに、必ず消せる位置に新しいブロックが出る（盤面の生成の手順 11 の最後の手段を除く）。キャラクターのマスにブロックは出ない。生成直後に、すでに揃っている行・列がない。
- 乱数シード 200 通り × 10 ラウンドの連続プレイで、盤面の生成が「何も追加しない」結果にならない（テストで確認する）。
- 同じ連続プレイで、一列を消した直後の盤面のうち、押せないブロックの数が目標数に届かないものは 5% 以下である（置ける場所がないときだけ届かない。実装後に実測して閾値を確認する。テストで確認する）。

## 実装裁量

- 盤面生成での乱数の使い方の細部（候補の選び方の順序など）。ただし「盤面の生成」の保証と、`パラメータ表` の値は守ること。
