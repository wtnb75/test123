# pushline

倉庫番のようにブロックを 1 個ずつ押して、縦か横の一列をブロックで埋めて消す、エンドレスのパズルです。一列を消すと手数が回復し、消えた後には必ず消せる位置に新しいブロックが出ます。手数が 0 になるまでに、何本消せるかを競います。

仕様は [docs/spec.md](docs/spec.md) にあります。

## 遊び方

### 目的

手数が尽きるまでに、できるだけ多くの一列を消します（スコアは消したライン数）。

### ルール

- 黄色のブロック（押せるブロック）は、キャラクターが 1 個だけ押せます。押した先に別のブロック・壁・盤面の外があると動きません。
- 灰色の×印のブロック（押せないブロック）は動かせません。ただし「埋まったマス」として、一列の判定には数えます。一列が消えて新しい盤面が作られるとき、簡単すぎる盤面しか作れないと、押せないブロックが別のマスへ移ることがあります（元のマスで縮んで消え、新しいマスに現れます。数は変わりません）。
- 押したブロックが入ったマスの行または列が、すべてブロックで埋まると、その一列が消えます（押せないブロックも消えます）。キャラクターのいる一列は埋まったことになりません。
- 1 マス動くごとに手数が 1 減ります（動けない入力では減りません）。一列を消すと手数が 11 回復します（上限 40）。その盤面が出てから動いた回数（戻しても減りません）が、最短手数以下で消せたときは、さらに 4 回復します（「最短!」）。Result に最短で消せた回数が出ます。最高のライン数はブラウザに保存され、プレイ中は盤面の下（横画面では左）に「ベスト N」と出ます。前回の最高より多く消すと、その場で「ベスト N 更新!」に変わって保存されます（ゲームオーバーを待たないので、途中で Quit しても残ります）。Result にも同じ行が出ます。保存できない環境では出ません。手数が 10 以下になると、手数の表示が赤く脈打ち、5 以下ではさらに画面の縁も赤く脈打ちます。
- 手数が 0 になると終わりで、結果が出ます。「Quit」を 2 回タップ（1 回目で「Quit?」、2 秒以内にもう一度）すると、結果を出さずにタイトルへ戻ります。R キーなら確認なしで戻ります。
- 一列が消えるたびに、必ず消せる位置に新しい押せるブロックが出ます。進むほど、消すのに必要な手数が増えていきます。残っていた押せるブロックのうち、2 個を超える分は間引かれます（灰色に点滅して消えます）。

### 操作

| 操作 | タッチ | キーボード |
|---|---|---|
| 歩く | 空きマスをタップ（最短経路で歩く） | — |
| 押す | キャラクターの隣の押せるブロックをタップ | 矢印キー / WASD |
| 1 マス動く | 画面をスワイプ | 矢印キー / WASD |
| 戻す（盤面内） | 「Undo」ボタン | Z / Backspace |
| 中断してタイトルへ | 「Quit」ボタンを 2 回タップ | R（確認なし） |

画面の向きは、ウィンドウの大きさで縦画面と横画面が切り替わります。

タイトル画面では、盤面の上でお手本のプレイ（自動プレイ）が流れます。「Start」ボタン（または Space / Enter）で始まります。デモの間、盤面の操作は受け付けません。

## 開発

```bash
pnpm install          # リポジトリのルートで
npm run dev           # このディレクトリで開発サーバー
npm run lint
npm run test
npm run test:coverage
npm run build         # 単体ビルド（dist/）
```
