# dutchcalc

競馬や toto などで複数の候補（馬・組み合わせ等）に賭けるとき、どの候補が当たっても払戻額がなるべく均等になるように口数を配分するブラウザツールです。

## どんなツール?

- 各候補の倍率（オッズ）を入力する
- 合計購入口数と1口あたりの金額を入力する
- 「計算」を押すと、各候補への口数配分と払戻見込み額・回収率が表示される

## 操作

- 「候補を追加」: 候補行を増やす（最大20件）
- 各候補行の「削除」: その候補を削除する（候補が2件のときは無効）
- 合計口数 / 1口あたり金額を入力して「計算」を押す
- 入力が不正な場合はエラーメッセージが表示される

## ルール

- 候補は2件以上、倍率はすべて1.0より大きい数値
- 合計口数は候補数以上、100,000以下の整数
- 1口あたり金額は100以上かつ100の倍数
- 配分は「逐次貪欲法」: 現在の払戻見込み額が最小の候補に1口ずつ追加していく
- 表示される「バランス度」は各候補の払戻見込み額の最大値と最小値の差。小さいほど均等

## 非対応

- 複数グループの組み合わせベット（toto の複雑な組み合わせ全体の最適化等）
- オッズの自動取得・外部API連携
- 実際の購入・決済機能
- 配分結果の保存・共有・履歴機能

## 開発メモ

- `src/game/logic/allocate.ts`: 配分計算のロジック（Phaser非依存、Vitestで単体テスト）
- `src/game/scenes/Game.ts`: フォーム入力と結果表示（DOMオーバーレイ）
