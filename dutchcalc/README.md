# dutchcalc

競馬や toto などで複数の候補（馬・組み合わせ等）に賭けるとき、どの候補が当たっても払戻額がなるべく均等になるように口数を配分するブラウザツールです。

## どんなツール?

- 各候補の倍率（オッズ）を入力する
- 合計購入口数と1口あたりの金額を入力する
- 「計算」を押すと、各候補への口数配分と払戻・回収率・損益が表示される
- 損益が 0 円未満の候補は、赤い背景と「▼元本割れ」で示される（損益はちょうど 0 円なら元本割れではない）
- 「理論回収率」（1 / Σ(1 / 倍率)）は、払戻を完全に均等にできたときの回収率の上限。100.0% 未満なら、どう配分しても少なくとも 1 つの候補が元本割れになる

## 操作

- 「候補を追加」: 候補行を増やす（最大20件）
- 各候補行の「削除」: その候補を削除する（候補が2件のときは無効）
- 合計口数 / 1口あたり金額を入力して「計算」を押す
- 予算（円）を入力すると、合計口数が「予算 ÷ 1口あたり金額」（切り捨て）に入る。合計口数を入力すると予算も入る。予算を入れたときは、計算結果の後に「余り」（予算 − 合計投資額）が出る
- 入力が不正な場合はエラーメッセージが表示される

## ルール

- 候補は2件以上、倍率はすべて1.0より大きい数値
- 合計口数は候補数以上、100,000以下の整数
- 1口あたり金額は100以上かつ100の倍数
- 払戻は、100 円あたりの払戻（倍率 × 100）を 10 円未満切り捨てた額で求める（小数第 6 位で四捨五入してから切り捨てる）。払戻 = 口数 × (1口あたり金額 ÷ 100) × 100 円あたりの払戻。例: 倍率 2.35 → 235 → 230 円
- 配分は、切り捨てる前の払戻額の最大と最小の差（バランス度の元になる値）が最小になる配分を厳密に求める。差が同じなら、切り捨てる前の最小の払戻額が高いほうを選ぶ。切り捨ては配分には使わない
- 表示される「払戻」「最小払戻」「最大払戻」「バランス度(差)」「損益」「回収率」は、切り捨て後の払戻から出す。そのため「バランス度(差)」は、配分が最小化した差と一致するとは限らない
- 合計投資額 = 合計口数 × 1口あたり金額
- 損益 = 払戻 − 合計投資額。回収率 = 払戻 ÷ 合計投資額
- 理論回収率は倍率だけで決まる（払戻の切り捨ては使わない）

## 非対応

- 複数グループの組み合わせベット（toto の複雑な組み合わせ全体の最適化等）
- オッズの自動取得・外部API連携
- 実際の購入・決済機能
- 配分結果の保存・共有・履歴機能
