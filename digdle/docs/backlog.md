# digdle 拡張候補（backlog）

公開済みの digdle に、次に足せるものの候補を、上から順に並べたものです。上のカードが「次の候補」です。仕様（`spec.md`）ではありません。`game-extend` が上から順に 1 件を選び、目的・コアループへの効き方・変えないものを固めてから、仕様に書きます。

- 規模: S = 1 画面と数値の追加程度、M = 複数の画面や仕組みにまたがる追加、L = 大きいので、`game-extend` で 1 PR 分に切り出してから採用する。

### 低い画面で、盤面・メッセージ・キーパッドが重ならないようにする（`small-screen-fit`）

- 狙い: SE（375 × 550）で、盤面の 5 行目がメッセージ（「Enter a prime number …」）とキーパッドに隠れる。スマホ縦では、題名「digdle」が左端に縦向きに出て、Title は下の 1/3 が空く。根拠: 2026-10-12 の画面構成の調査（dev サーバー、スマホ縦 390×844・SE 375×550・PC 1280×720、汎用の操作で進めた画像）／AGENTS.md 4.6（切れ・重なり、盤面の占有）
- 何を足すか: 盤面の行の高さ・メッセージ・キーパッドの配分を、画面の高さから決め直し、最小画面（375 × 550）でも全ての行が見えるようにする。題名を縦向きにするのが意図かを確かめ、意図でなければ横にする。Title は、下の空きを使うか、要素を縦に均す。
- コアループへの効き方: 広げない — 見え方だけを変える。
- 種別: presentation-only
- 規模: S
- 出どころ: 画面構成の調査
- メモ: 題名の縦向きは、`Scale.RESIZE` の縦長用の配置の可能性がある。spec の「レイアウト方針」を読んでから判断する。
