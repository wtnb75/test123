# 文字集め（`wordfall`・仮称）

## コンセプト

上から文字が落ちてくる。画面に出ている英単語のお題（日本語の意味つき）を見ながら、必要な文字をタップしてトレイに拾い、材料が揃うと単語が完成して得点になる。長い単語ほど高得点で、遊び終えると出た単語と意味を一覧で見直せる。

## コアループ

1. 落ちてくる文字を見る
2. お題に必要な文字をタップして拾う（トレイに入る）
3. トレイが満杯に近いときは、不要な文字をタップして捨てる
4. 材料が揃うと自動で完成 → 得点と時間が増え、新しいお題が出る

## 操作仕様

- タッチ / マウス: 落ちてくる文字をタップで拾う。トレイの文字をタップで捨てる
- キーボード（補助）: 文字キーで、その文字のうち一番下に落ちているものを拾う。結果画面は Space / Enter でリトライ

## パラメータ表

| 項目 | 初期値 | `params.ts` |
|---|---|---|
| 論理サイズ | 360 × 640 | `WORLD_W/H` |
| 同時表示するお題 | 3 語 | `TARGET_COUNT` |
| お題の長さの重み（3〜8 文字） | 3,3,3,2,2,1 | `LENGTH_WEIGHT` |
| トレイの上限 | 10 文字 | `TRAY_CAPACITY` |
| 初期時間 | 60 秒 | `START_TIME_SEC` |
| 完成時の加算時間 | 文字数 × 1 秒 | `BONUS_SEC_PER_LETTER` |
| 得点（3〜8 文字） | 30 / 50 / 80 / 120 / 170 / 230 | `SCORE_BY_LENGTH` |
| 文字の出現間隔 | 650 ms | `SPAWN_INTERVAL_MS` |
| 落下速度 | 80 px/s から毎秒 +0.8、上限 200 | `FALL_SPEED_*` |
| 落ちてくる文字のうち、お題に必要な文字の割合 | 0.55（残りは A〜Z のおとり） | `NEEDED_RATIO` |
| 落ちる列数 | 8 | `COLUMNS` |

## プレイテストで固まったこと

- 1 回目のプレイテストで、ユーザーから「いい感じ」と評価があった。パラメータ表の初期値は 1 つも変えていない。具体的な不満・要望は出なかった（細かい手触りの調整は `game-balance` で行う）
- 残すもの（調整で消さない）:
  - 材料が揃ったら並べ替え操作なしで自動完成する
  - お題 3 語を同時に表示し、お題の下に日本語の意味・文字数・得点を小さく出す
  - お題の文字のうち、トレイで足りている文字は緑、足りない文字は灰色で示す
  - トレイが満杯のとき、文字をタップしても拾えない（画面が揺れる）。捨てるのはトレイの文字をタップ
  - 落とした文字にペナルティは無い。完成で時間が増え、時間切れ（0 秒）が唯一の終わり
  - 結果画面は、そのプレイで出た単語をすべて並べ、完成した語に ✓ を付けて意味を出す（最大 20 件）
- まだ確かめていないこと（`game-spec` で決めるか、実装裁量にする）:
  - 小さい画面（375 × 550・667 × 310）での文字の大きさと、意味の行の収まり（AGENTS.md 4.6）
  - 結果画面の単語が 20 件を超えたときの扱い
  - 自己ベストの保存と、Title 画面

## プロトタイプの範囲

- Scene は 1 つ（プレイ → 時間切れで結果）。Title・効果音・演出・自己ベストの保存は無い
- 単語は 3〜8 文字の英単語 36 語（意味つき）。`src/proto/words.ts`
- トレイの材料が複数のお題を同時に満たす場合は、表示順（上）のお題を先に完成させる
