# wordfall（文字集め）

落ちてくる文字を拾って、英単語を完成させろ！ 長い単語ほど高得点。

## どんなゲーム?

- 画面の上に、英単語のお題が 3 つ並ぶ（日本語の意味つき）
- 上から文字が落ちてくる。必要な文字をタップすると、画面下のトレイに入る
- トレイにお題の文字がそろうと、並べ替えなしで自動的に完成。得点と時間が増えて、新しいお題が出る
- お題の文字は、トレイに足りていれば緑、足りなければ灰色で表示される
- トレイは 10 文字まで。満杯のときは拾えない（画面が揺れる）。いらない文字はトレイの文字をタップで捨てる
- 落とした文字にペナルティはない。時間が 0 になったら終わり（残り 10 秒以下は TIME が赤くなる）
- 終わると、そのプレイで出た単語が意味つきで一覧に並ぶ（完成した語には ✓）

## スコアと時間

- 得点は文字数で決まる: 3 文字 30 / 4 文字 50 / 5 文字 80 / 6 文字 120 / 7 文字 170 / 8 文字 230
- 完成すると、文字数 × 1 秒だけ残り時間が増える（最初は 60 秒）
- 時間がたつほど、文字が落ちる速さが上がる
- 自己ベストはブラウザに保存される

## 操作方法

### スマートフォン / タブレット

- 文字を拾う: 落ちてくる文字をタップ
- 捨てる: トレイの文字をタップ
- ボタン: START / もう一度 / タイトルへ をタップ（押した場所で離したときに働く。押したまま外へ出して離せば取り消せる）
- 結果の単語一覧は、上下にドラッグでスクロール
- 横向きで画面が小さいときは「画面を縦にしてください」と出る。縦にすると続きから遊べる

### PC

- 文字を拾う: クリック、または文字キー（そのキーの文字のうち、一番下に落ちているものを拾う）
- 捨てる: トレイの文字をクリック、または Backspace（最後に拾った文字）
- 開始・もう一度: Enter / Space
- 結果の単語一覧: マウスのホイール、または ↑ ↓
